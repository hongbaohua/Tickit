# 華語領隊人員評量：新手教材
## 第一章　旅遊契約：民法旅遊專節＋國外旅遊定型化契約

**對應單元：01 法規 旅遊契約**｜**每年約 11 題（法規科最大宗）**

旅客報名旅行團，就是和旅行社簽一份「旅遊契約」。這份契約有兩層規定：

| 層級 | 名稱 | 白話 |
|---|---|---|
| 上位法律 | **民法債編「旅遊」專節**（第514條之1～之12） | 大原則，條文很短 |
| 細部規定 | **國外旅遊定型化契約應記載及不得記載事項**（交通部公告，105年9月13日修正） | 一堆具體數字：幾天、幾%、幾倍 |

- 去大陸港澳的團也用「國外」旅遊定型化契約。
- 民法題通常問「誰有什麼權利」；定型化契約題通常是**計算題**。
- 契約條款如果比規定**更有利於旅客**，從其約定。
- 所有規定都有一個方向：**保護旅客**。考試卡住時，選對旅客比較有利的答案，通常就對了。

---

### 一、民法旅遊專節（12條，全部要懂）

| 條文 | 重點 | 考法 |
|---|---|---|
| 514-1 | **旅遊營業人**＝提供旅遊服務並收費的人；旅遊服務＝安排旅程＋交通、膳宿、導遊或其他服務 | 「保管證件」不在定義裡 |
| 514-2 | 旅客請求時，旅行社要**書面**記載：名稱地址、旅客名單、地區旅程、服務品質、**旅遊保險種類金額**、填發日期 | 哪一項不用記載 |
| 514-3 | **旅客協力義務**：要旅客配合的事（例如交照片辦簽證），旅客不做，旅行社**定期催告**，還不做旅行社可**終止**契約並請求賠償；旅途中終止，旅客可請求墊付費用送回出發地（之後附利息還） | 是「旅行社」能終止，不是旅客 |
| 514-4 | **出發前可換人參加**，旅行社非有正當理由不得拒絕；**增加的費用**旅行社可向第三人收，**減少的費用旅客不能要求退** | 每年必考 |
| 514-5 | **不得已才能變更旅遊內容**；減少的費用退旅客，**增加的費用不能收**；旅客不同意可終止，請求**墊付**送回（到達後附利息償還） | 「墊付」＝先借錢，不是旅行社出錢 |
| 514-6 | 旅遊服務要有**通常之價值及約定之品質** | |
| 514-7 | 品質不夠：①請求**改善**→②不改善或不能改善→**減少費用**→③難達目的→**終止契約**；**可歸責旅行社**時，另可請求**損害賠償**，送回費用由旅行社負擔 | 不可歸責（如飯店失火）就不能請求損害賠償 |
| 514-8 | 可歸責旅行社致行程沒照走：時間浪費**按日**賠，每日上限＝**團費總額÷天數** | |
| 514-9 | 旅遊未完成前，旅客**隨時可終止**，但要賠旅行社損失 | |
| 514-10 | 旅途中身體或財產事故，旅行社要**協助處理**；**不可歸責旅行社**時，費用**由旅客負擔** | 心臟病發送醫的費用→旅客付 |
| 514-11 | 旅行社安排的購物點，商品有瑕疵，旅客可在**受領後1個月內**請旅行社協助處理 | 1個月＝30天 |
| 514-12 | 費用增減、損害賠償、墊付償還的請求權，自**旅遊終了或應終了時起1年**不行使而消滅 | 不是「訂約日起」 |

**「可歸責 vs 不可歸責」是整章的關鍵：**
- **可歸責於旅行社**（作業疏失、訂錯飯店、沒訂到機位）→ 旅行社要負擔費用＋違約金＋損害賠償
- **不可抗力 / 不可歸責**（天災、罷工、飯店失火、航班因天候延誤）→ 旅行社可以變更行程、不用賠償，但**增加的費用不能收、減少的要退**

### 二、定型化契約：簽約時

| 項目 | 規定 |
|---|---|
| **審閱期** | 不得少於 **1日**。違反者條款不構成契約內容，但旅客可主張仍有效 |
| **廣告** | 廣告、宣傳文件、行程表、說明會內容都是契約的一部分；不符時以**最有利旅客**的為準 |
| **簽約地點** | 沒寫 → 以**旅客住（居）所地**為準 |
| **簽約日期** | 沒寫 → 以**首次交付金額之日**為準 |
| **購物行程** | 有安排就要寫清楚；旅途中**不得臨時安排**購物，除非旅客要求或同意 |

#### 團費包含 vs 不包含

| 包含（團費裡） | 不包含 |
|---|---|
| 代辦證件的**行政規費** | 旅客個人費用 |
| 交通運輸費（含機場服務稅捐） | **建議**給領隊、導遊、司機的**小費** |
| 餐飲、住宿、遊覽、接送費 | 契約明列的**自費行程** |
| **領隊**及其他服務人員的**報酬** | 其他代辦代收費用 |
| 保險費＝旅行社依法投保的**責任保險、履約保證保險** | 旅客自己加保的**旅行平安險、意外險** |

- 陷阱：領隊的「報酬」包含在團費裡，給領隊的「小費」不包含。

#### 簽約後漲價（範本第8條）
- 因政府調整或航空公司調整票價，交通運輸費或遊覽費增減**超過10%**：漲價由旅客**補足全部差額**，降價由旅行社退還。
- 例：機票 18,000 → 21,000，漲 16.7% > 10% → 旅客補 3,000 元。

### 三、定型化契約：出發前取消

#### 3-1　最低組團人數
- 人數不足時，旅行社至少在出發前 **7日**通知解約（沒寫天數，視為7日）。
- 契約沒寫最低人數、或廣告寫**保證出團** → 視為**無最低組團人數**，人數不夠也一定要出團，不出就是旅行社違約。
- 解約後：全額退費（可扣已代繳的行政規費），或經旅客同意轉到另一個團。

#### 3-2　賠償比例表（最重要，每年必考）

旅客取消（第13點），和旅行社因可歸責事由取消（第12點），**比例完全一樣**：

| 距出發日 | 賠償旅遊費用 |
|---|---|
| 第 **41** 日以前 | **5%** |
| 第 **31～40** 日 | **10%** |
| 第 **21～30** 日 | **20%** |
| 第 **2～20** 日 | **30%** |
| 前 **1** 日 | **50%** |
| **當日**以後（或旅客沒通知不來） | **100%** |

- 口訣：**41、31、21、2、1、0 → 5、10、20、30、50、100**
- 旅行社取消卻**沒有通知**（怠於通知）→ 賠 **100%**
- 任何一方能證明實際損害超過比例，可請求實際損害
- **旅客取消的計算公式：(旅遊費用 − 行政規費) × 比例**，另外再繳行政規費
    - 例：團費 31,000（含簽證費 1,000），出發前1日取消 → (31,000−1,000)×50% = **15,000** 元
- 旅客**遲到**沒趕上集合、也沒辦法中途加入 → 視為**任意解除契約**

#### 3-3　不是任何人的錯
| 情況 | 規定 |
|---|---|
| **不可抗力**（天災、戰爭等）致無法履行 | 雙方都可解約、**都不用賠**；旅行社扣除已付的必要費用（憑單據）後退餘款 |
| 旅遊地**有危險之虞**（客觀風險，如傳染病、動亂） | 可解約，但解約方要補償對方，**最多 5%** |

### 四、定型化契約：出發後出狀況

#### 4-1　違約金倍數總表（背這張）

| 狀況 | 賠多少 |
|---|---|
| 可歸責旅行社，**沒照約定**的飯店、交通、餐食、景點 | **差額 × 2倍**；沒提出差額說明 → 至少**全部團費 5%** |
| 可歸責旅行社，**行程延誤**（浪費時間） | 每日 = 團費 ÷ 天數，按日賠；**5小時以上未滿1日，算1日** |
| **故意**棄置或留滯旅客 | 每日金額 × 留滯日數 × **5倍** |
| **重大過失**棄置或留滯 | × **3倍** |
| **過失**棄置或留滯 | × **1倍** |
| 可歸責旅行社，旅客遭**恐怖分子留置、當地政府逮捕羈押** | **每日 2萬元** 懲罰性違約金 |
| 出發後才發現契約被**轉讓**給別家旅行社 | **全部團費 5%** |
| 派**沒有執業證**的領隊 | **1,500元 × 天數 ÷ 實際出團人數 × 3倍** |
| 旅行社**沒投保**責任險或履約保證險 | 依最低投保金額計算理賠額的 **3倍** |

#### 4-2　計算題示範
1. **延誤**：團費15萬、10日團，原訂11:00回程，改搭翌日20:00 → 延誤33小時＝1日＋9小時→算2日 → 15萬÷10×2 = **3萬元**
2. **故意留滯**：團費3萬、6日團，留滯1日 → 3萬÷6×1×5 = **25,000元**
3. **無照領隊**：5天團、20人 → 1,500×5÷20×3 = **1,125元**
4. **沒投保責任險**：意外死亡最低保額 250萬 × 3 = **750萬元**
5. **住錯飯店＋延誤**：團費20萬、10日團，飯店價差4,000＋回程延誤（算2日）→ 4,000×2 + 20萬÷10×2 = 8,000 + 40,000 = **48,000元**（115年考題）

#### 4-3　轉讓
- 出發前要轉讓給別家旅行社，須經旅客**書面同意**；旅客不同意可解約、全額退費。
- 出發後才知道 → 賠 **5%**；受讓旅行社出錯，旅客也可找原本那家負責。

#### 4-4　旅客自己的問題
| 情況 | 規定 |
|---|---|
| 旅客**中途離隊** | 不能要求退團費（**不按比例退**）；但旅行社可節省、不用付的費用要退；返程食宿交通費由**旅客**付 |
| 旅客**沒趕上**行程（遲到） | 視為自願放棄，不能要求退費或補償 |
| 旅客不配合完成旅遊所需行為而終止契約 | 旅客可請求旅行社**墊付**送回，到達後附利息償還 |

#### 4-5　其他常考規定
- **證照保管**：旅途中旅客原則上**自己保管**證件；為了通關或經同意可交給旅行社，旅行社要以「**善良管理人**」的注意保管，旅客**隨時可取回**。
- **領隊**：旅行社必須派**有執業證**的領隊，全程隨團服務。
- **外國業者出錯**：旅行社委託的國外業者違約，國內旅行社要負**同一責任**。
- **個資**：外洩時，旅行社要立刻通報主管機關並通知旅客。
- **消費爭議**：可向觀光署、消保官、旅行業品質保障協會申訴（同業公會不是調處單位）；消保法規定業者收到申訴要在 **15日** 內妥適處理。

### 五、不得記載事項（看到就是錯的）

1. 行程、住宿、交通等內容寫「**僅供參考**」
2. 排除原刊登的廣告內容
3. 排除旅客任意解約、終止的權利
4. 超過主管機關規定的旅客**最高賠償**基準
5. 旅客對旅行社**片面變更**不得異議
6. 團費以外變相或額外加價
7. 委託旅客**代為攜帶物品**返國
8. 免除或減輕依法應履行的義務
9. 其他違反誠信、平等互惠、不利旅客的約定
10. 排除對履行輔助人（如當地接待旅行社）的責任

### 六、數字速記卡（考前最後看這張）

| 數字 | 用在哪 |
|---|---|
| **1日** | 審閱期 |
| **7日** | 人數不足最晚通知解約 |
| **10%** | 簽約後交通費、遊覽費調整的門檻 |
| **5–10–20–30–50–100%** | 41／31／21／2／1／0 日 解約賠償 |
| **5%** | 客觀風險解約補償上限；契約轉讓；差額說明未提出的最低違約金 |
| **2倍** | 服務沒照約定的差額 |
| **5／3／1倍** | 棄置留滯：故意／重大過失／過失 |
| **3倍** | 無照領隊違約金；未投保賠償 |
| **1,500元** | 無照領隊每人每日基數 |
| **2萬元／日** | 被羈押或恐怖分子留置 |
| **5小時** | 延誤或留滯 5小時以上未滿1日，算1日 |
| **1個月** | 購物瑕疵請旅行社協助 |
| **1年** | 民法請求權時效（從旅遊終了起算） |
| **15日** | 消保法：業者處理申訴的期限 |
