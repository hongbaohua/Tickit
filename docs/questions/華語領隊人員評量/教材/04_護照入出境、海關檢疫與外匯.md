# 華語領隊人員評量：新手教材
## 第四章　護照入出境、海關檢疫與外匯

**對應單元：04 法規 護照入出境、海關檢疫與外匯**｜**每年約 14 題**

照「出國 → 回國」的順序讀：出國前辦護照、役男申請出境 → 去目的地（簽證） → 帶錢（外匯） → 回國過海關（免稅額、檢疫）。

---

## 第一部分　護照與簽證

### 一、護照效期與換發（護照條例）

| 情況 | 效期 |
|---|---|
| 一般（**14歲以上**） | **10年** |
| 未滿14歲 | 5年 |
| **遺失補發** | **5年**（未滿14歲遺失補發 **3年**）；例：25歲第一次申請10年，遺失補發只有5年 |

- 護照效期**不得延期**，到期要換新。
- **應換發**：中文姓名變更、資料頁記載事項變更、相貌變更與照片不符、護照內頁加蓋圖戳、取得國民身分證統一編號等。
- 施行細則：空白內頁不足可**加頁一次**；中文姓名**不得加列別名**；本人簽名，無法簽名可用**指印**。
- 出國時護照效期至少要剩 **6個月**（國際慣例）。

### 二、國外遺失護照
1. 先向**當地警察機關**報失，取得報案證明
2. 向我國**駐外館處**申請補發；急著回國可申辦「**入國證明書**」返臺
3. 在**大陸**遺失：沒有駐外館處，搭機前約2天帶身分證明、報案證明、臺胞證，洽**出發地機場的航空公司**協助，向**移民署**申請返臺

### 三、役男出境
- **役男**：19歲當年1月1日起，至36歲當年12月31日止，尚未服役者
- 出境要**事先申請核准**（可線上申請）；未經核准擅自出境會被列管、限制出境
- **接近役齡**男子（未滿19歲）出國**不用**核准
- 出境就學、僑民役男：向**移民署**申請
- 在國外因重病、意外不能如期返國：延期**每次不得逾2個月**

### 四、簽證與入境
- 臺灣人去大陸：用「**臺灣居民來往大陸通行證**」（臺胞證）
- **申根區**免簽：任何 **180天**內停留合計不超過 **90天**
- 韓國觀光免簽：**90日**
- **電子簽證**：線上申請，不用送護照，但仍要審核（不能免審核）
- 自動查驗通關（e-Gate）：外國人只有航空公司貴賓卡**不能**申請
- 有戶籍國民入國：只要**有效護照**

## 第二部分　海關與檢疫（回國時）

### 五、免稅額與菸酒

| 項目 | 規定 |
|---|---|
| 行李物品**免稅額** | 完稅價格 **35,000元** |
| 菸酒年齡 | **酒18歲、菸20歲**（112年起） |
| **免稅**菸 | 捲菸 **200支**、或雪茄 **25支**、或菸絲 **1磅** |
| **免稅**酒 | **1.5公升** |
| 攜帶**上限**（超過不得帶） | 捲菸 1,000支、雪茄125支、菸絲5磅；酒5公升 |
| 自用**非處方藥** | 每種12瓶，合計不超過 **36瓶** |

- 超過免稅量 → 走**紅線檯**申報，扣掉免稅量後課稅。

### 六、錢與貴重物品要申報的門檻

| 物品 | 超過多少要申報 |
|---|---|
| **外幣**現鈔 | 等值 **1萬美元** |
| **新臺幣** | **10萬元** |
| **人民幣** | **2萬元**（超過部分封存，出境再帶走） |
| 有價證券 | 等值1萬美元 |
| **黃金** | 總值逾 **2萬美元**：要向經濟部國際貿易署申請輸入許可並報關（1萬美元的黃金可以走綠線） |
| 其他有洗錢之虞物品 | 總值逾 **50萬元**（不包括黃金，黃金另有規定） |

- 沒申報或申報不實：**超過申報的部分沒入**。

### 七、動植物檢疫
- **肉製品**一律不能帶，包括**泡麵裡的肉類調理包**；蔬菜、蝦味乾燥調理包可以帶
- 從非洲豬瘟疫區帶豬肉產品：第一次就罰 **20萬元**
- 從口蹄疫等疫區**擅自輸入**禁止的檢疫物：**7年以下**有期徒刑
- 活動物：**寵物鼠**即使檢疫合格也不能隨身帶
- 活植物不符規定：**退運或銷燬**，不能「重新申請」
- 種子、種球限量規定不同，不是都限3公斤

### 八、搭機安全規定（連到第六章）
- 三腳架：收合後超過 **60公分**要託運
- **水銀溫度計**：不得攜帶
- 外籍旅客退稅：從**購買之日**起算期限

## 第三部分　外匯

### 九、管理外匯條例
- **外匯**＝外國貨幣、票據、有價證券（**黃金、白銀、國際信用卡、飾金**都不算）
- 行政主管機關：**財政部**；掌理外匯業務：**中央銀行**
- 新臺幣 **50萬元**以上等值外匯收支，要申報，辦法由**中央銀行**定
- 非法買賣外匯為常業：**3年以下**有期徒刑
- 外幣收兌處遇疑似洗錢：向**法務部調查局**舉報

### 十、匯率怎麼看（每年一題）
銀行牌告都是「**銀行的角度**」：
- **銀行買入**（低）：旅客**賣**外幣給銀行時用
- **銀行賣出**（高）：旅客**買**外幣時用
- 例：美金買入29.81／賣出30.48 → 旅客買1美元要付 **30.48** 元（不是29.81）
- **現鈔**用「現金匯率」，**旅行支票**用「即期匯率」
- 買賣價差不是固定不變的
- **信用卡**國外消費：以商店向銀行**請款日**的匯率計算

### 十一、旅行支票
- 買到時**立即在上款簽名**，使用時才在下款**副署**（不是背面背書）
- 支票號碼和使用紀錄要與支票分開存放

### 十二、偽鈔
- 銀行發現偽造外幣：當面說明；持兌人不同意截留時，要記下持兌人身分資料並報警（不論金額多少）
