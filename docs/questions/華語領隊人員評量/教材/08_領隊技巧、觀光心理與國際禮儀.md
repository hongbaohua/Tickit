# 華語領隊人員評量：新手教材
## 第八章　領隊技巧、觀光心理與國際禮儀

**對應單元：08 實務 領隊技巧、觀光心理與國際禮儀**｜**每年約 18 題（技巧心理 12＋禮儀 6）**

這章最多「情境題」：題目描述一個帶團狀況，問最適當的作法。判斷原則只有三條：
1. **團員安全第一**
2. **誠實說明、先安撫情緒、再解決問題**
3. **事前預防優於事後補救**（事先確認、事先告知、事先約定）

## 第一部分　帶團流程與技巧

### 一、行前
- **行前說明會**：說明行程、班機時間、天氣、**當地風俗和法律**、安全注意事項
- 綜合、甲種旅行社出國團：成行前要書面說明旅遊安全或辦說明會
- 規劃行程最重要的考量：**顧客的需求和喜好**

### 二、飯店
| 名詞 | 意思 |
|---|---|
| **EP**（European Plan） | 只有住宿，**不含餐** |
| **CP**（Continental Plan） | 含歐陸式早餐 |
| **AP**（American Plan） | 含三餐 |
| **MAP**（Modified American Plan） | 含早餐＋一餐 |
| **Connecting Room** | 兩間房中間**有門相通**，適合親友 |
| Adjoining Room | 相鄰但沒有門相通 |
| Twin／Double | 兩張床／一張大床 |
| **Wake-up call** | 晨喚（請總機叫醒） |

- **Check-in** 要宣布：集合時間、早餐時間地點、領隊房號、緊急聯絡方式、飯店設施；在英國等地「大廳樓層是 G 或 0」（不是 1）
- **Check-out** 順序：②確認房帳、個人消費已付清 → ③清點團體行李件數 → ④交還房卡 → ①最後提醒團員帶齊個人物品、確認大行李上車
- 房間空調壞、有菸味：請領隊跟飯店反映換房

### 三、餐食
- 訂餐要告知：團名、人數、**特殊飲食需求人數**（素食、糖尿病等）、餐標、抵達時間
- 抵達餐廳沒位子（領隊沒再確認）：**誠懇道歉** → 先安置團員休息 → 協調餐廳加快 → 準備**備案餐廳**
- 餐廳在巷弄難找：領隊先熟悉位置和**附近明顯地標**，告訴團員

### 四、購物與自費行程
- 不得臨時安排購物，除非旅客要求或同意
- 旅客不想進店，**可以不進去**（不能強迫）
- 購物瑕疵：受領後 **1個月內**請旅行社協助
- 危險性自費行程：事先**告知危險性**，由旅客自己決定
- 歐洲退稅：各國退稅門檻**不一樣**

### 五、與國外代理商合作
- **Working Itinerary**：國外代理商提供的工作行程表，照表執行；表上**註明不含**的費用（例如城市稅）**不能**先墊付再向代理商請款

### 六、解說導覽技巧
- 吸引注意：互動、提問、說故事（**不是**單一講述事實）
- **兒童**：注意力時間**短**，解說要短、要有趣
- 年長者：放慢速度、注意體力、音量清楚

### 七、觀光心理學
- **消費者決策五階段**：問題認知 → **資訊蒐集**（聽親友推薦、看網路評價）→ 替代方案評估 → 購買決策 → 購後行為
- 處理客訴：傾聽、同理、道歉、提出方案、追蹤

### 八、常見情境（選最合理的）

| 情境 | 最合適作法 |
|---|---|
| 郵輪因天候不能靠岸，團員抱怨 | **誠實說明**、安撫情緒、協調後續行程 |
| 飯店少訂兩間房 | 領隊出面協調；不能叫會外語的團員自己去處理 |
| 地震等天災致交通中斷 | 帶團撤離到安全區，通報旅行社與駐外館處 |
| 旅行社疏失（沒辦好簽證），團員被拒入境 | 安排到下一站會合或返國，**費用旅行社負擔** |

## 第二部分　國際禮儀（食衣住行育樂）

### 九、食
**西餐**
- 從椅子**左側**入座
- **麵包在左、飲料在右**（左麵包、右水杯）
- 杯子由左至右：水杯、紅酒杯、白酒杯（都在右上方）
- 餐巾：用餐中暫時離席 → 放**椅子上**；用餐結束 → 放**桌上**
- 刀叉**由外往內**取用
- 餐具掉了：**請服務生換新**，不要自己撿起來繼續用

**英式下午茶**（三層架）
- 下層：**三明治**（鹹） → 中層：**司康** → 上層：**甜點、水果塔**
- 吃法：**由下往上**

**其他**
- 在印度、中東：用**右手**拿食物、遞東西（左手被視為不潔）

### 十、衣
| 場合 | 服裝 |
|---|---|
| 大禮服（燕尾服） | **白**領結 |
| 小禮服（無尾晚禮服 Tuxedo） | **黑**領結 |

### 十一、住、行（位次：**右為尊**）
- **宴會座次**：男女主人相對；**男主賓坐女主人右側、女主賓坐男主人右側**
- **乘車**：
    - 有司機開車：**後座右側**為尊
    - 主人親自開車：**副駕駛座**為尊
    - 九人座小巴：**司機後面一排最右邊靠門**的位子為尊
- **電梯**：無人操作時，位低者先進後出；有人操作時，尊者先進先出
- **國旗**：在本國，**主辦國國旗居中**（或首位），其他國家依**英文字母**順序排兩側

### 十二、社交
- **介紹順序**（先介紹「較不尊」的那一方）：
    - 男士介紹給女士
    - 年少者介紹給年長者
    - 位低者介紹給位高者
    - 未婚者介紹給已婚者
    - 被介紹時，除了女士和長者，都應起立
- **名片**：**位低者先遞**給位高者；雙手遞、字朝對方
- **握手**：女士、長者、位高者先伸手
- 酒會、茶會：主人在賓客間寒暄；賓客早退可以不用告知主人；主人在出口送客；不要在接待線上和主人長談
- 演奏國歌時，文職官員行**扶手禮**
- 「入境問俗、入國問禁、入門問諱」出自《**禮記**》
- 高爾夫：果嶺上不要踩其他球員的推桿線
