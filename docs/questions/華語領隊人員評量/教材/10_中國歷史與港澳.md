# 華語領隊人員評量：新手教材
## 第十章　中國歷史與港澳

**對應單元：10 資源 中國歷史與港澳**｜**觀光資源科「中國大陸與港澳」每年約 15 題，其中歷史約一半**

觀光資源科不考你背年代，考的是「**景點背後的歷史**」：這座建築是哪個朝代、這個習俗怎麼來的、這條路誰走過。所以本章用「朝代 → 代表人物與景點」的方式整理，帶團解說時也用得上。

### 一、朝代總表（先背順序）

### 二、宗教與思想
- **儒家**：孔子；漢武帝起成為正統
- **道教**：本土宗教；「**功過格**」＝道教徒記錄善惡、自我約束的方法
- **佛教**：東漢傳入；石窟藝術；「種福田」＝誠心行善，未來就能得到福報
- **伊斯蘭教**：唐宋海上貿易傳入；泉州**清淨寺**是**清真寺**
- **天主教**：明朝晚期**耶穌會**來華（利瑪竇）

### 三、絲路與中亞
- **絲綢之路**：西安、洛陽 → 河西走廊（酒泉、敦煌、**玉門關**、陽關）→ 中亞 → 西亞
- 酒泉等河西綠洲：靠**高山融雪**灌溉
- 中亞史：阿拉伯人統治後大量翻譯**希臘文**著作；13世紀**蒙古人**西征屠城；馬可波羅時代中亞由蒙古統治；20世紀屬蘇聯，所以四十幾歲以上的人都會說**俄語**
- **茶馬古道**：西南地區（雲南、四川 → 西藏）的商貿通道

### 五、香港
- 範圍：香港島、九龍半島、**新界**及附屬島嶼
- 國際金融與貿易中心；維多利亞港夜景（世界三大夜景之一）
- 夜遊：維港、太平山頂、幻彩詠香江
- **港珠澳大橋**（2018 完工）：連接**香港、澳門、珠海**

### 六、澳門
- 16世紀中葉葡萄牙人取得居住權，東西方交流的門戶
- **澳門歷史城區**：2005年列入世界文化遺產，包括**大三巴牌坊**（聖保祿教堂遺址，**天主教**）、議事亭前地、媽閣廟等
- 經濟以**博弈觀光**為主
- 交通政策「公交優先、綠色出行」：減少車流，保護歷史城區

### 七、中國城市發展口訣
「**十年看深圳、百年看上海、千年看北京、三千年看西安**」
- 深圳：改革開放經濟特區
- 上海：開埠後的近代大城
- 北京：元明清首都
- 西安：周秦漢唐古都

**五大古都**（西安、洛陽、南京、開封、北京）大多分布在**黃河**流域及附近。

### 八、建築與文化
- **北京故宮**：世界現存規模最大的木結構宮殿建築群
    - 中軸線**由北到南**：保和殿 → 中和殿 → 太和殿 → 午門
- **明十三陵**是明朝皇陵（不是清朝）；清朝皇陵是清東陵、清西陵
- 越南**順化皇城**模仿北京紫禁城
- **四大石窟**（依年代）：**敦煌莫高窟** → 天水麥積山 → 大同**雲岡** → 洛陽**龍門**
- **江南三大名樓**：湖北**黃鶴樓**、湖南**岳陽樓**、江西**滕王閣**
- **四大名園**：蘇州**拙政園**、蘇州**留園**、北京**頤和園**、承德**避暑山莊**
- **承德**：皇家園林＋外八廟，清朝與蒙古、西藏交流的地方
- **淮揚菜**：明清時揚州是**鹽商**聚集地，菜色精緻
- 天花（痘瘡）：清**順治**皇帝、法王路易十五都死於這種病
- 《**山海經**》：先秦古籍，記載山川、異獸、邦國
