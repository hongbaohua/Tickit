# 華語領隊人員評量：新手教材
## 第十一章　中國地理與世界遺產

**對應單元：11 資源 中國地理與世界遺產**

地理題的典型問法是「**某種景觀或民居，是因為什麼地形氣候形成的**」。只要記住「地形 → 氣候 → 生活方式 → 景點」這條因果線，大部分題目都能推出來。

---

### 一、地形骨架
- 地勢**西高東低**，分三級階梯：青藏高原（第一級）→ 高原盆地（第二級）→ 東部平原丘陵（第三級）
- **四大高原**：**青藏**（世界屋脊）、**內蒙古**、**黃土**（窯洞）、**雲貴**（喀斯特）
- **四大盆地**：塔里木、準噶爾、柴達木、**四川**（天府之國）
- **三大平原**：東北、華北、長江中下游

### 二、河流
| 河流 | 重點 |
|---|---|
| **長江** | 最長；三峽；中下游是「魚米之鄉」 |
| **黃河** | 流經黃土高原，含沙量大；古都多在黃河流域 |
| **珠江** | 華南 |
| **黑龍江** | 東北流路最長；最大支流**松花江**（滿語 sunggari ula，意思是天河） |
| **瀾滄江** | 雲南，流經**西雙版納**，出境後叫**湄公河** |

### 三、地形景觀（每年必考）

| 地貌 | 成因 | 代表景點 |
|---|---|---|
| **喀斯特**（石灰岩溶蝕） | 石灰岩被雨水溶蝕 | **桂林、陽朔**（「桂林山水甲天下」）、雲南**石林**、貴州**黃果樹瀑布**（打幫河）、**九寨溝**；越南**下龍灣**（水上桂林）也是 |
| **鈣華** | 含鈣的水沉澱堆積 | 四川**黃龍**（3,400多個鈣化彩池） |
| **丹霞地貌、砂岩峰林** | 紅色砂岩、石英砂岩侵蝕 | 湖南**張家界**（武陵源） |
| **花崗岩** | | 安徽**黃山**（奇松、怪石、雲海、溫泉） |
| **斷層陷落湖** | 地殼斷裂下陷 | 雲南**洱海**（大理「風花雪月」之洱海月） |
| **乾燥綠洲** | 高山融雪＋地下水 | 新疆**吐魯番**（火州，**坎兒井**引地下水：豎井、暗渠、明渠、澇壩四部分）、河西走廊 |

- 「看山張家界、看水九寨溝」

### 四、氣候與生活
| 地區 | 氣候 | 生活景觀 |
|---|---|---|
| 東北 | 寒冷 | **哈爾濱**國際冰雪節 |
| 華北（河北、山東） | 溫帶 | 溫室等**技術革新、克服氣候限制**→成為重要蔬果產地 |
| 華南 | **多雨潮溼** | **騎樓、高腳屋** |
| 雲南西雙版納 | 熱帶季風雨林 | 「孔雀之鄉」；**傣族潑水節** |
| 海南島 | 熱帶季風 | 海島度假 |
| 新疆 | 乾燥 | 瓜果之鄉、綠洲農業 |
| 青藏高原 | 高寒 | 可可西里保護**藏羚羊** |
| 東北溼地 | | **丹頂鶴**棲息在沼澤（如黑龍江扎龍） |

### 六、名山
- **五嶽**：東嶽**泰山**（山東）、西嶽**華山**（陝西）、南嶽**衡山**（湖南）、北嶽**恆山**（山西）、中嶽**嵩山**（河南，少林寺）
- **三山**：**黃山**、**廬山**、**雁蕩山**
- **佛教四大名山**：
    - **五臺山**（山西）— 文殊菩薩
    - **峨眉山**（四川）— 普賢菩薩
    - **普陀山**（浙江）— 觀音菩薩
    - **九華山**（安徽）— 地藏菩薩

### 八、中國的世界遺產（常考的）
| 類別 | 遺產 |
|---|---|
| 皇家 | 北京故宮、天壇、頤和園、**明清皇家陵寢**、承德避暑山莊、**北京中軸線** |
| 古城、古村 | **平遙古城**（山西，清代票號「匯通天下」）與**麗江古城**（1997年一起列入）、皖南古村落（宏村、西遞）、**福建土樓**、開平碉樓、**鼓浪嶼** |
| 宗教、石窟 | **莫高窟**、雲岡、龍門、大足石刻、武當山、**曲阜三孔**、五臺山、布達拉宮 |
| 自然 | 黃山、九寨溝、黃龍、**武陵源**、**三江併流**（金沙江、瀾滄江、怒江；中國面積最大的世界遺產，位於湄公河等東南亞河流上游）、**可可西里**、梵淨山 |
| 混合（文化＋自然） | 泰山、黃山、峨眉山－樂山大佛、武夷山 |
| 線性、跨國 | **絲綢之路**（2014，長安－天山廊道）、**大運河**（2014） |
| 其他 | 杭州**西湖**、蘇州古典園林、**揚州瘦西湖**（屬大運河）、**澳門歷史城區**（2005）、良渚古城、泉州（2021）、都江堰－青城山 |
