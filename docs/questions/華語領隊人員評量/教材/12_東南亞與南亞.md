# 華語領隊人員評量：新手教材
## 第十二章　東南亞與南亞

**對應單元：12 資源 東南亞與南亞**｜**新制每年約 12 題（比舊制多一倍，是華語卷的第二大主題）**

東南亞題目只要抓三條線就能串起來：**宗教**（印度教、佛教、伊斯蘭、天主教從哪裡來）、**殖民**（誰統治過誰）、**華人**（移民與文化融合）。

---

### 一、國家總表

| 國家 | 首都 | 主要宗教 | 殖民者 | 必記景點 |
|---|---|---|---|---|
| **泰國** | 曼谷 | 上座部佛教 | **從未被殖民** | 大城（阿瑜陀耶）、素可泰、清邁、普吉、**蘇梅島**、**美斯樂**（雲南孤軍後裔種茶） |
| **越南** | 河內 | 大乘佛教（**漢字文化圈**） | **法國** | **下龍灣**（喀斯特，自然遺產）、**會安**古城、**順化**皇城（仿紫禁城）、**河內升龍皇城**、峴港巴拿山「黃金橋」 |
| **柬埔寨** | 金邊 | 上座部佛教 | **法國** | **吳哥窟**（國旗圖案；先**印度教**後**佛教**） |
| **寮國** | 永珍 | 上座部佛教 | **法國** | **龍坡邦**（殖民建築與傳統寺廟並存，世界遺產） |
| **緬甸** | 奈比多 | 上座部佛教 | 英國 | 蒲甘、仰光大金塔 |
| **馬來西亞** | 吉隆坡 | **伊斯蘭教** | 英國 | **雙子星塔**（伊斯蘭八角星造型）、**麻六甲**與**檳城喬治市**（殖民建築，世界遺產） |
| **新加坡** | 新加坡 | 多元（華人為主） | 英國 | 牛車水、植物園 |
| **印尼** | 雅加達 | **伊斯蘭教**（人口最多的伊斯蘭國家） | **荷蘭** | **婆羅浮屠**（**佛教**）、普蘭巴南（印度教）、**峇里島**（**印度教**） |
| **菲律賓** | 馬尼拉 | **天主教** | **西班牙**→美國 | **巴拿威梯田**（伊富高族開墾） |
| 汶萊 | 斯里巴卡旺市 | 伊斯蘭教 | 英國 | |

- **法屬印度支那**：越南、柬埔寨、寮國
- 「**千島之國**」：印尼、菲律賓
- 東南亞人口最多：**印尼**
- **龍目島**（峇里島旁邊）：居民主要信**伊斯蘭教**
- **巴達維亞**＝今天的**雅加達**（1619年荷蘭東印度公司據點）
- **麥哲倫**1521年抵達菲律賓，之後西班牙統治300多年
- 越南**胡志明市**原名**西貢**
- 越南河內**升龍皇城**建在中國**唐代安南都護府**的堡壘原址上

### 二、會安古城（近年熱門）
- 15～19世紀的貿易港，街景融合**中式、日式、法式**建築
- 能完整保存的原因：19世紀河道淤積，港口沒落、沒有被現代化開發

### 三、華人在東南亞
- **峇峇娘惹**（土生華人）：15～17世紀華商與當地女子通婚形成的族群，男稱峇峇、女稱娘惹；「三代成峇」
- 新加坡：華人為主；**大寶森節**（印度教徒苦行繞境，以鐵鉤穿過皮膚）
- 印尼蘇哈托「新秩序」時期：限制華文教育、華人姓名、華人節慶（**沒有**限制華人從商）
- 越南華人集中在**胡志明市**（堤岸）

### 四、河川
- **湄公河**：流經**6國**（中國、緬甸、寮國、泰國、柬埔寨、越南），水資源衝突最多；上游在中國叫**瀾滄江**

### 五、時區
- 理論上每15度一時區，但各國自訂；新加坡、馬來西亞理論上屬UTC+7，實際用 **UTC+8**

### 六、南亞
| 國家 | 重點 |
|---|---|
| **印度** | **印度河文明**（城市規劃、排水系統）；印度教、佛教發源地；**泰姬瑪哈陵**（伊斯蘭建築）；英屬印度1947年分治為印度和巴基斯坦（印度教 vs 穆斯林）；旅遊最佳季節為**10月～3月乾季** |
| **尼泊爾** | 藍毗尼（佛陀誕生地）、加德滿都 |
| **斯里蘭卡** | 上座部佛教 |
| **不丹** | 國民幸福指數 |
| **馬爾地夫** | 伊斯蘭國家；**不屬於南島文化** |

### 七、佛教傳播（串聯第十章、第十三章）
- 印度 → 中國（東漢傳入、**玄奘**唐朝西行取經）→ 朝鮮（新羅「九山禪門」）→ 日本（**鑑真**東渡）
- 上座部（南傳）：斯里蘭卡、泰、緬、柬、寮
- 大乘（北傳）：中國、越南、韓國、日本
