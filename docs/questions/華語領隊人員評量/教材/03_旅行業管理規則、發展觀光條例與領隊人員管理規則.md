# 華語領隊人員評量：新手教材
## 第三章　旅行業管理規則、發展觀光條例與領隊人員管理規則

**對應單元：03 法規 旅行業、發展觀光條例與領隊規則**｜**每年約 13 題**

三部法規的關係：

| 法規 | 位階 | 管誰 |
|---|---|---|
| **發展觀光條例** | 法律（母法，最新修正114年11月28日） | 整個觀光產業：旅行業、旅館、民宿、導遊、領隊；**罰則都在這裡** |
| **旅行業管理規則** | 命令（最新修正115年9月18日） | 旅行社怎麼設立、怎麼經營 |
| **領隊人員管理規則** | 命令（最新修正115年10月7日） | 領隊怎麼取得資格、怎麼執業 |

- 主管機關：中央為**交通部**，執行機關為**交通部觀光署**（112年9月由「觀光局」改制）。
- 舊考古題寫「觀光局」，新題目都寫「**觀光署**」。

> ⚠️ 旅行業管理規則115年9月大修，條號和部分金額（例如履約保證保險）都改了。113年以前考古題的金額可能是舊規定，**以本章為準**。

## 第一部分　旅行業管理規則

### 一、旅行社三種類

| | 綜合 | 甲種 | 乙種 |
|---|---|---|---|
| 業務範圍 | 國內外，可**批發**、委託甲乙種代招攬 | 國內外，**自己招攬自己出團** | **只做國內** |
| 實收資本額 | **3,000萬** | **600萬** | **120萬** |
| 每增設一家分公司增資 | 150萬 | 100萬 | 60萬 |
| 保證金 | **1,000萬** | **150萬** | **60萬** |
| 分公司保證金（每家） | 30萬 | 30萬 | 15萬 |
| 註冊費 | 資本總額 **1/1000**（分公司按增資額 1/1000） | 同左 | 同左 |

- 「以包辦旅遊方式自行組團」、「委託甲乙種代招攬」是**綜合**旅行業才有的業務。
- **品保協會會員**且最近2年未受停業處分：保證金可按 **1/10** 繳納。
- 保證金以**銀行定存單**繳納；執照費 1,300元。
- 範例：綜合旅行業＋2家分公司保證金＝1,000萬＋30萬×2＝**1,060萬**。
- 範例：甲種資本額1,000萬、增設1家分公司（原資本已夠，不用增資）→ 註冊費 1萬元，總公司保證金 150萬元。

### 二、保險（每年必考）

**責任保險**（保旅客出事）：

| 項目 | 金額 |
|---|---|
| 意外**死亡** | 最低 **250萬**、最高 500萬（舊規定200萬） |
| 意外**體傷醫療** | 最低 **10萬**、最高 20萬 |
| 家屬赴海外處理善後 | **10萬**（國內旅遊 5萬） |
| **證件遺失**損害賠償 | **2,000元** |

**履約保證保險**（保旅行社倒閉、無法出團）：

| | 一般 | 品保協會會員 |
|---|---|---|
| 綜合 | **1億** | **8,000萬** |
| 甲種 | **3,000萬** | **1,500萬** |
| 乙種 | **1,600萬** | **800萬** |
| 每增設分公司 | 綜合甲種＋800萬、乙種＋400萬 | 綜合甲種＋400萬、乙種＋200萬 |

- 發展觀光條例規定：**只有旅行業**要同時投保責任保險和履約保證保險。
- 責任保險死亡給付的請求順位（發展觀光條例）：①**父母、子女、配偶** → ②**祖父母** → ③**孫子女** → ④**兄弟姊妹**。

### 三、經營規定

| 規定 | 數字或重點 |
|---|---|
| 出國團成行前 | 以書面向旅客說明**旅遊安全**或舉辦**說明會** |
| 出國團成行時 | **每團都要派領隊**全程隨團 |
| 旅遊契約保管 | 設專櫃保管 **1年** |
| 職員異動 | **10日**內報備 |
| 暫停營業1個月以上 | 停業日起 **15日**內報備；停業最長 **1年**，可展延 **1次**、1年為限 |
| 停業期滿 | **15日**內申報復業 |
| 緊急事故 | 事故發生後 **24小時**內向**觀光署**報備 |
| 代辦證照遺失 | **24小時**內向外交部領事事務局、警察機關或觀光署報備（移民署不是） |
| 航空票價、食宿行情 | **品保協會按季**發表 |
| 廣告 | 應載明公司名稱（甲乙種不可用商標代替）、註冊編號、行程名稱、出發地點日期天數、費用、責任保險與履約保證保險金額；**不能寫「僅供參考」**；不需要寫網址 |
| 指派或僱用人員的行為 | **推定**為該旅行社的行為 |
| 國外設分支機構 | 報**觀光署**備查 |

### 四、旅行業經理人資格（每年一題）

| 學歷 | 曾任 | 年資 |
|---|---|---|
| **大專以上**（或高考及格） | 旅行業代表人 | **2年** |
| 〃 | 海陸空客運業務單位主管 | 3年 |
| 〃 | 旅行業**專任職員** / 領隊導遊 | **4年** / **6年** |
| **高中職** | 代表人 / 專任職員 / 領隊導遊 | 4年 / **6年** / 8年 |
| 不限 | 旅行業專任職員 | 10年 |

- **觀光科系畢業**：第2～4款的年資可**減1年**。
- 例：大學觀光科系＋專任職員 → 4−1＝**3年**；高職觀光科＋專任職員 → 6−1＝**5年**。
- 經理人訓練合格後**連續3年**沒在旅行業任職，要重新受訓。

## 第二部分　發展觀光條例（罰則集中在這）

### 五、重要定義
- **旅行業**：經中央主管機關核准，為旅客設計安排旅程、食宿、領隊、導遊、代購代售客票、代辦簽證等服務而收取報酬的營利事業。
- **領隊人員**：引導**出國**觀光旅客團體旅遊業務並收取報酬。
- **導遊人員**：接待或引導**來本國**觀光旅客。
- 經營旅行業：向**中央觀光主管機關**申請執照。
- 民宿：向**縣市政府**申請登記。
- 自然人文生態景觀區：應設**專業導覽人員**；未申請專業導覽人員陪同進入，罰3萬元以下。

### 六、罰則對照表（背金額區間）

| 違規 | 罰鍰 |
|---|---|
| **沒有執業證**就當領隊、導遊 | **1萬～5萬**，並禁止執業 |
| 領隊、導遊**違反管理規則**（例如華語領隊帶日本團、擅離團體） | **3千～1萬5千**；情節重大可停止執業或廢止執業證 |
| 旅行社沒派合格領隊、沒和旅客簽**書面契約**、停業未報備 | **1萬～5萬** |
| 旅行社經營核准範圍外業務 | 3萬～15萬 |
| 旅行社**沒投保**責任險或履約險 | **3萬～50萬**，可立即停止出團業務，3個月內沒補就廢照 |
| **沒有執照**經營旅行業 | **10萬～200萬**，勒令歇業（舊規定10萬～50萬） |
| 沒執照卻刊登廣告 | 10萬～150萬 |
| 旅行社詐騙旅客、玷辱國家榮譽 | 3萬～15萬；重大者15萬～50萬 |
| 受停業處分**仍繼續營業** | **50萬以上**，廢止執照 |
| **損壞**觀光地區名勝、自然資源 | **50萬以下**＋回復原狀；無法回復再罰500萬以下 |
| 風景區強迫推銷、強行拍照收費、擺攤 | 1萬～5萬 |

**口訣：沒證1～5萬、有證違規3千～1萬5、沒照開業10萬～200萬。**

## 第三部分　領隊人員管理規則

### 七、執業範圍
- **華語領隊**：只能帶國人赴**香港、澳門、大陸**；**不得**帶出國團（日本、越南、泰國都不行）。
- **外語領隊**：出國＋港澳大陸都可以。
- 違反（華語領隊帶越南團）→ 依發展觀光條例罰 **3千～1萬5千**。

### 八、報考資格
- **高中職以上**畢業，或大專在學、肄業（五專限4年級以上）。
- **專用制**外語領隊：綜合、甲種旅行社現職人員，年資滿 **2年**，由公司推薦。
- 報名費 **1,300元**。

### 九、從評量及格到上路

| 步驟 | 數字 |
|---|---|
| 職前訓練期限 | **通用制、華語：3年內**（成績公布日起算滿3年之6月30日前）；**專用制：1年內**；產假重病可展延1年 |
| 職前訓練節數 | **56節**（每節50分鐘） |
| 已有華語領隊、再考上外語領隊 | 訓練**減半＝28節** |
| 已有外語領隊、再考上另一種外語領隊 | **免**訓練 |
| 缺課 | 不得超過 **1/10**；遲到早退逾10分鐘算缺課1節 |
| 測驗 | **70分**及格；不及格者 **7日內補考1次**；補考不及格不得結業 |
| 延期測驗 | 產假、重病等核准延期者，**1年內**申請測驗 |
| 結業證書費 | **500元**（補發相同） |
| 執業證費 | 申請、換發、補發都是 **200元** |
| 執業證效期 | **3年**，期滿前1年內換發 |
| 連續3年未帶團 | 重新參加訓練（**28節**）才能執業 |
| 被廢止執業證 | **5年**內不得當領隊 |

**退訓事由**：缺課逾1/10、對講座**強暴脅迫**、**冒名頂替**、文件**偽造變造**、品德操守違反倫理情節重大。
- 因強暴脅迫、冒名頂替、偽造文件被退訓：**2年內**不得再參加訓練。
- 產假、重病是正當事由，**不是**退訓事由。
- 訓練機構結訓後 **10日內**將成績陳報觀光署。

**口訣：56節、缺課1/10、70分、7天補考、證照3年、3年沒帶團重訓28節、吊照5年。**

### 十、執業規定
- 依旅行社安排的行程執業，非因不可抗力不得擅自變更。
- 執業證**佩掛胸前**明顯處。
- 發生特殊或意外事件 → **24小時內**向**受僱旅行社及觀光署**報備。
- **禁止行為**（第39條）：
    1. 旅客生病不照料、不注意旅客安全
    2. 誘導購物收**回扣**、額外需索、兜售或收購物品、**託旅客帶東西圖利**
    3. 執業證**借人**、無故延誤、委託他人代為執業、停止執業期間執業、擅自經營旅行業務
    4. **擅離團體**、擅自解散旅客、使用非法交通工具或設施
    5. **非經旅客請求**保管證照；經請求代為保管卻遺失
    6. 言行不當
- 第5款陷阱：**旅客請你保管證照是可以的**，沒請求就主動保管才違規。

### 十一、取得資格的順序
**評量及格 → 職前訓練 → 結業證書 → 受旅行社僱用或指派 → 請領執業證**
