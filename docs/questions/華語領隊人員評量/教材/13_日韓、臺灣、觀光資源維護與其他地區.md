## 第三部分　臺灣史地

### 三、臺灣歷史時間軸
| 時期 | 重點 |
|---|---|
| **荷蘭**（1624–1662） | 南部大員（安平）**熱蘭遮城**；傳教士用**西拉雅語**羅馬拼音寫「**新港文書**」 |
| **西班牙**（1626–1642） | 北部：雞籠（基隆和平島）**聖薩爾瓦多城**、淡水聖多明哥城 |
| **鄭氏**（1662–1683） | **沈光文**開館授徒，推動漢文化 |
| **清治**（1683–1895） | 移民諺語「唐山過臺灣，心肝結歸丸」；**牡丹社事件**（1874，最早最著名的外國武力入侵）；開港通商後**馬偕**等長老教會傳教士來臺 |
| **日治**（1895–1945） | 總督府進行漢人祖籍調查；臺灣作曲家**鄧雨賢**等；「第一憨，種甘蔗給會社磅」是**日治**時期的諺語 |
| **戰後** | **美援**（麵粉袋做的內褲）；**八二三砲戰**（1958，第二次臺海危機）；**鹿港反杜邦**（最早的環保抗爭）；解嚴 → 廢除動員戡亂臨時條款 → 首次總統直選 |

### 五、臺灣地理

## 第四部分　觀光資源維護

### 六、核心概念
- **承載量**：在不破壞資源的前提下，一個地方能容納的遊客量
    - **生態承載量**：以自然環境**不退化**為前提
    - 實質（空間）承載量、社會（心理）承載量、設施承載量
- **世界遺產**：UNESCO 1972年《世界遺產公約》；分**文化、自然、複合**三類；另有「瀕危名錄」
- 跨國世界遺產：例如**西班牙聖地牙哥朝聖之路**、絲綢之路
- **無痕山林**（LNT）：垃圾**帶下山**，不就地掩埋
- **氣候變遷**：海平面上升、冰川消退、珊瑚白化 → 觀光資源長期流失
- 保護區例子：青海**可可西里**保護**藏羚羊**；三江併流

### 七、國外旅遊警示（外交部）
- **灰色**提醒注意 → **黃色**特別注意 → **橙色**避免非必要旅行 → **紅色**不宜前往
