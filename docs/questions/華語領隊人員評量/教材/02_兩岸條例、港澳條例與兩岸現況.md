# 華語領隊人員評量：新手教材
## 第二章　兩岸條例、港澳條例與兩岸現況

**對應單元：02 法規 兩岸條例與港澳條例**｜**每年約 9 題**

華語領隊只能帶大陸、港澳團，所以這章是華語領隊的「本行」。題目分三類：**法條**（兩岸條例、港澳條例）、**機關**（誰管什麼）、**時事**（旅遊警示、兩岸協議、政府政策）。

---

### 一、先搞懂名詞

| 名詞 | 意思 |
|---|---|
| **臺灣地區** | 臺灣、澎湖、金門、馬祖及政府統治權所及之其他地區 |
| **臺灣地區人民** | 在臺灣地區**設有戶籍**的人民 |
| **大陸地區人民** | 在大陸地區設有戶籍的人民。大陸人旅居國外、取得外國籍，來臺觀光仍以**大陸地區人民**身分申請 |
| **兩岸條例** | 全名「臺灣地區與大陸地區人民關係條例」，**民國81年**施行，規範兩岸關係的主要法律 |
| **港澳條例** | 全名「香港澳門關係條例」 |

**身分判斷題：**
- 大陸出生、父母都是大陸人，經許可來臺**定居並設戶籍** → 變成臺灣地區人民
- 大陸出生、父母一方是臺灣人 → **出生後1年內**在臺設戶籍，才是臺灣地區人民
- 臺灣人**在大陸設戶籍或領用大陸護照** → 喪失臺灣身分，由戶政機關**註銷臺灣戶籍**
    - 「設有戶籍」＝持有**大陸居民身分證及定居證**

### 二、誰管什麼（機關題）

| 事務 | 機關 |

**口訣：陸委會統籌、海基會辦事、內政部管人、外交部管國外警示。**

### 三、兩岸條例常考條文

#### 3-1　臺灣人去大陸
- 禁止事項：不得在大陸**設戶籍、領大陸護照**；不得擔任中共黨政軍機關職務
- **公務員**赴陸交流：遇到中共旗、歌、政治人物圖像時，**不得**舉手致敬、鞠躬或合唱
- 遇重大突發事件，可經**立法院**議決，由行政院公告限制人民赴陸；立法院**1個月**內未決議視為同意
- 大陸的出版品、電影、節目，**不能**因為大陸審批通過就直接在臺發行播映（要依我方規定許可）
- 廣告：不得為中共從事具政治性目的之宣傳

#### 3-2　大陸人來臺
- 採**事前許可制**
- 大陸人來臺觀光：除**個人旅遊**外，須由旅行社組團，**團進團出**，每團 **5人以上40人以下**
- 金馬澎小三通：大陸民眾組團到金門，最低 **3人**
- 大陸觀光客**逾期停留且行方不明**：旅行社**每1人扣繳保證金5萬元**
- 大陸人來臺**打工**是違法的（雇主也違法）
- 有危害國安或社會安定之虞：**移民署**可逕行強制出境
- 保證人沒協助強制出境，要負擔強制出境費用

#### 3-3　大陸配偶與定居
- 依親居留滿 **4年**、每年居住逾 **183日** → 可申請長期居留
- 大陸人在臺設籍後，擔任公職等須設籍滿 **10年**

#### 3-4　民事
- 行為地或事實發生地跨兩岸 → 以**臺灣地區**為行為地
- 兩岸人民結婚的方式 → 依**行為地**規定
- 大陸人繼承臺灣人遺產 → 繼承開始起 **3年內**，以書面向法院表示，逾期視為拋棄

#### 3-5　錢
- **人民幣**入出境限額 **2萬元**（不計入其他外幣額度）
    - 超過2萬要申報，超過的部分**封存**在海關，出境時再帶走
    - **申報不實**：超過申報的部分**沒入**
- 大陸資金：從大陸匯來、在大陸的人或公司（含其海外分公司）匯來的，都算大陸資金
- 人民幣代碼 **CNY**（ISO 4217）
- 「幣券」包括紙幣、硬幣、紀念幣，**不包括虛擬貨幣**

#### 3-6　罰則
- 大陸船舶越界捕魚：船長罰 **30萬～1,000萬元**

### 四、港澳條例
- **香港**＝香港島、九龍半島、**新界**及附屬部分
- 港澳情況變化危害臺灣安全時，行政院得**停止**港澳條例一部或全部適用
- 港澳居民在臺投資 **600萬元**以上，可申請居留
- 港澳法律禁止攜帶的管制物品（如電子菸等）要注意；**自拍棒不在禁止之列**
- 澳門**大三巴牌坊**屬「澳門歷史城區」，**已列世界遺產**

### 五、兩岸協議與事件（時事題）

| 協議或事件 | 重點 |
|---|---|
| **金門協議**（民國79年） | 兩岸紅十字會簽署，處理**偷渡犯、刑事犯遣返**；是兩岸遣返偷渡犯最早的依據 |
| **海峽兩岸共同打擊犯罪及司法互助協議** | 雙方即時**通報人身自由受限**訊息 |
| **兩岸避免雙重課稅協議** | 已簽署、**尚未生效** |
| **兩岸旅遊協議** | 大陸由**海旅會**聯繫實施 |
| 國際賽事 | 採「**奧會模式**」 |
| 小三通航線 | 金門－廈門、金門－泉州、馬祖－福州（**馬祖－湄洲**不是） |

### 六、政府政策與安全提醒
- **旅遊警示**：113年6月27日起，赴中國大陸及港澳為**橙色**警示，主因是臺灣民眾赴陸後**人身自由受限或遭拘留**
- 赴陸安全登錄系統：陸委會、海基會、外交部、觀光署都有提供登錄或通報（**法務部沒有**「赴陸期間司法案件協助登錄系統」）
- **反滲透法、國安五法**：不包括國家安全會議組織法
- 三道防護網（108年元旦談話）：民生、資安、民主防護網（**沒有**文化防護網）
- 臺灣不承認「兩制臺灣方案」；我方主張**海峽中線存在**

### 七、在大陸出事怎麼辦（連到第七章緊急事件）
- **護照遺失**：在大陸不能找我國駐外館處（沒有），帶身分證明、遺失報案證明、**臺胞證**等，搭機前約 **2天**洽**出發地機場的航空公司**協助，向**移民署**申請返臺
- **醫療**：在大陸臨時就醫，**出院日起6個月內**向健保署申請核退
- 大陸法定受益人申請保險死亡給付：檢附身分證明、親屬關係證明等（不用健康證明）
