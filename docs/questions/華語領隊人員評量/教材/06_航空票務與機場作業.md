# 華語領隊人員評量：新手教材
## 第六章　航空票務與機場作業

**對應單元：06 實務 航空票務與機場作業**｜**每年約 11 題**

這章名詞多，但都是領隊每天會碰到的事：訂位 → 開票 → 報到 → 安檢 → 搭機 → 轉機 → 領行李。考題大多是「**代碼對應**」和「**時差計算**」，背熟就能拿分。

### 四、票種與票價
- **GV10、GV15**：團體票，數字是最低人數（GV15＝至少15人）
- **IT**：旅遊團體套裝票（Inclusive Tour）；例：IT8CX3PG43 → CX 國泰
- **Sub-load（Subject to Load）**：**限空位**搭乘的票
- **APEX**：預購票；YLAP21 ＝ Y艙、L淡季（Low）、**出發前21天購票**（不是限21人）
- **嬰兒**（未滿2歲）：成人票10%、不占位；一個大人帶**第二個嬰兒**，第二個要買**兒童票**（不是成人票）
- 嬰兒途中滿2歲：依開票航空公司規定處理
- **里程計價**：TPM（實際里程）÷ MPM（最高允許里程）
    - 超過的部分加收 **EMS**（超哩數附加），上限 **25%**；商數超過 **1.25** 改分段計價
    - **EMA**：經過特定城市時給的哩程寬減
- **LCC**（廉價航空）：主要在**官網**賣票

### 六、時差計算
1. 把出發、抵達時間都換成 **GMT**（減掉時區）
2. 相減就是飛行時間
- 例：臺北 2/8 23:25（GMT+8）→ 羅馬 2/9 07:15（GMT+1）
    - 出發 GMT：23:25−8 ＝ 2/8 15:25
    - 抵達 GMT：07:15−1 ＝ 2/9 06:15
    - 飛行時間 ＝ **14小時50分**
- **國際換日線**：大致沿180度經線，但**不是直線**（為了避開國家而彎曲）；向東越過減一天、向西越過加一天
- 美國本土有**4個時區**
- 時區理論：每15度一個時區，但各國可自訂（新加坡理論上 UTC+7，實際用 UTC+8）

### 七、機場與搭機
- **C.I.Q.**：**C**ustoms 海關、**I**mmigration 移民（證照查驗）、**Q**uarantine 檢疫
- **MCT**：**最短轉機時間**（Minimum Connecting Time）
- **STPC**：航空公司造成延誤、當天轉不上班機，由航空公司負擔**食宿交通**
- 機場服務費 **500元**，隨機票代收；**未滿2歲**免繳
- 團體自助報到流程：自助選位 → 護照掃描 → 報到 → 刷出登機證
- **液體**：手提每瓶 ≤100ml，裝在1公升透明夾鏈袋；安檢時**取出**放置物盤
- 手提 vs 託運：
    - **行動電源、鋰電池**：只能**手提**，不能託運
    - **水銀溫度計**：完全不能帶
    - **三腳架**收合超過 **60公分**：託運
    - 手杖不可放在**靠走道**的座位邊
- 機上：**助聽器、心律調整器**可使用，不受限制
- 機場隨地吐痰、丟菸蒂：最高罰 **2萬5千元**

### 八、行李
- **計重制**（多數航線）vs **計件制**（美洲相關航線，例如夏威夷到紐西蘭）
- 行李牌要核對：姓名、目的地、件數、航班（不用核對出發地）
- **行李延誤或遺失**：
    1. 帶行李收據、護照、登機證
    2. 在機場填 **PIR**（Property Irregularity Report，行李意外報告表）：行李外觀、內容物、聯絡地址、行程（**不用填賠償價格**）
    3. 請航空公司**送達**旅客住處或下一站飯店
    4. 跨多家航空公司轉機：向**最後一段**航空公司申報（不用報警）
    5. 可向航空公司爭取**零用金**購買日用品
- **國內法賠償**（航空客貨損害賠償辦法）：
    - 乘客**死亡 300萬**元
    - 隨身行李最高 **2萬**元
- 航班延誤 **30分鐘**以上，航空公司要向旅客說明原因及處理方式

### 九、領隊實務情境
| 情境 | 正確作法 |
|---|---|
| 班機取消、飯店全滿 | 先安撫團員，聯繫旅行社與航空公司安排**餐券、臨時住宿** |
| 空服員罷工 | 屬不可抗力，但增加的費用**不能一律向旅客收** |
| 遊覽車沒來、要趕飛機 | 聯繫公司、叫合法計程車或其他合法車輛；**不能**用私人轎車載客 |
| 遊覽車拋錨 | 聯繫車行派車、評估時間；不要一開始就改航班 |
| 回國行李沒到 | 請航空公司把行李**送到團員家** |
| 臥鋪火車門鎖壞了 | 貴重物品**隨身**，請列車員協助 |
| 銀髮團入住，行李要快送到房間 | 協助行李員在**行李牌寫上房號** |
| 旅行社附加費用常見項目 | 燃油附加費、機場稅、簽證費等（**機票本身**不是附加費用） |
