# 華語領隊人員評量：新手教材
## 第七章　急救保健、緊急事件與旅遊保險

**對應單元：07 實務 急救保健與緊急事件**｜**每年約 18 題（急救 9＋緊急事件 9）**

領隊是團員在國外的第一個求助對象。這章分三塊：**人生病受傷怎麼救**、**出事了怎麼處理**、**錢由誰賠（保險）**。

## 第一部分　急救

### 一、CPR 與 AED
- 看到有人倒地：先評估**意識**（拍肩呼叫）
- 流程「**叫叫 C-A-B-D**」：
    1. **叫**：確認意識
    2. **叫**：求救（打當地緊急電話、拿 **AED**）
    3. **C**（Compressions）：胸部按壓
    4. **A**（Airway）：暢通呼吸道
    5. **B**（Breathing）：人工呼吸
    6. **D**（Defibrillation）：AED 電擊
- 按壓：每分鐘 **100～120下**、深度 **5～6公分**
- 壓胸：吹氣 ＝ **30：2**
- 有效按壓口訣：**用力壓、快快壓、胸回彈、莫中斷、二分換**（每2分鐘換人）
- 民眾版已**不教檢查脈搏**
- **AED**：電擊後**不要關機**，繼續 CPR，等 AED 再次分析

### 二、異物哽塞（哈姆立克法）
- **完全阻塞**（不能說話、不能咳、雙手抓喉嚨）→ 用**哈姆立克法**
- 還能**用力咳嗽** → 鼓勵他咳，**不要**做哈姆立克
- 用餐時有人突然講不出話：先看口腔、問他是不是噎到

### 三、常見急症

| 狀況 | 辨識 | 處理 |
|---|---|---|
| **中風** | 臉歪、手無力、口齒不清（**FAST**：Face、Arm、Speech、Time） | 記下發作時間、立即送醫；**不可給水或食物** |
| **心肌梗塞** | 胸口中央壓迫緊縮痛、持續數分鐘，冒冷汗、噁心、肩頸痛 | 停止活動、打緊急電話 |
| **癲癇** | 失去意識、抽搐、咬牙吐沫 | 移開危險物、側躺；**不可撬開牙關或塞東西** |
| **熱傷害、中暑** | 體溫高、頭暈 | 順序：**蔭涼 → 脫衣 → 散熱 → 喝水（有意識時）→ 送醫** |
| 天旋地轉站不穩 | 較像**眩暈**，不一定是中風 | 先休息觀察 |
| **糖尿病** | | 隨身帶糖、少吃濃湯碎肉等高脂食物 |

### 四、外傷
- **燒燙傷**：**沖、脫、泡、蓋、送**
    - 沖：流動冷水沖 **15～30分鐘**（不是只沖10分鐘）
    - 脫：在水中小心脫掉衣物
    - 泡：冷水泡 15～30分鐘
    - 蓋：乾淨布蓋住
    - 送：送醫
    - 火災最容易致命的是**呼吸道吸入性灼傷**
    - 成人三度灼傷超過體表 **10%** 就有生命危險
- **出血**：先**直接加壓**止血；**止血帶**只用在四肢大動脈出血、加壓止不住時
- **骨折**：固定患部、不要隨便移動；開放性骨折不要把骨頭推回去
- **蛇咬**：保持冷靜、記住蛇的特徵、患肢**放低**、包紮**不可太緊**、盡快送醫
- **蜂螫**：可能出現眼皮浮腫、呼吸困難等過敏反應；遇到蜂群要**快速離開**，不要就地臥倒

### 五、傳染病與旅遊保健

| 疾病 | 傳染途徑 |
|---|---|
| **A 型肝炎** | **飲食**（吃到汙染的食物） |
| B、C 型肝炎 | 血液、體液 |
| 新冠肺炎、流感 | **空氣或飛沫** |
| **日本腦炎** | 三斑家蚊（不是埃及斑蚊） |
| 登革熱 | **埃及斑蚊**、白線斑蚊 |
| 瘧疾 | 瘧蚊 |
| 沙門氏菌 | 不潔食物（蛋、肉） |

- **國際檢疫傳染病**：霍亂、鼠疫、黃熱病（**瘧疾不是**）
- **旅行者腹瀉**：喝瓶裝水、熟食；**不要喝自來水**
- 傳染病防治**不是**「優先用抗生素」
- 出國前 **2～4週**到旅遊醫學門診
- **時差調適**：出發前逐步調整睡眠，抵達後白天多曬太陽、晚上避光
- 送醫時描述病情：從頭部往下、從主要症狀說起（不是由腳往上）

## 第二部分　緊急事件處理

### 六、CRISIS 處理六步驟
| 字母 | 意思 |
|---|---|
| **C**alm | 冷靜 |
| **R**eport | 報告（通報公司、相關單位） |
| **I**nterpretation | 說明：**控制、掌握客人的行動及心態** |
| **S**olution | 解決 |
| **I**nspection | 檢查追蹤 |
| **S**ummary | 總結報告 |

### 七、通報
- 領隊發生特殊或意外事件：**24小時內**向**受僱旅行社及觀光署**報備（不是48小時）
- 旅行社的緊急事故報告書：附**行程、團體名冊、責任保險單**

### 八、常見事件

| 事件 | 處理重點 |
|---|---|
| **護照遺失** | 向**當地警察**報案 → 駐外館處補發或申辦**入國證明書** → 回國補發時**免附**國內警察報案證明；**24小時內**報案，重製費用保險才賠 |
| **簽證遺失** | 查明簽證號碼、日期地點；確認能否在當地補辦（不用向交通機關報案） |
| **團員走失** | 事先約定：走散了**在原地等**，領隊回頭找；不要叫其他團員去找 |
| **治安問題** | 先**保護團員安全** |
| **車禍** | 傷患（尤其骨折）**不要任意移動**，等救護；報警做筆錄；通知旅行社和國外代理商 |
| 遊覽車門打不開 | 用擊破器敲**車窗四個角落** |
| **飯店火災** | 走樓梯、低姿勢，**不搭電梯** |
| 天災、戰亂、恐攻 | **主動**聯繫駐外館處和旅行社、帶團撤到安全區（不要等館處主動聯絡）；向媒體說明不是領隊的工作 |
| 團員生病住院 | 安排照顧、聯繫家屬；**不能**丟下病人自己跟團走 |
| 旅館超賣 | 要求旅館安排同級以上旅館；不能讓團員睡大廳 |
| 團員中途要回國 | 告知權利義務，盡善良管理人責任協助 |
| 旅客在飯店遺失物品 | 協助報案、向飯店查詢；不是直接要求飯店賠 |
| 危險性自費行程 | 報名前**告知危險性**，由旅客自己決定 |

### 九、外交部旅遊警示（國外）／陸委會（大陸）

| 燈號 | 意思 |
|---|---|
| **灰色** | 提醒注意 |
| **黃色** | 特別注意旅遊安全並檢討應否前往 |
| **橙色** | **避免非必要旅行** |
| **紅色** | **不宜前往**，儘速離境 |

### 十、駐外館處能幫什麼
- **可以**：提供不可抗力事件的資訊和協助、協助聯繫家屬、提供醫院和律師名單、翻譯協助
- **不可以**：**代墊醫療費或入院保證金**、介入**商業糾紛**、代付罰款
- 急需返國又沒錢：提供候機期間生活費**借款**，最高 **800美元**

## 第三部分　旅遊保險

### 十一、保險分類

| 保險 | 誰買 | 保什麼 |
|---|---|---|
| **旅行業責任保險** | 旅行社（強制） | 旅客**意外**死亡 250萬起、醫療 10萬起、家屬善後 10萬、證件遺失 2,000元 |
| **履約保證保險** | 旅行社（強制） | 旅行社**倒閉**、財務困難不能出團 → 賠旅客團費損失 |
| 旅行平安險 | 旅客自己 | 個人意外與醫療 |
| 旅遊不便險 | 旅客自己 | 班機延誤、行李延誤 |
| 海外急難救助 | 附加在保險上，由**保險公司**提供 | 醫療轉送、法律、旅遊協助等 |

- 責任險：意外事故發生日起 **180日內**死亡，可申請死亡給付
- 責任險額外住宿附加條款：每人每日上限 2,000元（例：延後8天、每天花3,000 → 賠 2,000×8＝**16,000元**）
- 申請理賠文件：領隊報告書、理賠申請書、醫療收據正本、意外事故證明
- 旅客自己生病（非可歸責旅行社）：醫療費由旅客負擔，責任險不理賠疾病
- **健保**：國外緊急就醫，**出院日起6個月內**申請核退
