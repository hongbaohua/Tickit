## 1　基本名詞：先把字看懂

### 1-1　地方與身分

| 名詞 | 白話解釋 | 例子 |
|---|---|---|
| **兩岸** | 臺灣海峽的兩邊：一邊是臺灣（我們），一邊是中國大陸。新聞說的「兩岸關係」就是臺灣和中國大陸之間的關係 | 兩岸交流、兩岸協議 |
| **臺灣地區** | 法律用語，指**臺灣、澎湖、金門、馬祖**，以及政府統治權所及的其他地區 | 臺北、金門都是臺灣地區 |
| **大陸地區** | 法律用語，指臺灣地區以外的中華民國領土，也就是一般說的中國大陸 | 北京、上海 |
| **戶籍** | 政府登記「你是哪裡的人」的資料，臺灣的戶籍登記在戶政事務所。有臺灣戶籍才會有臺灣身分證 | 你的身分證背面的地址 |
| **臺灣地區人民** | 在**臺灣地區設有戶籍**的人 | 你 |
| **大陸地區人民** | 在**大陸地區設有戶籍**的人 | 一般的中國大陸居民 |
| **港澳** | 香港和澳門。兩地原本分別由英國、葡萄牙治理，1997 年、1999 年由中國接管，實行「一國兩制」，所以法律上另外處理 | 香港、澳門 |
| **陸配** | 「大陸配偶」的簡稱，和臺灣人結婚的大陸人 | — |

::: tip
**記法：** 兩岸條例判斷「你是哪邊的人」只看**戶籍**，不看出生地、護照、住哪裡、在哪裡工作。
:::

### 1-2　法律與制度

| 名詞 | 白話解釋 |
|---|---|
| **條例** | 法律的一種名稱。法律可以叫「法」「律」「條例」「通則」，效力都一樣，條例通常是針對特定事項的法律 |
| **兩岸條例** | 全名「**臺灣地區與大陸地區人民關係條例**」，規範兩岸人民往來的**主要法律** |
| **港澳條例** | 全名「**香港澳門關係條例**」，規範臺灣和港澳往來的法律 |
| **施行細則** | 法律通過後，主管機關再訂的「補充說明書」，把法律沒寫清楚的細節寫出來 |
| **許可辦法** | 主管機關依法律授權訂的「申請規定」，例如「大陸地區人民來臺從事觀光活動許可辦法」 |
| **許可制** | 要**先申請、政府同意**之後才能做 |
| **事前許可** | 「做之前」就要先拿到許可。例如大陸人要先拿到入境許可，才能來臺 |
| **通報** | 做完之後告訴政府，不用事先等政府同意 |
| **申報** | 主動向政府報告（有時是事前、有時是事後，題目會說清楚） |
| **驗證** | 由指定機構確認一份文件「是真的」 |
| **協議** | 兩岸透過授權的團體談好、簽下的約定，像兩國之間的條約，但兩岸不叫條約 |

### 1-3　機關與團體（先認識名字，第 4 節詳細講）

| 簡稱 | 全名 | 是什麼 |
|---|---|---|
| **陸委會** | 行政院**大陸委員會** | 我方政府管大陸事務的**最高機關** |
| **海基會** | 財團法人**海峽交流基金會** | 我方政府**委託**的民間團體，代替政府和對岸接觸辦事 |
| **海協會** | **海峽兩岸關係協會** | 大陸那邊和海基會對口的團體 |
| **國台辦** | 國務院台灣事務辦公室 | 大陸那邊管臺灣事務的機關（對應我方陸委會） |
| **移民署** | 內政部移民署 | 管人進出國境、外國人與陸人居留 |
| **台旅會** | **台灣海峽兩岸觀光旅遊協會** | 觀光署在大陸的辦事處名義 |
| **海旅會** | **海峽兩岸旅遊交流協會** | 大陸那邊管兩岸旅遊的對口團體 |

::: tip
**財團法人是什麼？** 由一筆錢（財產）成立的組織，用這筆錢做公益或特定目的，例如基金會。海基會是政府出大部分的錢成立的財團法人。
:::

### 1-4　旅行會碰到的詞

| 名詞 | 白話解釋 |
|---|---|
| **臺胞證** | 全名「**臺灣居民來往大陸通行證**」。臺灣人去大陸**不能用中華民國護照入境**，要用這張證，由大陸的**出入境管理局**簽發。現在是卡片式 |
| **小三通** | 金門、馬祖和大陸福建沿海**直接坐船往來**。相對於「大三通」（兩岸直接通郵、通商、通航） |
| **直航** | 飛機或船直接從臺灣飛到大陸，不用經過香港、澳門等第三地轉機 |
| **團進團出** | 一起入境、一起出境，整團行動，不能自己脫隊 |
| **旅遊警示** | 政府提醒民眾「某地方去了可能有危險」的燈號，大陸港澳由陸委會發布，其他國家由外交部發布 |
| **人身自由受限** | 被警察或政府扣押、留置、不准離開 |

## 2　為什麼會有兩岸條例

### 2-1　一段簡短的歷史

| 年份 | 發生什麼事 |
|---|---|
| 民國 38 年（1949） | 國共內戰後，中華民國政府遷到臺灣，兩岸**分治**（各自管理），長期互不往來 |
| 民國 76 年（1987）11 月 | 政府**開放民眾赴大陸探親**，兩岸開始有人員往來 |
| 民國 79 年（1990） | 兩岸紅十字會簽「**金門協議**」，處理偷渡犯遣返 |
| 民國 80 年（1991） | 成立**陸委會**、**海基會**；大陸成立**海協會**（1991 年底） |
| 民國 **81 年**（1992） | **兩岸條例施行** |
| 民國 86 年（1997） | 香港回歸中國；「香港澳門關係條例」施行 |

::: plain
**白話：** 兩岸幾十年不往來，突然開放探親後，大家開始結婚、做生意、繼承遺產、坐船來往，問題一大堆（例如：大陸人可以繼承臺灣的房子嗎？在大陸結的婚臺灣承認嗎？）。所以政府訂了一部專門的法律來處理，就是兩岸條例。
:::

::: exam
**考古題（109年）：** 兩岸條例於民國幾年開始施行？答：**81 年**。
**考古題（108年）：** 目前規範兩岸關係的主要法律？答：**臺灣地區與大陸地區人民關係條例**。
:::

## 3　身分：誰是臺灣地區人民

### 3-1　判斷原則：看戶籍

**規定（兩岸條例第 2 條）：**

- **臺灣地區人民**：在臺灣地區設有戶籍的人民
- **大陸地區人民**：在大陸地區設有戶籍的人民

::: exam
**考古題（112年）：** 臺灣地區人民指的是？答：**在臺灣地區設有戶籍之人民**。
:::

### 3-2　常考的身分情境

| 情境 | 結果 | 為什麼 |
|---|---|---|
| 大陸出生、父母都是大陸人，經許可來臺**定居並設戶籍** | **臺灣地區人民** | 有臺灣戶籍了 |
| 大陸出生、父母**一方**是臺灣人 | **出生後 1 年內**在臺灣設戶籍，才是臺灣地區人民 | 施行細則的規定 |
| 臺灣人在大陸**設戶籍**或**領用大陸護照** | **喪失**臺灣地區人民身分，由戶政機關**註銷臺灣戶籍** | 兩岸條例第 9 條之 1 |
| 大陸人旅居國外、甚至已取得外國國籍，要來臺觀光 | 還是以**大陸地區人民**身分申請 | 兩岸條例第 3 條 |

::: exam
**考古題（114年）：** 下列何者可視為臺灣地區人民？答：「在大陸地區出生，父母皆為大陸地區人民，經許可進入臺灣地區**定居，並設有戶籍**者」。
**考古題（109年）：** 大陸出生、父母一方為臺灣人，何種情況得為臺灣地區人民？答：**出生後一年內在臺灣地區設有戶籍**。
:::

### 3-3　領大陸護照、設大陸戶籍的後果

**規定（第 9 條之 1）：** 臺灣地區人民**不得**在大陸地區設有戶籍或領用大陸地區護照。違反的話：

1. **喪失臺灣地區人民身分**
2. 由**戶政機關註銷**臺灣戶籍
3. 隨之喪失在臺灣的**選舉、罷免、擔任公職**等權利

::: plain
**白話：** 不能同時當兩邊的人。拿了大陸護照或大陸身分證，臺灣這邊就不承認你是臺灣人了。
「在大陸設有戶籍」的判斷：持有**大陸居民身分證**或**定居證**等。
**注意：** 臺灣人申辦大陸的「**居住證**」（給在大陸居住的臺灣人用的證件）不等於設戶籍，但陸委會提醒，申辦要按捺指紋，有個資外洩的風險。
:::

::: exam
**考古題（113年）：** 臺灣地區人民領用大陸護照，正確的是？答：**由戶政機關註銷其臺灣地區之戶籍登記**。
:::

::: info
**近年的新規定（114年10月）：** 大陸人申請來臺**定居**時，除了要證明已經**喪失大陸戶籍**，還要附上「**未申領或已放棄（註銷）大陸護照**」的證明。目的就是不讓一個人同時有兩邊的身分。
:::

### 3-4　旅居國外的大陸人

**規定（第 3 條）：** 本條例關於大陸地區人民的規定，**大陸地區人民旅居國外者，也適用**。

::: example
**例子（108年考題）：** 一位大陸人在國外住了 3 年，已經拿到當地國籍，想來臺灣觀光，要用什麼身分申請？
→ **大陸地區人民**。就算有外國國籍，還是照大陸人的規定申請。
:::

## 4　機關：誰管什麼

這是每年必考的題型。先記住一句口訣，再看表格。

::: tip
**口訣：** **陸委會統籌、海基會辦事、內政部管人、外交部管國外警示。**
:::

### 4-1　我方的機關與團體

| 事務 | 由誰負責 | 補充 |
|---|---|---|
| **統籌**處理大陸事務 | **大陸委員會（陸委會）** | 兩岸條例第 3 條之 1 |
| 受政府**委託**和對岸接觸、協商、**驗證文書** | **海峽交流基金會（海基會）** | 財團法人；設立時**政府捐助超過 1/2**；目的事業主管機關是**陸委會** |
| 公務員、國安局、國防部、調查局人員**赴陸許可** | **內政部** | 由內政部會同國安局、法務部、陸委會組成**審查會**審查 |
| 縣市長等政務人員赴陸，**返臺後通報** | **內政部** | — |
| **大陸專業人士**來臺申請 | **內政部**（實際由**移民署**受理） | — |
| 大陸人來臺入境、居留、定居、強制出境 | **內政部移民署** | — |
| 學校和大陸學校簽**校際書面約定** | 事前向**教育部**申報 | 誰管這項業務，就向誰申報 |
| 地方政府和大陸地方機關**締結聯盟** | 由**內政部會商陸委會**，報請**行政院同意** | — |
| 赴大陸**投資**、技術合作 | **經濟部** | — |
| 大陸港澳**旅遊警示** | **陸委會** | — |
| **國外**（大陸港澳以外）旅遊警示 | **外交部** | — |
| 觀光署在大陸的辦事處 | 名義是「**台灣海峽兩岸觀光旅遊協會**」（台旅會），設在**北京、上海、福州** | — |
| 大陸製作的文書在臺使用 | 由**海基會驗證** → 推定為真；**實質證據力**由**法院或主管機關**認定 | 第 7 條 |
| 大陸法院的**民事判決**要在臺灣生效 | 向**法院**聲請**裁定認可** | 第 74 條 |

名詞說明：

- **統籌**：統一規劃、協調各機關，當總負責人。
- **目的事業主管機關**：管這個團體做的事情的政府機關。
- **審查會**：好幾個機關的人一起開會決定要不要許可。
- **推定為真**：先當作是真的，除非有人拿出證據證明是假的。
- **實質證據力**：文件內容能不能用來證明某件事。文件是真的，不代表內容一定能證明什麼，要由法院或主管機關判斷。

::: exam
**考古題（110年）：** 依兩岸條例，誰**統籌**處理大陸事務？答：**大陸委員會**。
**考古題（114年）：** 有關海基會的敘述何者正確？答：**設立時，政府捐助其財產總額逾二分之一**。
**考古題（114年）：** 公務員及國安局、國防部、調查局未具公務員身分的人員，進入大陸要向誰申請許可？答：**內政部**。
**考古題（109年）：** 新竹市長赴陸返臺後，向哪個機關通報？答：**內政部**。
:::

::: trap
**陷阱：**

1. 海基會**不是**政府機關，是政府**委託**的**財團法人**；統籌的是**陸委會**。
2. 海基會的主管機關是**陸委會**，不是內政部。
3. 「金門協議」是兩岸**紅十字會**簽的，**不是**海基會和海協會（110年考題）。
4. 大陸文書經海基會驗證只是「推定為真」，內容能不能證明事情，由**法院或主管機關**決定（109年考題）。
:::

### 4-2　大陸那邊的機關與團體

| 我方 | 對應的大陸方 |
|---|---|
| 陸委會 | 國台辦（國務院台灣事務辦公室） |
| 海基會 | **海協會**（海峽兩岸關係協會） |
| 台旅會（台灣海峽兩岸觀光旅遊協會） | **海旅會**（海峽兩岸旅遊交流協會） |
| — | 臺胞證由大陸**公安部出入境管理局**簽發 |

::: plain
**觀光「小兩會」：** 台旅會和海旅會合稱「**觀光小兩會**」，兩岸旅遊的事情（例如陸客來臺怎麼恢復）原則上由小兩會溝通協商。
:::

::: exam
**考古題（114年、113年）：** 觀光署在大陸設辦事處的名義？答：**台灣海峽兩岸觀光旅遊協會**，設在**北京、上海、福州**。
**考古題（109年）：** 兩岸旅遊協議，大陸方由哪個協會聯繫實施？答：**海峽兩岸旅遊交流協會**。
**考古題（113年）：** 臺胞證由大陸哪個單位簽發？答：**出入境管理局**。
:::

## 5　臺灣人去大陸

### 5-1　一般民眾 vs 公務員

| 身分 | 去大陸要怎麼做 |
|---|---|
| **一般民眾** | 不用向政府申請許可，持臺胞證就能去（但政府建議行前**登錄**，第 10 節講） |
| **公務員**、國安局／國防部／調查局人員、涉及國家機密的人等 | 要事先向**內政部**申請**許可** |
| **政務人員**、縣市長等 | 依規定申請或報准，**返臺後向內政部通報** |

::: info
**時事補充：** 行政院 114 年 12 月 26 日通過兩岸條例修正**草案**，送立法院審議。重點包括：公務員赴陸**全面採許可制**、**立法委員**赴陸也要經審查許可、民選公職人員赴陸接觸中共黨政軍要**公開揭露**。草案還沒有通過前，考試以**現行條文**為準；但題目可能考「政府推動的方向」。
:::

### 5-2　臺灣人不能做的事

| 禁止的事 | 說明 |
|---|---|
| 在大陸**設戶籍**、**領大陸護照** | 違反會喪失臺灣身分（第 3-3 節） |
| 擔任中共**黨務、軍事、行政**或具政治性機關（構）、團體的**職務**或成為成員 | 兩岸條例第 33 條 |
| **公務員**赴陸交流時，遇到中共旗、歌、政治人物圖像，**舉手致敬、鞠躬或合唱** | 有損國家尊嚴 |
| 在臺灣為中共做**具政治性目的的宣傳廣告** | 111年考題 |

::: plain
**廣告的規定：** 在臺灣播映、刊登廣告，**不能**為中共做任何政治性宣傳。但已經依法取得許可的大陸商品、電影，可以做一般的商業推廣。
大陸的出版品、電影、節目，**不能**因為「大陸那邊審查通過了」就直接在臺灣發行播映，要照我方的規定申請許可。
:::

### 5-3　政府可以限制大家去大陸

**規定（第 9 條）：** 遇到**重大突發事件**，影響臺灣重大利益或對兩岸互動有重大危害時，可以**經立法院議決**，由**行政院公告**在一定期間內，對臺灣人民赴陸採取**禁止、限制**或其他必要處置。立法院如果在**會期內 1 個月**沒有決議，就**視為同意**。

::: plain
**名詞：**

- **議決**：開會討論後做決定。
- **會期**：立法院開會的期間（每年有固定的會期）。
- **視為同意**：沒有表示意見，就當作同意。
:::

::: tip
**兩個「1 個月」：**

1. 重大突發事件限制人民赴陸 → 立法院會期內 **1 個月**沒決議，視為同意（108年考題）
2. 實施兩岸**直接通商、通航**及**大陸人民來臺工作**前，應經立法院同意 → 會期內 **1 個月**沒決議，視為同意（112年考題）
:::

### 5-4　在大陸生病、遺失護照怎麼辦

| 狀況 | 怎麼處理 |
|---|---|
| 在大陸**臨時生病受傷就醫**（或緊急分娩） | 可在**出院日起 6 個月內**，向**健保署**申請**核退**醫療費用 |
| 在大陸**遺失護照** | 大陸**沒有**我國駐外館處，要帶身分證明、遺失報案證明、**臺胞證**等，洽**出發地機場的航空公司**協助，向**移民署**申請返臺 |
| 遺失**臺胞證** | 向當地公安機關出入境管理部門報失、申請補發 |

::: plain
**核退：** 先自己付醫藥費，回臺灣後拿收據向健保署申請，健保署依標準退一部分錢給你。
**為什麼遺失護照要找航空公司？** 在其他國家可以找我國的駐外館處補辦，但大陸沒有我國的使領館，所以要請航空公司協助，向移民署申請讓你搭機回臺灣。
:::

::: exam
**考古題（111年）：** 在大陸遺失護照，正確的是？答：**檢具相關證明文件，洽請大陸地區出發地機場之航空公司協助，向內政部移民署申請返臺**。
**考古題（109年）：** 在大陸臨時就醫，可在出院日起幾個月內申請核退？答：**6 個月**。
:::

## 6　大陸人來臺灣

### 6-1　基本原則：事前許可制

**規定（第 10 條）：** 大陸地區人民**非經許可**，不得進入臺灣地區。也就是採「**事前許可制**」：要先申請、拿到許可，才能入境。

::: exam
**考古題（110年）：** 政府採取何種制度規範大陸人民進入臺灣？答：**事前許可制**。
:::

### 6-2　大陸人來臺觀光

依「**大陸地區人民來臺從事觀光活動許可辦法**」：

| 項目 | 規定 |
|---|---|
| 團體旅遊 | 除了**個人旅遊**外，要由**旅行社組團**辦理，**團進團出** |
| 每團人數 | **5 人以上、40 人以下** |
| 小三通（福建居民組團到金門、馬祖等） | 最低 **3 人**就可以組團 |
| 團員**逾期停留且行方不明** | 接待的旅行社，**每 1 人扣繳保證金新臺幣 5 萬元** |

::: plain
**名詞：**

- **逾期停留**：許可的停留時間到了還沒離開。
- **行方不明**：找不到人，不知道去哪裡了。
- **保證金**：旅行社事先繳給政府的一筆錢，出問題時政府從裡面扣。
- **扣繳**：從保證金裡直接扣掉。
:::

::: exam
**考古題（113年）：** 大陸人來臺觀光團，每團人數限制？答：**5 人以上 40 人以下**。
**考古題（111年）：** 廈門、福州民眾組團到金門，最低人數？答：**3 人**。
**考古題（111年）：** 陸客逾期停留且行方不明，旅行社怎麼處分？答：**每一人扣繳保證金新臺幣 5 萬元**。
:::

::: info
**現況（截至 115 年 11 月）：** 大陸方面在 2019 年 8 月片面停止陸客來臺自由行，並大幅縮減陸客團。目前陸客來臺**本島**團體旅遊**尚未恢復**；政府已先開放旅居海外（第三地）的陸客來臺觀光，以及陸客赴**金門、馬祖**旅遊。政府立場是：陸客來臺應由**觀光小兩會**先協商旅遊安全、品質等事項後再恢復。
:::

### 6-3　其他來臺規定

- 大陸人**不能在臺灣非法打工**，雇用的人也違法。
- 大陸人有**危害國家安全或社會安定**之虞的，**移民署**可以**逕行強制出境**（直接送出境）。
- 保證人沒有協助處理強制出境，要負擔強制出境的費用。

### 6-4　陸配：從依親居留到定居

大陸配偶（陸配）要拿到臺灣身分證，要經過三個階段：

| 階段 | 條件 | 白話 |
|---|---|---|
| ① **依親居留** | 和臺灣人結婚，經許可入境 | 「依親」＝依靠親人（配偶）住在臺灣 |
| ② **長期居留** | 依親居留**滿 4 年**，且**每年**在臺居住**超過 183 天** | 183 天大約是半年 |
| ③ **定居**（設戶籍、拿身分證） | 長期居留**連續滿 2 年**，且**每年**居住**超過 183 天**，品行端正、無犯罪紀錄，並證明**已喪失大陸戶籍、未持用大陸護照** | 定居後就是臺灣地區人民 |

::: tip
**記法：** 陸配「**4 ＋ 2 ＝ 6 年**」拿身分證，每年都要住**超過 183 天**（至少 184 天）。
:::

**設籍後的限制（第 21 條）：** 大陸人在臺灣**設戶籍未滿 10 年**，不能登記為公職候選人、擔任公教或公營事業人員、組織政黨。

## 7　民事、文書與錢

「民事」是人和人之間的事，例如結婚、繼承、買賣、借錢（相對於「刑事」是犯罪的事）。

### 7-1　民事規定

| 狀況 | 規定 | 白話 |
|---|---|---|
| 行為地或事實發生地**跨兩岸** | 以**臺灣地區**為行為地或事實發生地 | 例如合約一部分在臺灣簽、一部分在大陸做，就當作在臺灣發生 |
| 兩岸人民**結婚的方式**和其他要件 | 依**行為地**的規定 | 在哪裡結婚，就照那裡的結婚方式（在臺灣結就照臺灣規定） |
| 大陸人**繼承**臺灣人的遺產 | 要在**繼承開始起 3 年內**，用**書面**向被繼承人住所地的**法院**表示要繼承；**逾期視為拋棄** | 繼承開始＝被繼承人過世的時候 |
| 大陸人繼承臺灣的遺產，可以拿多少 | 每人**不得超過新臺幣 200 萬元**，超過的部分歸臺灣的繼承人（沒有的話歸國庫） | 防止臺灣的錢大量流到大陸 |
| 大陸法院的**民事確定判決** | 要向臺灣的**法院**聲請**裁定認可**，才有效 | 108年考題 |
| 大陸的**法定受益人**申請**保險死亡給付** | 要附死亡證明、身分證明、親屬關係證明等；**不用健康證明** | 113年考題 |

名詞說明：

- **繼承**：家人過世後，依法拿到他留下的財產（遺產）。
- **被繼承人**：過世、留下遺產的人。
- **拋棄繼承權**：不要這份遺產。
- **確定判決**：已經不能再上訴、確定了的判決。
- **法定受益人**：依法律規定可以領保險金的人（通常是家人）。

::: exam
**考古題（113年）：** 行為地跨連兩岸，以何處為行為地？答：**臺灣地區**。
**考古題（112年）：** 兩岸人民結婚的方式依何處規定？答：**行為地**。
**考古題（108年）：** 大陸人民繼承臺灣人遺產，應於繼承開始起多久內表示？答：**3 年**。
:::

### 7-2　人民幣與幣券

| 規定 | 內容 |
|---|---|
| 人民幣現鈔入出境限額 | **2 萬元**，而且**不計入**其他外幣的額度（外幣另外算，超過等值 1 萬美元要申報） |
| 超過 2 萬元 | 要向海關**申報**，超過的部分由海關**封存**，出境時再領回 |
| 申報不實 | 超過申報的部分**沒入**（沒收） |
| 「幣券」的範圍 | 大陸發行的**紙幣、硬幣、紀念幣**及票據、有價證券等；**不包括虛擬貨幣** |
| 人民幣的國際代碼（ISO 4217） | **CNY**（RMB 是俗稱，不是國際代碼） |

::: plain
**為什麼管人民幣？** 兩岸條例規定大陸發行的幣券，除了在金管會規定的限額以下，不能進出臺灣。所以人民幣有自己的限額（2 萬），和美元、日圓等外幣分開計算。
:::

::: exam
**考古題（112年）：** 人民幣現鈔攜帶限額？答：**人民幣 2 萬元，但不計入攜帶之其他外幣現鈔額度內**。
**考古題（114年）：** 「幣券」的範圍，何者錯誤？答：**虛擬貨幣**。
**考古題（113年）：** 人民幣的 ISO 4217 代碼？答：**CNY**（MOP 是澳門幣）。
:::

### 7-3　大陸船舶越界捕魚

**規定（第 80 條之 1）：** 大陸船舶在臺灣的限制或禁止水域**越界捕魚**，扣留後，可處**船長**新臺幣 **30 萬元以上、1,000 萬元以下**罰鍰。

::: plain
**罰鍰**：行政罰的罰款（不是刑事的罰金）。
:::

## 8　港澳條例

「香港澳門關係條例」處理臺灣和港澳的往來。因為港澳實行和大陸不同的制度，所以另外訂一部法律，**不完全適用**兩岸條例。

| 重點 | 內容 |
|---|---|
| 「香港」的範圍 | 原由英國治理的**香港島、九龍半島、新界**及其附屬部分 |
| 「澳門」的範圍 | 原由葡萄牙治理的澳門半島、**氹仔島、路環島**及附屬部分 |
| 港澳情況變化危害臺灣安全時 | **行政院**可以**停止**港澳條例一部或全部的適用 |
| 港澳居民在臺**投資** | **新臺幣 600 萬元以上**，經審查通過可以申請**居留** |
| 港澳法律**禁止攜帶**的物品 | 瓦斯噴霧器（防狼噴霧）、電擊棒、伸縮警棍、手指虎、彈簧刀等攻擊性物品；**自拍棒不在禁止之列** |
| 澳門**大三巴牌坊** | 屬「**澳門歷史城區**」，是**世界遺產** |

::: exam
**考古題（114年）：** 香港指香港島、九龍半島以及何者？答：**新界**。
**考古題（108年）：** 港澳居民在臺投資至少多少可申請居留？答：**新臺幣 600 萬元**。
**考古題（109年）：** 何者**不是**港澳法律禁止攜帶的物品？答：**自拍棒**。
:::

::: trap
**陷阱：** 防狼噴霧在臺灣可以合法買，很多女生會隨身帶，但帶去香港、澳門會觸法。帶團前要提醒團員。
:::

## 9　兩岸協議與重要事件

| 協議或事件 | 重點 |
|---|---|
| **金門協議**（民國 79 年） | 兩岸**紅十字會**簽署；處理**偷渡犯、刑事犯及刑事嫌疑犯**的遣返；是兩岸遣返偷渡犯**最早**的依據 |
| **海峽兩岸共同打擊犯罪及司法互助協議** | 雙方同意**即時通報**對方人員**被限制人身自由**的訊息 |
| **海峽兩岸避免雙重課稅及加強稅務合作協議** | **已簽署、尚未生效** |
| **海峽兩岸關於大陸居民赴臺灣旅遊協議** | 聯繫主體：我方**台旅會**、大陸方**海旅會** |
| 參加國際運動賽事 | 採「**奧會模式**」，我方以「**中華台北**」名義參賽 |
| **小三通**目前運行的航線 | **金門－廈門**、**金門－泉州**、**馬祖－福州**；「馬祖－湄洲」**不是** |

::: plain
**名詞：**

- **遣返**：把人送回原來的地方。
- **偷渡**：沒有合法證件，偷偷進入別的地方。
- **雙重課稅**：同一筆收入被兩邊都收稅。避免雙重課稅協議就是要讓錢只被課一次稅。
:::

::: exam
**考古題（110年）：** 民國 79 年金門協議處理什麼？答：**兩岸刑事犯及刑事嫌疑犯之遣返等事宜**。
**考古題（109年）：** 哪項協議已簽署尚未生效？答：**海峽兩岸避免雙重課稅及加強稅務合作協議**。
**考古題（114年）：** 小三通航線何者配對錯誤？答：**馬祖與湄洲**。
:::

## 10　政府政策與兩岸現況

這部分是時事題，**以考試前公布的最新狀況為準**。以下整理到 115 年 11 月。

### 10-1　旅遊警示

**陸委會**發布大陸、港澳的旅遊警示，分 4 級：

| 燈號 | 意思 |
|---|---|
| 灰色 | 提醒注意 |
| 黃色 | 特別注意旅遊安全，並檢討應否前往 |
| **橙色** | **避免非必要旅行** |
| 紅色 | 不宜前往 |

**現況：** **113 年 6 月 27 日**起，赴**中國大陸及港澳**調升為**橙色**，到 115 年仍維持。原因是陸港澳持續增修國安法令，國人赴陸遭扣押、留置、盤查的案例增加，加上中共發布懲治「台獨」的意見（俗稱「**懲獨 22 條**」）。

::: exam
**考古題（114年）：** 113 年 6 月 27 日起赴大陸港澳的旅遊警示是什麼顏色？答：**橙色**。
:::

::: trap
**陷阱：** 大陸港澳的旅遊警示由**陸委會**發布；其他國家（例如日本、泰國）由**外交部**發布。兩者燈號名稱一樣，發布機關不同。
:::

### 10-2　旅行社組團赴陸：「禁團令」

- 政府目前**不准旅行社招攬組團赴大陸旅遊**，業界稱為「**禁團令**」。原本規劃 113 年春節後恢復，但因大陸遲未安排陸客團來臺、又片面改變 M503 航路，觀光署在 113 年 2 月宣布暫停招攬。
- 一般民眾**自己**去大陸（自由行）**不受限制**；旅行社可以代訂機票、飯店。
- **115 年 9 月 1 日起**，旅行社辦理赴陸**考察團、參訪團、民眾自組團**時，要逐團做 4 件事：
    1. 告知旅遊風險
    2. 行前到陸委會「**國人赴陸港澳動態登錄**」系統登錄**團體**資訊（旅行社名稱、承辦人、**領隊聯絡資訊**、人數、起訖日期、簡要行程；**不含**旅客個資）
    3. 填報赴陸業務統計資料
    4. 投保**旅行業責任保險**

::: plain
**為什麼要登錄？** 萬一出事（例如車禍、被扣留），陸委會和海基會可以馬上知道是哪個團、找得到旅行社和領隊，第一時間協助。
:::

### 10-3　赴陸安全登錄

陸委會、海基會、外交部、觀光署都有提供赴陸登錄或通報管道；考古題考過：**法務部沒有**「赴陸期間司法案件協助登錄系統」。

### 10-4　政府的其他政策

| 政策 | 內容 |
|---|---|
| 三道防護網（108 年元旦談話） | **民生安全、資訊安全、民主**防護網；**沒有**「文化防護網」 |
| 國安五法、反滲透法 | 為反制中共滲透所修的法，包括刑法、國家機密保護法、兩岸條例等；**不包括**國家安全會議組織法 |
| 兩制臺灣方案 | 中共提出的統一方案，我方**不接受** |
| 海峽中線 | 我方主張海峽中線**存在** |

::: exam
**考古題（109年）：** 何者**不是**三道防護網？答：**文化防護網**。
**考古題（111年）：** 國安五法及反滲透法不包含？答：**國家安全會議組織法**。
:::

## 11　帶團去大陸的實務提醒

這節不一定會考，但領隊真的帶團時一定會用到。

### 11-1　出發前

- 確認每位團員的**臺胞證**有效、護照有效（回臺灣入境用）。
- 提醒團員：手機、電腦裡可能被認為違法的內容（例如政治相關的圖片、文字），建議**在臺備份後刪除**。
- 提醒不要攜帶**防狼噴霧、電擊棒、伸縮警棍**等物品，尤其經過**香港、澳門**時。
- 人民幣現鈔不要超過 **2 萬元**，超過要申報。
- 建議團員到陸委會系統做**動態登錄**；旅行社辦理特定團體時要逐團登錄（第 10-2 節）。

### 11-2　在當地

- 不要參加政治性活動、不要拍攝軍事設施或敏感地點。
- 遇到盤查要冷靜配合，馬上聯絡旅行社。
- 大陸自 **2026 年 9 月 15 日**起實施新的出入境管理規定，範圍擴大，陸委會提醒赴陸要審慎評估風險。

### 11-3　出事時

| 狀況 | 聯絡誰 |
|---|---|
| 團員被扣留、失聯 | 旅行社 → **海基會**（24 小時緊急服務專線）、**陸委會** |
| 遺失護照 | 出發地機場的**航空公司** → 向**移民署**申請返臺 |
| 生病受傷 | 當地醫院；保留收據，回臺 **6 個月內**向健保署申請核退 |

::: info
大陸**沒有**我國的駐外館處，所以在大陸出事，不能找「駐外館處」，要找**海基會**、**陸委會**協助。這和去其他國家不一樣（第七章會再講緊急事件處理）。
:::

## 12　容易搞混總整理

| 容易搞混 | 正確說法 |
|---|---|
| 陸委會 vs 海基會 | 陸委會是**政府機關**，**統籌**；海基會是**財團法人**，受**委託**辦事 |
| 海基會 vs 海協會 | 海基會是**我方**；海協會是**大陸方** |
| 台旅會 vs 海旅會 | 台旅會（台灣海峽兩岸**觀光旅遊**協會）是**我方**；海旅會（海峽兩岸**旅遊交流**協會）是**大陸方** |
| 金門協議是誰簽的 | 兩岸**紅十字會**，不是海基會、海協會 |
| 公務員赴陸 | 向**內政部**申請許可；縣市長返臺向**內政部**通報 |
| 大陸港澳旅遊警示 vs 國外旅遊警示 | 陸委會 vs 外交部 |
| 大陸文書驗證 vs 實質證據力 | 驗證由**海基會**；證據力由**法院或主管機關**認定 |
| 大陸民事判決 | 向**法院**聲請**認可** |
| 判斷身分 | 看**戶籍**，不看出生地或國籍 |
| 大陸人有外國國籍來臺 | 仍以**大陸地區人民**身分申請 |
| 觀光團人數 vs 小三通 | 一般 **5～40 人**；小三通最低 **3 人** |
| 人民幣 2 萬 vs 外幣 1 萬美元 | 兩者**分開計算** |
| RMB vs CNY | 國際代碼是 **CNY** |
| 小三通航線 | 金門－廈門、金門－泉州、馬祖－福州；**沒有**馬祖－湄洲 |
| 港澳禁止攜帶 | 防狼噴霧、電擊棒、伸縮警棍有禁；**自拍棒沒有** |
