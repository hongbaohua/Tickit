## 1　基本名詞：先把字看懂

這一章會一直出現下面這些詞。不用一次背起來，先讀一遍，後面看到再回來查。

### 1-1　跟「法律」有關的詞

| 名詞 | 白話解釋 | 例子 |
|---|---|---|
| **契約** | 兩個人（或公司）說好「我做什麼、你做什麼」，而且法律承認、會保護的約定。不一定要寫在紙上，口頭說好也算，但寫下來比較有證據 | 你付錢，旅行社帶你出國玩 |
| **當事人** | 簽契約的那兩方 | 旅客、旅行社 |
| **民法** | 規定「人和人之間」權利義務的法律，例如買賣、租房子、借錢、結婚、繼承 | 民法規定買到壞東西可以退 |
| **債編** | 民法分成好幾「編」（像一本書分好幾大章），「債編」專門講契約和欠錢、賠錢的事。這裡的「債」不是只有欠錢，而是「一方可以要求另一方做某件事」的關係 | — |
| **專節** | 一編裡面再分「節」。民法債編裡有一節專門講「旅遊」，叫**旅遊專節** | — |
| **第514條之1** | 法律條文的編號。原本第514條後面沒有空位了，後來新增的條文就叫「514條之1、之2……」。旅遊專節就是 **514條之1 到 514條之12，共12條** | — |
| **定型化契約** | 公司**事先寫好**、要給很多客人簽的**制式合約**，客人通常只能簽或不簽，沒辦法一條一條討價還價。例如手機門號合約、健身房合約、旅行社合約 | 旅行社給你簽的那份好幾頁的契約書 |
| **應記載事項** | 政府規定：定型化契約裡「**一定要寫進去**」的內容。就算旅行社沒寫，法律也當作有寫 | 審閱期至少1天 |
| **不得記載事項** | 政府規定：定型化契約裡「**絕對不能寫**」的內容。就算寫了也無效 | 「行程僅供參考」 |
| **範本** | 政府提供的契約「參考樣本」，旅行社可以照抄來用 | 國外旅遊定型化契約書範本 |
| **公告** | 政府機關正式發布的規定 | 交通部公告 |
| **消費者保護法（消保法）** | 保護「消費者」（買東西、買服務的人）的法律。定型化契約的「應記載／不得記載」就是依消保法訂出來的 | — |

### 1-2　跟「人」有關的詞

| 名詞 | 白話解釋 |
|---|---|
| **旅客** | 參加旅遊、付錢的人 |
| **旅遊營業人** | 民法的講法，意思就是「**以安排旅遊為生意、跟旅客收錢的人**」，實際上就是旅行社 |
| **旅行業** | 法規裡對旅行社的正式稱呼。看到「旅行業」＝旅行社 |
| **第三人** | 契約兩方以外的人。例如小美不能去，換她媽媽去，媽媽就是「第三人」 |
| **履行輔助人** | 幫旅行社完成工作的人或公司，例如國外的當地旅行社、遊覽車公司、飯店、餐廳。他們出錯，**旅行社也要負責** |
| **受僱人** | 旅行社的員工，例如領隊、業務 |

### 1-3　跟「取消、結束契約」有關的詞（很重要，常常考）

| 名詞 | 白話解釋 | 什麼時候用 |
|---|---|---|
| **解除契約** | 把契約「**從頭取消**」，當作沒簽過。通常是**還沒出發**的時候 | 出發前不去了 |
| **終止契約** | 契約「**從現在起不再繼續**」，已經發生的部分還是算數。通常是**已經出發**、玩到一半的時候 | 玩到第三天不玩了 |
| **任意解除／任意終止** | 「任意」＝不需要理由，想取消就取消（但要賠錢） | 旅客臨時不想去 |
| **催告** | 正式提醒對方「請在幾天內做到」 | 旅行社催旅客交護照 |
| **定相當期限** | 給對方一段「合理的時間」去做 | 給7天去拍大頭照 |
| **怠於** | 「偷懶沒做」、「拖延沒做」 | 怠於通知＝該通知卻沒通知 |

::: tip
**記法：** 「**解**除」像把結「**解**開」，整個沒了；「**終**止」像電影演到一半「**終**止」，前面已經播的還是播過了。
出發**前**多用「解除」，出發**後**多用「終止」。
:::

### 1-4　跟「錢」有關的詞

| 名詞 | 白話解釋 | 例子 |
|---|---|---|
| **旅遊費用（團費）** | 參加這個團要付的總價 | 38,900 元 |
| **行政規費** | 辦證件時繳給政府的手續費，例如簽證費、護照費。這筆錢已經交給政府了，退不回來 | 申請某國簽證 1,000 元 |
| **違約金** | 契約裡**事先說好**的「違反約定要賠多少」。只要違反就要付，**不用證明損失多少** | 旅行社取消，賠團費 20% |
| **損害賠償** | 實際上受到多少損失，就賠多少。要**拿出證據**證明損失 | 因為班機取消多花的計程車費 |
| **懲罰性違約金** | 違約金的一種，目的是「處罰」做錯的一方，所以金額比較高 | 被當地政府關起來，每天賠 2 萬元 |
| **差額** | 兩個價錢相減的差 | 五星級飯店 6,000、三星級 2,000，差額 4,000 |
| **墊付** | 「**先幫你出錢，之後你要還**」。不是送你的！ | 旅行社先幫你買機票回國，回國後你要還 |
| **附加利息** | 還錢的時候要多付一點利息 | — |
| **請求權** | 「可以向對方要求（例如要錢）的權利」 | 向旅行社要求賠償的權利 |
| **消滅（時效）** | 請求權放太久沒用，就「過期作廢」，不能再要了 | 1 年沒去要，就不能要了 |

### 1-5　跟「誰的錯」有關的詞（整章最關鍵）

| 名詞 | 白話解釋 | 例子 |
|---|---|---|
| **可歸責於旅行業** | 「**是旅行社的錯**」，可以怪旅行社 | 旅行社忘記訂飯店、機位沒訂好、員工疏失 |
| **不可歸責於旅行業** | 「**不是旅行社的錯**」 | 颱風、飯店失火、旅客自己生病 |
| **不可抗力** | 人力**無法抵抗、無法預防**的事情 | 地震、颱風、戰爭、大規模傳染病 |
| **故意** | 「**明明知道還故意這樣做**」 | 領隊為了省錢，故意把旅客丟在機場 |
| **重大過失** | 「**非常不小心**」，一般人稍微注意就不會犯的錯 | 完全忘記去接旅客 |
| **過失** | 「**一般的不小心**」 | 算錯集合時間 |
| **善良管理人之注意** | 法律用語，意思是「**用一個認真負責的專業人士應有的小心程度**」去處理。比對待自己的東西還要小心 | 旅行社保管旅客護照，要非常小心 |

::: tip
**錯的程度：** 故意 ＞ 重大過失 ＞ 過失。錯越嚴重，賠越多（後面會學到 5 倍、3 倍、1 倍）。
:::

### 1-6　跟「保險」有關的詞

| 名詞 | 誰買的 | 保什麼 |
|---|---|---|
| **責任保險**（旅行業責任保險） | **旅行社依法一定要買** | 旅客在旅途中發生**意外**（例如車禍）死亡、受傷時，保險公司理賠 |
| **履約保證保險** | **旅行社依法一定要買** | 旅行社**倒閉、跑路**，沒辦法讓你出團時，保險公司賠你繳的團費 |
| **旅行平安險**、**旅遊不便險** | **旅客自己決定要不要買** | 保自己的意外、班機延誤、行李遺失等 |

「履約」＝履行契約，就是「照著契約做到」。「履約保證」＝保證旅行社會做到，做不到由保險公司賠。

## 2　旅遊契約有「兩層」規定

旅客和旅行社之間的規則，由兩層規定組成：

| 層級 | 名稱 | 誰訂的 | 特色 |
|---|---|---|---|
| 第一層（大原則） | **民法債編第八節之一「旅遊」**，簡稱「**民法旅遊專節**」，第 514 條之 1～之 12 | 立法院（法律） | 只有 12 條，講大原則，**幾乎沒有數字** |
| 第二層（細節） | **國外旅遊定型化契約應記載及不得記載事項**（105 年 9 月 13 日交通部公告修正）＋**國外旅遊定型化契約書範本** | 交通部（行政命令） | 很多**具體數字**：幾天、幾 %、幾倍 |

::: info
**為什麼要兩層？** 民法是大家都要遵守的基本法律，不可能寫得太細；所以政府再訂「定型化契約」的規定，把細節（例如取消要賠幾 %）寫清楚。

**考試的分法：**

- 題目寫「**依民法規定**」→ 想第一層，通常問「誰有什麼權利」
- 題目寫「**依國外旅遊定型化契約規定**」→ 想第二層，通常是**計算題**
:::

### 幾個大原則（先記住，遇到不會的題目可以用來猜）

1. **去中國大陸、香港、澳門的團，也是用「國外」旅遊定型化契約。**（另外還有一份「國內」旅遊定型化契約，是在臺灣玩用的，領隊考試考的是「國外」那份。）
2. **契約內容如果比規定「更有利於旅客」，就照契約。** 規定只是最低標準，旅行社願意給更好的條件，當然可以。
3. **所有規定的方向都是「保護旅客」。** 因為旅客是一般人，旅行社是專業公司，兩邊實力不對等，所以法律站在旅客這邊。

::: tip
**猜題技巧：** 題目卡住時，選「**對旅客比較好**」的選項，通常就是對的。
:::

## 3　民法旅遊專節：12 條逐條講解

這 12 條都要懂。每條會先講規定，再用白話和例子說明。

### 第 514 條之 1　什麼叫「旅遊營業人」？

**規定：** 旅遊營業人，是指以提供旅客旅遊服務為營業、並收取旅遊費用的人。旅遊服務是指：**安排旅程**，以及提供**交通、膳宿、導遊或其他有關的服務**。

::: plain
**白話：** 只要是「幫人安排行程＋交通、吃住、導遊，並且收錢做生意」的，就是旅遊營業人。「膳宿」的「膳」是吃飯，「宿」是住宿。
:::

::: exam
**考古題（114年）：** 下列何者**不屬於**旅遊營業人提供的基本服務？
答案是「**提供旅客財產證件保管服務**」。保管證件不在定義裡面（定義只有安排旅程、交通、膳宿、導遊）。
:::

### 第 514 條之 2　旅客可以要求「寫成書面」

**規定：** 旅客要求的時候，旅行社要用**書面**記載下列事項交給旅客：

1. 旅行社的名稱和地址
2. 旅客名單
3. 旅遊地區和旅程
4. 旅行社提供的交通、膳宿、導遊或其他服務，以及它們的**品質**
5. **旅遊保險的種類和金額**
6. 其他有關事項
7. 填發的年月日

::: plain
**白話：** 旅客有權要求旅行社「白紙黑字寫清楚」，才不會事後吵說「當初明明說好……」。注意清單裡有「**保險的種類和金額**」。
:::

### 第 514 條之 3　旅客要「配合」（協力義務）

**規定：** 有些事一定要旅客自己做，旅遊才能完成（例如提供照片、護照去辦簽證）。旅客不做，旅行社可以**定一段合理時間催告**；催了還是不做，旅行社可以**終止契約**，並要求賠償損失。
如果是**旅遊開始後**才終止，旅客可以要求旅行社**墊付**費用把他送回出發地，到了以後旅客要**附加利息還給旅行社**。

::: plain
**白話：** 「協力」＝幫忙配合。辦簽證一定要旅客本人的照片，旅客一直不交，旅行社怎麼催都沒用，旅行社就可以說：「那這個契約我們不做了，你還要賠我損失。」
:::

::: trap
**陷阱：** 這種情況是「**旅行社**」可以終止契約，不是旅客。
**考古題（113年）：** 問「旅客得隨時終止契約」的情形，哪個錯？答案是「旅客不配合繳交簽證大頭照，經催告仍不配合」——這是**旅行社**可以終止，不是旅客。
:::

### 第 514 條之 4　出發前可以「換人去」

**規定：** 旅遊開始前，旅客可以換**第三人**參加。旅行社**沒有正當理由不能拒絕**。
換人如果**增加費用**，旅行社可以向那位第三人收；如果**減少費用**，旅客**不能要求退**。

::: example
**例子：** 小美不能去，換她媽媽去。

- 媽媽要多辦一個簽證，多 1,000 元 → 旅行社可以向**媽媽**收 1,000 元
- 小美原本要加床，媽媽不用，省下 500 元 → 小美**不能**要求退 500 元
:::

::: plain
**為什麼？** 換人是旅客自己的需求，旅行社已經配合了，所以「多的錢你出、少的錢不退給你」。
**「正當理由」的例子：** 換的人不能辦該國簽證、機票不能改名等。
:::

::: exam
**考古題（112年）：** 旅客要求改由兒子參加，如果因此減少費用，怎麼處理？
答：**旅客不得請求退還減少的費用**。
:::

### 第 514 條之 5　旅行社「不能隨便改行程」

**規定：** 旅行社**沒有不得已的理由，不能變更旅遊內容**。
因為不得已的理由變更時：

- **減少的費用 → 要退給旅客**
- **增加的費用 → 不能向旅客收**

旅客不同意變更，可以**終止契約**，並要求旅行社**墊付**費用送他回出發地，到達後**附加利息償還**。

::: example
**例子：** 原本要去的景點因為土石流封路（不得已），改去另一個景點。

- 新景點門票比較便宜，便宜 300 元 → 退給旅客 300 元
- 新景點門票比較貴，貴 500 元 → 旅行社自己吸收，**不能**跟旅客收
:::

::: trap
**陷阱：** 「墊付」不是旅行社出錢，是**先借**，旅客回國後要**還錢加利息**。
**對照：** 514-4（旅客換人）是「增加的向第三人收」；514-5（旅行社改行程）是「增加的不能收」。方向剛好相反，因為一個是旅客的需求，一個是旅行社那邊的變動。
:::

### 第 514 條之 6　服務要有「通常的價值和約定的品質」

**規定：** 旅行社提供的旅遊服務，要具備**通常之價值**及**約定之品質**。

::: plain
**白話：**

- 「**通常之價值**」＝一般人認為這個價錢應該有的水準
- 「**約定之品質**」＝契約、廣告上說好的水準
說好五星級，就要給五星級。
:::

::: exam
**考古題（112年）：** 對於旅遊服務，依民法哪個正確？答：「**旅遊服務應符合通常之價值及約定之品質**」。
:::

### 第 514 條之 7　品質不夠怎麼辦？（三步驟）

**規定：** 服務沒有達到 514-6 的標準時：

1. 旅客可以先要求旅行社**改善**
2. 旅行社**不改善或沒辦法改善** → 旅客可以要求**減少費用**
3. 嚴重到旅遊**很難達到預期目的** → 旅客可以**終止契約**

如果是**可歸責於旅行社**（旅行社的錯），旅客**還可以要求損害賠償**；終止契約時，旅行社要把旅客送回出發地，**費用由旅行社負擔**。

::: example
**例子一（旅行社的錯）：** 旅行社作業疏失，把直飛班機訂成轉機班機。旅客可以**主張減少費用**，也可以請求損害賠償。（113年考題）

**例子二（不是旅行社的錯）：** 五星級飯店突然失火，當地沒有其他五星級，只好改住次一級飯店。

- 旅客可以要求**減少費用**（差價要退）
- 但**不能**要求**損害賠償**，因為失火不是旅行社的錯（111年考題）
:::

::: tip
**重點：** 「損害賠償」只有在「**可歸責於旅行社**」時才能要。不是旅行社的錯，最多只能退差價。
:::

### 第 514 條之 8　時間被浪費，按天賠

**規定：** 因為**可歸責於旅行社**，行程沒有照約定進行，旅客可以就**浪費的時間**要求**按日賠償**。每天的賠償金額，**不能超過「團費總額 ÷ 旅遊天數」**。

::: example
**例子：** 團費 50,000 元、5 天，旅行社訂錯機票，害大家在機場等了一整天。
每天最多賠 50,000 ÷ 5 ＝ **10,000 元**。
:::

### 第 514 條之 9　旅客「隨時」可以終止，但要賠

**規定：** 旅遊還沒結束前，旅客**隨時可以終止契約**，但要**賠償旅行社因此受到的損失**。

::: plain
**白話：** 旅客玩到一半不想玩了，可以走，但不能要求退錢（旅行社已經付了飯店、機票），還可能要賠旅行社。詳細規定看後面第 7-5 節。
:::

### 第 514 條之 10　旅途中出事，旅行社要幫忙

**規定：** 旅客在旅途中**身體或財產**發生事故時，旅行社要**提供必要的協助和處理**。
如果事故**不是旅行社的錯**，產生的費用**由旅客負擔**。

::: example
**例子：** 小美在旅途中心臟病發作被送醫。

- 領隊和旅行社**一定要幫忙**：叫救護車、陪同就醫、聯絡家屬、翻譯
- 但醫藥費、家屬飛過來照顧的機票和住宿費，**由小美自己付**（心臟病不是旅行社的錯）（112年考題）
:::

::: exam
**對照（111年考題）：** 如果事故**是**旅行社的錯（例如旅行社安排的車子沒有保養好出車禍），協助處理的費用由**旅行社**負擔。
:::

### 第 514 條之 11　在旅行社帶去的店買到瑕疵品

**規定：** 旅行社安排旅客到特定場所購物，買到的東西有**瑕疵**，旅客可以在**收到商品後 1 個月內**，請旅行社**協助處理**。

::: plain
**白話：** 「瑕疵」＝東西有缺陷、壞掉、跟說好的不一樣。因為店是旅行社帶去的，旅行社有責任幫忙處理（例如幫忙聯絡店家退換）。
**1 個月**，題目有時會寫成「**30 天**」，是一樣的意思。
:::

### 第 514 條之 12　要錢的權利，1 年內要用

**規定：** 下列這些請求權，從**旅遊終了**（結束）或**應終了時**（本來應該結束的那天）起，**1 年**不行使就**消滅**：

- 增加、減少或退還費用的請求權
- 損害賠償請求權
- 墊付費用償還請求權（旅行社要旅客還墊付的錢）

::: trap
**陷阱：** 是從「**旅遊結束**」開始算 1 年，不是從「**簽約日**」或「**出發日**」算。
:::

## 4　整章最重要的觀念：「是誰的錯？」

幾乎每一題都要先判斷：這件事是**誰的錯**？

| 情況 | 例子 | 結果 |
|---|---|---|
| **可歸責於旅行社**（旅行社的錯） | 忘記訂飯店、機位沒訂到、員工算錯時間、派了沒執照的領隊 | 旅行社要負擔費用，還要付**違約金**，甚至**損害賠償** |
| **不可抗力／不可歸責於雙方**（沒有人的錯） | 颱風、地震、罷工、飯店失火、班機因天候延誤 | 旅行社可以改行程，**不用賠**；但**增加的費用不能收、減少的費用要退** |
| **可歸責於旅客**（旅客的錯） | 遲到沒趕上、不交護照、自己中途離隊 | 旅客自己負擔，不能要求退費 |

::: tip
**解題三步驟：**

1. 先看題目情況是**誰的錯**
2. 再看是**出發前**還是**出發後**
3. 最後找對應的規定和數字
:::

## 5　定型化契約：簽約的時候

以下是「國外旅遊定型化契約應記載及不得記載事項」（以下簡稱「**定型化契約**」）的內容，照著「簽約 → 出發前 → 出發後」的時間順序來講。

### 5-1　審閱期：至少 1 天

**規定：** 契約要給旅客**至少 1 天**的時間把契約帶回去看清楚（審閱）。
違反的話，契約條款**不算數**；但旅客如果覺得條款對自己有利，**可以主張還是算數**。

::: plain
**白話：** 「審閱」＝仔細看過、檢查。旅行社不能逼你當場簽，要讓你帶回家看一天。
**為什麼「旅客可以主張還是算數」？** 因為這條是保護旅客的，所以選擇權在旅客手上：對旅客不利的條款可以不認，對旅客有利的可以照用。
:::

::: exam
**考古題（114年）：** 國外旅遊定型化契約的審閱期至少幾日？答：**1 日**。
:::

### 5-2　廣告也是契約的一部分

**規定：** 旅行社要確保廣告內容真實，對旅客的義務**不能低於廣告**。廣告、宣傳文件（DM）、行程表、說明會講的內容，**都算是契約的一部分**。
如果契約沒寫清楚，或契約跟廣告寫的不一樣，**以對旅客最有利的為準**。

::: example
**例子：** 網路廣告寫「全程五星級飯店」，契約卻寫「四星級飯店」。
→ 以**五星級**為準（對旅客最有利）。
:::

### 5-3　簽約地點和日期

| 沒寫的時候 | 以什麼為準 |
|---|---|
| 沒寫**簽約地點** | **旅客的住（居）所地**（旅客住的地方） |
| 沒寫**簽約日期** | **旅客第一次付錢的那天** |

::: plain
**白話：** 「住所」是戶籍、長期住的地方；「居所」是暫時住的地方。寫在一起就是「旅客住的地方」。
**為什麼簽約地點重要？** 以後如果打官司，會影響在哪個法院告。以旅客住的地方為準，旅客比較方便。
:::

::: exam
**考古題（113年）：** 未記載簽約地點，以何者為準？答：**旅客住（居）所地**。
:::

### 5-4　行程和購物

- 契約要寫清楚：去哪些地區、城市、景點，出發和回程的地點、日期、**交通工具、住宿旅館、餐飲、遊覽**。
- 有安排**購物行程**，一定要寫清楚。
- 旅途中旅行社**不能臨時加購物行程**，除非**旅客要求或同意**。

::: plain
**為什麼特別管購物？** 有些旅行社會用很便宜的團費吸引人，再靠帶旅客去購物店抽佣金賺錢，旅客整天被帶去買東西。所以法規規定要先講清楚，不能臨時加。
:::

### 5-5　團費包含什麼、不包含什麼

這是常考題。先看正式規定的清單：

| ✔ 包含在團費裡 | ✘ 不包含在團費裡 |
|---|---|
| 代辦證件的**行政規費**（例如簽證費） | 旅客的**個人費用**（例如自己買的飲料、紀念品、洗衣費） |
| **交通運輸費**（機票、遊覽車，含機場服務費、稅） | **建議**給**領隊、導遊、司機**的**小費** |
| **餐飲費** | 契約明列為**自費行程**的費用 |
| **住宿費** | 其他由旅行社**代辦代收**的費用 |
| **遊覽費**（門票等） | |
| **接送費**（機場接送等） | |
| **領隊**及其他服務人員的**報酬**（薪水） | |
| **保險費**（旅行社依法投保的**責任保險、履約保證保險**） | |

名詞說明：

- **自費行程**：契約上註明「想參加的人另外付錢」的活動，例如自費的溫泉、表演秀。
- **代辦代收**：旅行社幫忙代收、再轉交給別人的錢，例如幫你代買的特殊門票。
- **小費**：給服務人員的額外感謝金。在很多國家是習慣，但是是「**建議**」給的，**不在團費裡**。

::: trap
**三大陷阱：**

1. 領隊的「**報酬**」（薪水）**有**包含在團費裡；給領隊的「**小費**」**沒有**包含。
2. 團費裡的「保險費」是旅行社依法一定要買的**責任保險、履約保證保險**；旅客自己加買的「**旅行平安險、意外險**」**不包含**。
3. 行政規費（例如簽證費）**有**包含在團費裡。
:::

::: exam
**考古題（114年）：** 團費涵蓋的項目，**不包括**何者？答：「**旅行平安險或意外險**」。
:::

### 5-6　簽約後機票漲價怎麼辦？（10% 規則）

**規定（範本第 8 條）：** 簽約後，因為**政府機關**或**航空公司**等調整價格，導致交通運輸費或遊覽費的增減**超過 10%**：

- **漲價** → 旅客要**補足**（補差額）
- **降價** → 旅行社要**退還**

::: example
**例子（111年考題）：** 王小姐報名北海道 5 日遊，團費 38,900 元，其中機票 18,000 元。後來油價上漲，機票漲到 21,000 元。

1. 漲了多少？21,000 − 18,000 ＝ **3,000 元**
2. 漲幅多少？3,000 ÷ 18,000 ＝ **16.7%**
3. 有沒有超過 10%？**有**
4. 所以旅客要補足差價 **3,000 元**

注意：比例是用「**機票原價**」去算，不是用整個團費去算。
:::

::: exam
**考古題（114年）：** 交通運輸費或遊覽費的增減超過多少%，應由旅客補足或旅行社退還？答：**10%**。
:::

### 5-7　旅客不繳錢怎麼辦？

**規定：** 因為旅客的原因**拖延不繳團費**，旅行社可以定一段時間**催告**；過期還不繳，旅行社可以**終止契約**，旅客要照取消的賠償表（第 6-2 節）賠償。

### 5-8　其他簽約時要寫的事

- **當事人資料：** 旅客姓名、電話、地址；旅行社公司名稱、**註冊編號**、負責人等。還要寫**旅客的緊急聯絡人**（姓名、關係、電話），出事時才找得到家人。
- **付款方式：** 簽約時付多少、餘款（尾款）多少、什麼時候付。
- **集合時間和地點：** 要寫清楚。

## 6　定型化契約：出發前取消

### 6-1　人數不夠，沒辦法成團

一個團要有一定人數才划算（例如遊覽車、領隊的成本要大家分攤），所以契約會寫「**最低組團人數**」。

**規定：**

- 人數不夠時，旅行社**至少在出發前 7 天**通知旅客解除契約。（契約沒寫天數 → 當作 **7 天**）
- 旅行社**拖延沒通知**，害旅客受到損害 → 要賠償
- 契約**沒寫最低人數**，或廣告寫「**保證出團**」→ 當作**沒有最低人數**，人再少也要出團。不出團，就是旅行社違約。

**取消後的錢怎麼處理（擇一）：**

1. **全部退還**給旅客（已經代繳的**行政規費可以扣掉**）
2. 經旅客**同意**，把這筆錢轉去參加**另一個團**，多的退還

::: plain
**為什麼保證出團就沒有最低人數？** 因為旅行社已經對外承諾「一定會出團」，旅客是看到這個保證才報名的，旅行社就要做到。
:::

### 6-2　賠償比例表（每年必考！一定要背）

這張表用在兩種情況，**比例完全一樣**：

- **旅客自己取消**（任意解除契約，第 13 點）→ 旅客賠旅行社
- **因為旅行社的錯不能出團**（第 12 點）→ 旅行社賠旅客

| 通知取消的時間（距出發日） | 賠償團費的 |
|---|---|
| 出發前第 **41** 天以前 | **5%** |
| 出發前第 **31～40** 天 | **10%** |
| 出發前第 **21～30** 天 | **20%** |
| 出發前第 **2～20** 天 | **30%** |
| 出發前 **1** 天 | **50%** |
| 出發**當天**或之後（或旅客沒通知就不來） | **100%** |

::: tip
**口訣：** 「**41、31、21、2、1、0**」對「**5、10、20、30、50、100**」
天數記法：40、30、20 的「下一天」開始換級，最後剩 1 天、0 天。
百分比記法：5 → 10 → 20 → 30 → 50 → 100，越接近出發日，賠越多（因為旅行社越來越難把位子賣給別人）。
:::

**補充規定：**

1. 旅行社因為自己的錯不能出團，**卻沒有通知**旅客（怠於通知）→ 賠 **100%**。
2. 不管哪一方，如果能**證明實際損失比表上的比例還多**，可以要求賠實際損失。
3. **旅客取消時，要先把行政規費扣掉再算比例**，行政規費另外付。

**旅客取消的計算公式：**

> **賠償金 ＝（團費 − 行政規費）× 比例**

另外再付行政規費（因為這筆錢已經交給政府了）。

#### 怎麼算「距出發日幾天」？

用「**出發日 − 通知日**」。例如 8 月 30 日出發，8 月 5 日通知 → 30 − 5 ＝ **25 天** → 落在「21～30 天」→ **20%**。

#### 計算題示範

::: example
**例 1（112年考題）：** 張先生繳了團費 35,000 元，參加 8 月 30 日出發的新加坡 5 日遊。8 月 5 日通知取消。旅行社應退他多少？

1. 距出發日：30 − 5 ＝ 25 天 → **20%**
2. 要賠：35,000 × 20% ＝ 7,000 元
3. 退還：35,000 − 7,000 ＝ **28,000 元**
:::

::: example
**例 2（114年考題）：** 王姓夫婦參加德瑞十日遊，每人團費 80,000 元，在出發前第 41 天取消**兩個人**的契約。要賠多少？

1. 第 41 天以前 → **5%**
2. 兩個人：80,000 × 2 ＝ 160,000
3. 160,000 × 5% ＝ **8,000 元**

陷阱：別忘了是**兩個人**。
:::

::: example
**例 3：** 小美團費 31,000 元，其中簽證費（行政規費）1,000 元。出發**前一天**取消。

1. 先扣行政規費：31,000 − 1,000 ＝ 30,000
2. 前 1 天 → **50%**：30,000 × 50% ＝ 15,000 元
3. 小美要付：賠償 15,000 ＋ 行政規費 1,000 ＝ 16,000 元
4. 退給小美：31,000 − 16,000 ＝ **15,000 元**
:::

::: example
**例 4（113年考題）：** 甲在旅展繳 3 萬元報名乙旅行社的海外 5 日團，乙在現場廣告**保證出團**。出發前 3 天，因為乙的錯沒訂到機位，不能出團，**乙卻沒有通知甲**，甲出發當天到機場才發現。

1. 保證出團 → 沒有最低人數的藉口
2. 是乙的錯，又**沒通知** → 賠 **100%**
3. 乙要退還 3 萬元團費，**另外再賠違約金 3 萬元**
:::

::: example
**例 5（111年考題）：** 出發 3 天前，蔡小姐因家庭因素取消 → 落在「2～20 天」→ **30%**。
**例 6（111年考題）：** 出發 3 週（21 天）前取消，旅行社說是「包機行程」想多扣 → 還是照表賠 **20%**；旅行社如果能**證明**實際損失更多，才能多要。
:::

### 6-3　遲到沒趕上，等於自己取消

**規定：** 旅客沒有準時到集合地點，害自己**沒趕上出發**，也**沒辦法中途加入**，就當作旅客**任意解除契約**（照 6-2 的表，當天 → 100%）。

### 6-4　不是任何人的錯（不可抗力）

**規定：** 因為**不可抗力**，或是**不可歸責於雙方**的原因，契約全部或一部分沒辦法履行，**任何一方**都可以解除契約，而且**都不用賠償**。

旅行社可以扣掉**已經代繳的行政規費**和**已經付出去的必要費用**（要拿出**單據**證明），剩下的退給旅客。
知道不能成行的一方，要**馬上通知**對方；拖延沒通知，害對方受損，要賠。

::: example
**例子：** 出發前，目的地發生大地震，機場關閉。
→ 雙方都可以解約、都不用賠。旅行社拿出單據證明已經付了 2,000 元簽證費，就可以扣掉 2,000 元，其他退還。
:::

::: exam
**考古題（112年）：** 出發前因不可抗力解約，哪個敘述錯？答：「旅行社依規定解除契約後，其已支出之必要費用，應由**旅行社**負擔」——錯！已支出的必要費用可以**扣除**（等於由旅客負擔）。
:::

### 6-5　目的地「可能有危險」（客觀風險）

**規定：** 出發前，要去的地方**有事實足以認為**可能危害旅客的**生命、身體、健康、財產安全**（例如：當地傳染病流行、暴動、恐怖攻擊威脅），可以解除契約。但**提出解除的那一方**，要另外補償對方團費的一定比例，**最多 5%**。

| | 不可抗力（6-4） | 客觀風險（6-5） |
|---|---|---|
| 狀況 | **確定**沒辦法去（機場關了、地震） | **還能去**，但**可能有危險** |
| 要不要補償對方 | 不用 | 提出解除的人補償對方，**最多 5%** |

::: plain
**為什麼客觀風險要補償？** 因為行程「理論上還可以走」，是其中一方覺得危險想取消，造成另一方損失，所以補一點，但上限 5%，不會太多。
:::

::: exam
**考古題（113年）：** 有事實足認危害旅客安全之虞，解除的一方應補償他方，不得超過百分之多少？答：**5%**。
:::

### 6-6　旅行社要把契約「轉讓」給別家

「轉讓」＝旅行社把你的團「交給另一家旅行社」來辦，常見於人數不夠，把幾家的客人併成一團（業界叫「**併團**」）。

**規定：**

- **出發前**要轉讓，一定要經旅客**書面同意**。旅客不同意，可以解約，旅行社要**全額退費**，旅客有損失還可以要求賠償。
- 旅客**出發後**才發現（或才被告知）被轉讓 → 旅行社賠**團費 5%** 的違約金。
- 出發後才發現被轉讓，接手的旅行社出錯，旅客**也可以找原本那家旅行社負責**。

### 6-7　換人參加

和民法 514-4 一樣：出發前，旅客不能參加，可以換第三人參加，旅行社沒正當理由不能拒絕；增加的費用向第三人收，減少的不退。

## 7　定型化契約：出發後出狀況

### 7-1　違約金倍數總表（這張表一定要背）

| 狀況（都是**旅行社的錯**） | 要賠多少 |
|---|---|
| **飯店、交通、餐食、景點沒照約定**（例如五星級變三星級） | 差額 × **2 倍**；旅行社沒提出差額說明 → 至少**團費 5%** |
| **行程延誤**，浪費時間 | 每天賠「團費 ÷ 天數」，按天數算；**5 小時以上未滿 1 天，算 1 天** |
| **故意**把旅客丟下或留在當地（棄置、留滯） | 每天金額 × 天數 × **5 倍** |
| **重大過失**棄置、留滯 | × **3 倍** |
| **過失**棄置、留滯 | × **1 倍** |
| 害旅客被**恐怖分子留置**、被**當地政府逮捕羈押** | **每天 2 萬元**（懲罰性違約金） |
| 出發後才發現被**轉讓** | **團費 5%** |
| 派**沒有領隊執業證**的領隊 | **1,500 元 × 天數 ÷ 實際出團人數 × 3 倍**（每位旅客） |
| 旅行社**沒有依規定投保**責任保險或履約保證保險 | 最低投保金額的理賠金額 × **3 倍** |

名詞說明：

- **棄置**：把旅客丟下不管。
- **留滯**：讓旅客被困在當地走不了。
- **逮捕羈押**：被警察抓、被關起來。
- **領隊執業證**：通過領隊考試、受完訓練後拿到的證照，有這張證才能合法當領隊（第三章會詳細講）。

### 7-2　計算題示範（照著做一遍）

::: example
**① 行程延誤（114年考題）**
甲繳團費 15 萬元參加 10 日團。回程日因為旅行社作業疏失，沒搭上原本 **11:00** 的飛機，只能改搭**隔天 20:00** 的飛機。旅行社要賠多少？

1. 延誤多久？從第一天 11:00 到第二天 11:00 是 24 小時（1 天），再到 20:00 多 9 小時 → 共 **1 天 9 小時**
2. 9 小時 ≥ 5 小時 → 算 1 天 → 共 **2 天**
3. 每天：150,000 ÷ 10 ＝ 15,000 元
4. 賠：15,000 × 2 ＝ **30,000 元**
:::

::: example
**② 故意留滯（113年考題）**
呂先生參加 6 日團，團費 3 萬元，旅行社**故意**把他留在國外 1 天。違約金多少？

1. 每天：30,000 ÷ 6 ＝ 5,000 元
2. 故意 → × 5 倍
3. 5,000 × 1 天 × 5 ＝ **25,000 元**
（另外還要負擔他被留滯期間的食宿、回國交通等費用。）
:::

::: example
**③ 沒有執業證的領隊**
5 天團，實際出團 20 人，旅行社派了沒執業證的領隊。每位旅客可以拿多少？

1,500 × 5 ÷ 20 × 3 ＝ **1,125 元**
:::

::: example
**④ 沒投保責任保險（113年考題）**
旅行社的責任保險過期沒續保，旅客車禍意外死亡。旅行社要賠多少？

1. 責任保險「意外死亡」的最低投保金額是 **250 萬元**（第三章會講）
2. × 3 倍 ＝ **750 萬元**
:::

::: example
**⑤ 住錯飯店＋延誤（115年考題）**
團費 20 萬元、10 日團。旅行社的錯：飯店價差 4,000 元，回程又延誤（算 2 天）。

1. 飯店：4,000 × 2 倍 ＝ 8,000 元
2. 延誤：200,000 ÷ 10 × 2 ＝ 40,000 元
3. 合計：**48,000 元**
:::

### 7-3　不是旅行社的錯，行程要改

**規定：** 旅途中因為**不可抗力**或**不可歸責於旅行社**的原因（例如颱風、罷工、群眾抗議、班機因天候延誤），沒辦法照原本的行程走，旅行社**為了團體的安全和利益**，可以變更行程、景點、食宿。

- **增加的費用 → 不能向旅客收**
- **減少的費用 → 要退給旅客**
- 旅客**不同意**變更 → 可以**終止契約**，要求旅行社**墊付**費用送回出發地，到達後**附加利息償還**。

::: exam
**考古題（111年）：** 因當地群眾抗議變更行程，哪個敘述錯？答：「所增加之費用得要求旅客負擔」——錯！增加的**不能**向旅客收。
:::

::: example
**考古題（113年）：** 王媽和李姨參加金廈 5 日團，出發當天班機**因天氣不好**延誤 5 小時。旅行社為了如期完成行程變更內容，李姨不同意而終止契約。
→ 旅行社要依李姨的請求**墊付**費用送她回出發地，李姨回到臺北後要**附加利息還給旅行社**。
:::

### 7-4　旅行社的錯，害旅客沒辦法完成部分行程

**規定：** 出發後，因為**旅行社的錯**（例如簽證沒辦好、機票有問題），旅客有一部分行程沒辦法完成：

- 旅行社要**自己出錢**安排旅客到**下一個旅遊地**跟其他團員會合
- 全團都沒辦法完成 → 安排相當的**替代行程**
- 沒有下一個旅遊地 → 安排旅客**回國**
- 等待期間的食宿交通費，**旅行社負擔**
- 旅行社都沒安排 → 退還沒去的地方的費用，**再賠同樣金額的懲罰性違約金**

### 7-5　旅客中途離隊（自己不玩了）

**規定：**

- 旅客出發後**中途離隊**退出，**不能要求退還團費**。
- 但旅行社因為旅客離開而**省下來、不用付的錢**（例如之後幾天的餐費、門票還沒付），**要退還**。
- 旅行社要幫旅客安排回出發地的住宿和交通，**費用由旅客自己付**。

::: plain
**白話：** 不是「按比例退」！5 天團玩 2 天走掉，不能要求退 3/5 團費。只能退旅行社「真的省下來」的錢（例如飯店、機票已經付了就退不了）。
:::

### 7-6　旅客沒趕上行程

**規定：** 出發後，旅客自己**沒趕上**某個行程（例如睡過頭沒參加早上的景點），就當作**自願放棄**，**不能要求退費或補償**。

::: exam
**考古題（113年）：** 旅客未能及時參加排定行程，哪個正確？答：**視為自願放棄其權利，不得要求退費或任何補償**。
:::

### 7-7　旅客不配合，害行程走不下去

**規定：** 出發後，旅客不配合旅行社完成旅遊需要的事（例如不肯拿出護照過海關），影響後面行程而終止契約，旅客可以要求旅行社**墊付**費用送他回去，到達後**附加利息償還**，旅行社**不能拒絕**。旅行社省下的錢要退，旅行社受到的損失可以向旅客要求賠償。

### 7-8　旅客在旅途中出事

**規定：** 旅客在旅途中**身體或財產**發生事故，旅行社要用**善良管理人的注意**提供必要的協助處理。事故**不是旅行社的錯** → 費用**由旅客負擔**。（和民法 514-10 一樣）

::: exam
**考古題（111年）：** 旅遊期間因不可歸責於旅行社的事由，旅客受到損害，哪個敘述錯？答：「搭乘遊覽車發生車禍，應由遊覽車公司**直接**對旅客負責……」——錯！遊覽車公司是旅行社的**履行輔助人**，旅行社**要負責**（契約明定旅行社對履行輔助人的行為負責，不能推給遊覽車公司）。
:::

## 8　其他常考規定

### 8-1　領隊

- 旅行社**一定要派有「領隊執業證」的領隊**。
- 領隊要帶旅客出國，幫旅客辦**出入境手續**、處理**交通、食宿、遊覽**，以及其他完成旅遊需要的事，**來回全程隨團服務**。
- 違反（派沒有執業證的人）→ 每位旅客 **1,500 元 × 天數 ÷ 實際出團人數 × 3 倍**。

::: example
**考古題（113年）：** 派未領有領隊執業證的領隊，每人每日新臺幣多少元、幾倍？答：**1,500 元，3 倍**。
:::

### 8-2　證照的保管

- 旅行社幫旅客辦手續（例如辦簽證）時，要**好好保管**旅客的證件。
- 遺失或損壞 → 旅行社要**主動補辦**；造成旅客損失 → 要賠償。
- 保管證件要盡「**善良管理人之注意**」。
- 旅客**隨時可以拿回**自己的證件，旅行社**不能拒絕**。

::: plain
**白話：** 證件（護照）是旅客自己的。旅途中原則上**旅客自己保管**；為了過海關方便，或旅客同意，可以暫時交給領隊統一保管，但旅客想拿回來，領隊不能說不。
:::

### 8-3　國外合作業者出錯

旅行社委託**國外的旅行社、飯店、餐廳、遊覽車**（履行輔助人）做事，他們出錯，國內旅行社要負**同樣的責任**，不能說「是國外那家的錯，不關我的事」。

### 8-4　保險

- 旅行社**一定要**投保**責任保險**和**履約保證保險**，並在契約寫明保險公司名稱、金額。
- 沒寫 → 照主管機關規定的金額。
- 沒投保 → 出事時賠「最低投保金額 × **3 倍**」。

### 8-5　購物

- 旅途中**不能臨時安排購物**（除非旅客要求或同意）。
- 在旅行社安排的店買到瑕疵品 → **1 個月內**可以請旅行社協助處理。

### 8-6　個人資料

- 旅客同意旅行社為了辦證件、訂機票飯店等目的，蒐集和使用他的**個人資料**（姓名、生日、護照號碼等）。
- 旅行社要**保密**，沒經旅客**書面同意**不能給別人。
- 旅遊結束、目的消失 → 要**刪除**。
- 個資**外洩**（被偷、被竄改、遺失）→ 旅行社要**馬上通報主管機關**，查原因，並用書面、簡訊等方式**通知旅客**。

### 8-7　吵架了怎麼辦（消費爭議）

「**消費爭議**」＝消費者（旅客）和業者（旅行社）之間的糾紛。

- 契約要寫清楚**申訴的方式和聯絡資訊**。
- 可以申訴的地方：
    - **交通部觀光署**（管旅行社的政府機關）
    - 各縣市政府的**消費者保護官**（消保官）
    - **中華民國旅行業品質保障協會**（簡稱「**品保協會**」，旅行社組成的團體，會幫忙調解旅遊糾紛）
- **注意：** 「旅行業商業**同業公會**」（例如台北市旅行商業同業公會）**不是**受理旅遊糾紛申訴的管道。
- **消保法規定：** 業者收到消費者申訴，要在 **15 天內**妥善處理。

### 8-8　打官司的法院

契約裡雙方可以約定發生糾紛要去哪個法院打官司（叫「**合意管轄法院**」），但**不能排除**「**小額訴訟**」的規定。

::: plain
**白話：** 「小額訴訟」是金額不大（10 萬元以下）的官司，程序比較簡單，旅客可以在比較方便的法院提告。旅行社不能用契約條款把這個權利拿掉。
:::

### 8-9　沒簽書面契約會被罰

依「旅行業管理規則」：

- 旅行社辦理團體或個別旅遊，**一定要跟旅客簽書面契約**；也可以用**電子簽章**的電子文件（線上簽約）。
- 旅行社把觀光署的**定型化契約範本**公開、並印在給旅客的「**代收轉付收據**」上交給旅客，除非另有約定，就**當作已經簽約**。（代收轉付收據＝旅行社收團費時開的收據，因為團費大部分是代旅客轉付給航空公司、飯店，所以叫「代收轉付」。）
- 旅遊契約書、旅客交付的文件、繳費收據要**保管 3 年**，讓觀光署查核。
- 沒有跟旅客簽書面契約 → 依「發展觀光條例」，罰 **1 萬元以上、5 萬元以下**。（112年考題）

## 9　不得記載事項（看到就是錯的）

以下這些內容**不能寫在契約裡**，寫了也**無效**：

| # | 不得記載 | 白話 |
|---|---|---|
| 1 | 行程、住宿、交通、價格、餐飲等寫「**僅供參考**」或其他不確定的字眼 | 不能寫得模模糊糊讓旅行社可以亂改 |
| 2 | 旅行社的義務**排除**原本刊登的廣告內容 | 不能說「廣告寫的不算」 |
| 3 | **排除**旅客任意解除、終止契約的權利 | 不能說「報名後不能取消」 |
| 4 | **超過**主管機關規定的旅客**最高賠償**基準 | 不能要旅客賠得比規定還多 |
| 5 | 旅客對旅行社**片面變更**契約**不得異議** | 不能說「旅行社想改就改，旅客不能有意見」（片面＝只有一方決定） |
| 6 | 團費以外，用其他方式**變相或額外加價** | 不能偷偷加錢 |
| 7 | 旅行社**委託旅客代為攜帶物品回國** | 不能叫旅客幫忙帶東西回國（可能是走私） |
| 8 | **免除或減輕**依法應負的義務 | 不能寫「旅行社不負任何責任」 |
| 9 | 其他違反**誠信原則**、**平等互惠原則**，對旅客不利的約定 | 誠信＝誠實守信用；平等互惠＝對雙方公平 |
| 10 | **排除**對**履行輔助人**所生責任的約定 | 不能寫「國外業者出錯，與本公司無關」 |

## 10　容易搞混的地方總整理

| 容易搞混 | 正確說法 |
|---|---|
| 「解除」和「終止」 | 解除：從頭取消（多在出發前）；終止：從現在停止（多在出發後） |
| 「違約金」和「損害賠償」 | 違約金：事先說好的金額，不用證明損失；損害賠償：要證明實際損失 |
| 「墊付」 | 旅行社先出錢，旅客到達後**附加利息償還**，不是旅行社送的 |
| 換人參加（514-4）的費用 | 增加 → 向**新參加的人**收；減少 → **不退** |
| 旅行社不得已變更（514-5、7-3）的費用 | 增加 → **不能收**；減少 → **要退** |
| 領隊報酬 vs 小費 | 報酬**包含**在團費；小費**不包含** |
| 責任險、履約險 vs 旅行平安險 | 前兩個旅行社必買、**包含**在團費；平安險旅客自己買、**不包含** |
| 不可抗力 vs 客觀風險 | 不可抗力：確定去不了，**不用補償**；客觀風險：可能有危險，解除方補償**最多 5%** |
| 請求權 1 年 | 從**旅遊結束**起算，不是簽約日 |
| 購物瑕疵 | **1 個月**（30 天）內請旅行社**協助**處理 |
| 延誤的「5 小時」 | 5 小時以上、未滿 1 天 → 算 **1 天** |
| 旅客中途離隊 | **不按比例退**，只退旅行社**省下來**的錢；回程費用旅客自己付 |
| 遇到事故的費用 | 旅行社的錯 → 旅行社付；不是旅行社的錯 → 旅客付（但旅行社一樣要幫忙處理） |

10. 哪個單位**不是**旅遊糾紛的申訴管道？（8-7）

**參考答案：**

1. 解除＝從頭取消；終止＝從現在停止
2. 簽證費向媽媽收；省下的錢不退

8. 60,000 ÷ 6 × 2 × 3 ＝ 60,000 元
