## 1　基本名詞：先把字看懂

| 名詞 | 白話解釋 |
|---|---|
| **主管機關** | 管這件事的政府機關。觀光的**中央**主管機關是**交通部**，由**交通部觀光署**實際執行 |
| **觀光署** | 112 年 9 月 15 日由「交通部觀光**局**」**改制**而成。舊考題寫觀光局，現在都寫觀光署 |
| **旅行業** | 法律上對旅行社的稱呼 |
| **籌設** | 準備設立公司：先申請核准，再辦公司登記 |
| **註冊** | 公司登記好之後，向觀光署登記成為旅行業，拿**旅行業執照** |
| **實收資本額** | 股東實際拿出來的錢 |
| **註冊費** | 註冊時繳的手續費，按資本額的 **1/1000** |
| **保證金** | 旅行社押在政府那邊的錢（用**銀行定存單**繳），旅行社出問題時用來賠旅客 |
| **分公司** | 同一家旅行社在其他地方開的分店。每開一家，資本額、保證金、保險都要**增加** |
| **經理人** | 負責監督管理旅行社業務的人，要受訓合格才能當 |
| **品保協會** | 「中華民國旅行業品質保障協會」，旅行社自己組成的公益團體，會員互相保證、調解糾紛。考題說的「**觀光公益法人會員**」就是品保協會會員 |
| **備查** | 報告給主管機關知道（不用等核准） |
| **核准** | 要主管機關同意才可以做 |
| **罰鍰** | 行政機關罰的錢 |
| **廢止執照** | 取消執照，不能再營業 |
| **勒令歇業** | 命令停止營業 |
| **執業證** | 領隊的工作證，要掛在胸前 |
| **職前訓練** | 評量及格後、開始工作前的訓練 |

## 2　三部法規的關係

| 法規 | 性質 | 管什麼 | 最新修正 |
|---|---|---|---|
| **發展觀光條例** | **法律**（母法） | 整個觀光產業：旅行業、旅館、民宿、導遊、領隊；**罰則都在這裡** | 114 年 11 月 28 日 |
| **旅行業管理規則** | 命令（依條例訂的細則） | 旅行社怎麼設立、怎麼經營 | **115 年 9 月 18 日** |
| **領隊人員管理規則** | 命令 | 領隊怎麼取得資格、怎麼執業 | 115 年 10 月 7 日 |

::: plain
**記法：** 條例是「媽媽」，規則是「小孩」。小孩寫細節（例如繳多少錢），但**罰多少錢要看媽媽**（發展觀光條例）。
例：「華語領隊帶越南團」是違反**領隊人員管理規則**，但罰鍰金額寫在**發展觀光條例**。
:::

::: trap
**修法提醒：** 旅行業管理規則、發展觀光條例近年大幅修正，**金額改了很多**。舊考古題的答案可能已經過時，第 11 節整理了對照表，**以現行規定為準**。
:::

## 3　旅行社的三種類型

| 業務 | 綜合 | 甲種 | 乙種 |
|---|---|---|---|
| 代售國內外機票、船票、車票 | ✔ | ✔ | 只有**國內** |
| 代辦出入國、**簽證** | ✔ | ✔ | ✘ |
| 招攬接待國內外旅客 | ✔ | ✔ | 只有**國內旅遊** |
| **自行組團**出國 | ✔ | ✔ | ✘ |
| 以**包辦旅遊**方式組團（設計好整套產品批發） | ✔ | ✘ | ✘ |
| **委託**其他旅行社**代為招攬** | ✔（可委託綜合、甲種、乙種） | ✘ | ✘ |
| **代理**綜合旅行業招攬 | — | ✔ | ✔（只限國內團） |
| 代理外國旅行業聯絡、推廣、報價 | ✔ | ✔ | ✘ |
| 設計國內外旅程、安排**導遊或領隊** | ✔ | ✔ | 只設計國內旅程 |
| 透過網路平臺或 APP **附隨代收旅遊保險費** | ✔ | ✔ | ✔ |

::: tip
**記法：**

- **綜合 ＝ 批發商**：可以做「包辦旅遊」，再委託別家旅行社幫忙賣。
- **甲種 ＝ 零售商**：自己組團、自己賣，也能幫綜合旅行社代賣。
- **乙種 ＝ 國內專賣店**：只能做國內。
- 世界上**沒有「丙種旅行業」**（114年考題陷阱選項）。
:::

**其他規定：**

- 帶團出國的旅行社一定是**綜合或甲種**；領隊要應徵這兩種旅行社才能帶出國團（109年考題）。
- 甲種、乙種代理綜合旅行社招攬時，要用**綜合旅行業的名義**和旅客簽約，並由**銷售的旅行社副署**（一起簽名）。
- **非旅行業不得經營旅行業務**，例外：代售**日常生活所需國內**海陸空運輸的客票，例如**超商賣高鐵票**，依據是**發展觀光條例**（112年考題）。

::: exam
**考古題（113年）：** 哪一項**不是**甲種旅行業的業務？答：「**以包辦旅遊方式**或自行組團……」（包辦旅遊是綜合才有）。
**考古題（115年）：** 綜合旅行業可以委託或代理其他綜合招攬、委託甲種代招攬、委託乙種代招攬國內團……答：**全部都可以**。
:::

## 4　開一家旅行社要繳的錢

### 4-1　總表

| 項目 | 綜合 | 甲種 | 乙種 |
|---|---|---|---|
| **實收資本額**（至少） | **3,000 萬** | **600 萬** | **120 萬** |
| 每增設一家**分公司**要**增資** | 150 萬 | 100 萬 | 60 萬 |
| **保證金**（總公司） | **1,000 萬** | **150 萬** | **60 萬** |
| **每家分公司**保證金 | 30 萬 | 30 萬 | 15 萬 |
| **註冊費** | 資本總額的 **1/1000**；分公司按**增資額**的 1/1000 | 同左 | 同左 |
| 旅行業**執照費** | 1,300 元 | 1,300 元 | 1,300 元 |

::: tip
**口訣：**

- 資本額：**3000、600、120**
- 保證金：**1000、150、60**；分公司 **30、30、15**
:::

### 4-2　品保會員的保證金優惠

經營同種類旅行業、**最近 2 年**沒被**停業處分**、保證金沒被**強制執行**，而且是**品保協會**（觀光公益法人）會員 → 保證金可以只繳 **1/10**。

（公司**改名**，或換了**新股東**當代表人，這 2 年要**重新算**。）

### 4-3　計算題

::: example
**例 1（114年考題）：** 設立綜合旅行社，同時開 2 家分公司，保證金多少？
1,000 萬 ＋ 30 萬 × 2 ＝ **1,060 萬元**
:::

::: example
**例 2（112年考題）：** 乙種旅行社加開 1 家分公司，實收資本額至少多少？
120 萬 ＋ 60 萬 ＝ **180 萬元**
:::

::: example
**例 3（113年考題）：** 甲種旅行社資本額已有 1,000 萬，再開 1 家分公司，註冊費和保證金各多少？

1. 甲種最低 600 萬 ＋ 分公司 100 萬 ＝ 700 萬，**原資本已經夠**，不用增資
2. 註冊費 ＝ 資本總額 1,000 萬 × 1/1000 ＝ **1 萬元**
3. 保證金（題目問的總公司部分）＝ **150 萬元**
:::

### 4-4　設立流程

1. 向觀光署申請**籌設**，經核准
2. 核准後 **2 個月內**辦好**公司設立登記**，繳保證金、註冊費，申請**註冊**（逾期廢止籌設許可，108年考題）
3. 領取**旅行業執照**後，才能**開始營業**

::: trap
**陷阱：** 「領取旅行業執照」是營業的條件，**不是**「開始經營**前**應辦妥事項」之一的錯誤選項要看清楚題目（109年考題問的是哪一個**不是**應辦事項）。
:::

### 4-5　解散

旅行社**解散**：辦好公司解散登記後 **15 天內**，拆招牌、繳回執照，由公司**清算人**申請**發還保證金**（109年考題）。

## 5　兩種強制保險（每年必考）

依發展觀光條例，**只有旅行業**要**同時**投保**責任保險**和**履約保證保險**；旅館、民宿等只要投保責任保險（114年考題）。

### 5-1　責任保險（保旅客出意外）

| 項目（每位旅客、每位隨團服務人員） | 金額 |
|---|---|
| 意外**死亡** | 最低 **250 萬**、最高 500 萬 |
| 意外受傷**醫療費** | 最低 **10 萬**、最高 20 萬 |
| 家屬到**海外**（或來臺）**處理善後** | **10 萬**；**國內**旅遊 **5 萬** |
| **證件遺失**賠償 | **2,000 元** |

- 責任保險不只保旅客，也保**隨團服務人員**（領隊）。
- 班機延誤使團體不能如期結束，保險期間**自動延長**，最多 **24 小時**（109年考題）。

### 5-2　死亡給付的請求順位

旅客意外**死亡**，可以向保險公司申請給付的人，順序是：

1. **父母、子女、配偶**
2. **祖父母**
3. **孫子女**
4. **兄弟姊妹**

受傷的話，由**受害人本人**申請。

::: example
**例子（115年考題）：** 已婚旅客死亡，子女和父母都已過世，請求順位？
→ **配偶 → 祖父母 → 孫子女 → 兄弟姊妹**
:::

### 5-3　履約保證保險（保旅行社倒閉）

旅行社因為**財務困難**，沒辦法繼續經營，付不出辦團的錢，使旅遊無法完成時，由保險公司賠旅客。

| | 一般旅行社 | **品保會員** |
|---|---|---|
| 綜合 | **1 億** | **8,000 萬** |
| 甲種 | **3,000 萬** | **1,500 萬** |
| 乙種 | **1,600 萬** | **800 萬** |
| 每增設一家分公司（綜合、甲種） | ＋**800 萬** | ＋**400 萬** |
| 每增設一家分公司（乙種） | ＋**400 萬** | ＋**200 萬** |

- 品保會員**失去優惠**的情形（要在接到通知 **15 天內**改按一般金額投保）：受停業處分、期滿後**未滿 2 年**；喪失會員資格；所屬公益法人解散或不足以保障旅客。
- 投保後 **10 天內**要填報保單資料。

::: example
**例子：** 品保會員的綜合旅行社，開 3 家分公司，履約保證保險至少多少？
8,000 萬 ＋ 400 萬 × 3 ＝ **9,200 萬元**
（113 年考題當時的答案是 4,300 萬，是舊規定。）
:::

::: tip
**責任保險 vs 履約保證保險：**

- **責任**保險 → 旅客出**意外**（死傷、證件遺失）
- **履約**保證保險 → 旅行社**倒閉**、出不了團（「履約」＝做到契約說的事）
:::

## 6　旅行業經理人

### 6-1　基本規定

- 旅行社和每家分公司都要有**至少 1 位**經理人。
- 經理人要**專任**：**不能兼任其他旅行社的經理人**，也不能自己經營或幫別人兼營旅行業（違反罰 3 千～1 萬 5 千）。
- 要先參加經理人**訓練**合格（**60 節**課、**70 分**及格），拿到結業證書才能當。
- 訓練合格後**連續 3 年**沒在旅行社工作，要**重新受訓**。

### 6-2　參加經理人訓練的資格（7 種，每年一題）

| 款 | 學歷 | 經歷 | 年資 |
|---|---|---|---|
| 1 | **大專以上**或高考及格 | 旅行業**代表人** | **2 年** |
| 2 | 大專以上或高考及格 | 海陸空客運業務**單位主管** | 3 年 |
| 3 | 大專以上或高考及格 | 旅行業**專任職員** ／ **領隊、導遊** | **4 年** ／ **6 年** |
| 4 | **高中職**或普考及格（或大學肄業等） | 代表人 ／ **專任職員** ／ 領隊、導遊 | 4 年 ／ **6 年** ／ 8 年 |
| 5 | 不限 | 旅行業專任職員 | **10 年** |
| 6 | 大專以上或高考及格 | 在大專院校教觀光專業課程 | 2 年 |
| 7 | 大專以上或高考及格 ／ 高中職 | 觀光行政機關業務部門專任職員 ／ 觀光行政機關或旅行公會 | 3 年 ／ 5 年 |

**觀光科系畢業**（大專或高中職）：**第 2～4 款**的年資可以**減 1 年**。

### 6-3　計算題

::: example
**例 1（112年考題）：** 小賢**大學觀光科系**畢業，在旅行社當**業務人員（專任職員）**，同時兼帶團。至少幾年？
→ 第 3 款：大專＋專任職員 **4 年** − 觀光科系 1 年 ＝ **3 年**
（兼帶團不用算領隊 6 年，用比較短的專任職員 4 年。）
:::

::: example
**例 2（115年考題）：** 小英**高職觀光科**畢業，在旅行社當業務人員，兼任領隊。至少幾年？
→ 第 4 款：高中職＋專任職員 **6 年** − 觀光科系 1 年 ＝ **5 年**
:::

::: example
**例 3（108年考題）：** 哪一項可以參加經理人訓練？答：「**高級中等學校畢業，曾任旅行業專任職員 6 年**」。
:::

### 6-4　不能當經理人（消極資格）

| 情形 | 多久內不能當 |
|---|---|
| 犯**組織犯罪**判決確定 | 執行完畢後 **5 年**內 |
| 犯**詐欺、背信、侵占**罪判 1 年以上徒刑確定 | 執行完畢後 **2 年**內 |
| 犯**貪污**罪判決確定 | 執行完畢後 **2 年**內 |
| 受**破產**宣告或法院裁定清算 | 尚未復權 |
| 使用**票據**經拒絕往來 | 尚未期滿 |
| **無行為能力**、限制行為能力、受輔助宣告 | — |
| 曾經營旅行業被**撤銷或廢止執照** | **5 年**內 |

這些人也不能當旅行社的發起人、董事、監察人。

（「曾犯內亂、外患罪」的寫法和現行條文不符，108 年考題為錯誤選項。）

## 7　經營規定

### 7-1　旅遊契約

- 辦團體或個別旅遊都要和旅客簽**書面契約**；也可以用**電子簽章**的電子文件。
- 把觀光署的**定型化契約範本**公開、印在**代收轉付收據**上交給旅客，除另有約定外，視為已經簽約。
- 契約書要寫：公司資料、**簽約地點日期**、旅遊地區行程、交通住宿膳食遊覽、**最低組團人數**、全部費用和付款條件、**解約條件**、損害賠償責任、**責任保險與履約保證保險**的權益等。
- 旅客交付文件、繳費收據，連同**旅遊契約書**要**保管 3 年**，備供查核。
- **自行組團**的業務，沒有旅客**書面同意**，**不能轉讓**給別的旅行社；接手的旅行社要和旅客**重新簽約**。

::: trap
**陷阱：** 契約保管期限現行是 **3 年**；112、108 年考題的答案「1 年」是**舊規定**。
:::

### 7-2　廣告

- 不得**誇大、虛偽不實**或引人錯誤，要和旅遊文件相符。
- 廣告要載明：**行程名稱**、**出發地點、日期、天數**、**旅遊費用**、**責任保險和履約保證保險及其金額**、**公司名稱、種類、註冊編號、電話**。
- 現行條文：可以用**註冊的商標**代替公司名稱（110 年舊題「甲種不能用商標」已修正）。
- 版面放不下時，要提供**網站**等管道讓消費者查詢；「公司網址」本身**不是必須載明**的事項（114年考題）。
- **不能寫「僅供參考」**。
- 用商標招攬旅客要申請**商標註冊**、報觀光署備查，商標以 **1 個**為限；但還是要用**公司名義**簽約。
- 用網站、APP 經營：頁面要揭露公司名稱、種類、地址、**註冊編號**、代表人、電話、電子信箱和聯絡人。

### 7-3　出國團

- 綜合、甲種辦出國團：
    - 團體**成行前**，要用**書面**向旅客說明**旅遊安全**等事項，或舉辦**說明會**
    - 成行時**每團**都要派**領隊**全程隨團服務
    - 出國團要派**外語領隊**，**不能**派**華語領隊**（華語只能帶大陸港澳團）
    - 不能讓自己的領隊幫**非旅行業**帶團（違反罰 1 萬～5 萬）
- **國內**團體旅遊：派「**專人**」全程隨團服務（不一定是領隊）。
- 慎選**國外當地政府登記合格**的旅行社，取得承諾書或保證文件；**國外旅行社違約**，**國內招攬的旅行社**要負賠償責任。

### 7-4　報備期限

| 事項 | 期限 |
|---|---|
| 公司名稱、資本額、地址、代表人、經理人等**變更** | 變更後 **15 天**內 |
| **職員異動** | **10 天**內 |
| **暫停營業 1 個月以上** | 停業日起 **15 天**內報備（附股東會議事錄或股東同意書） |
| 停業期間 | 最長 **1 年**；有正當理由可**展延 1 次**、以 **1 年**為限（期滿前 15 天內申請） |
| 停業期滿**復業** | 期滿後 **15 天**內申報 |
| **緊急事故**（旅客傷亡或滯留） | 事故後 **24 小時**內向**觀光署**報備 |
| 代辦的**證照遺失** | **24 小時**內向**外交部領事事務局、警察機關或觀光署**報備（**移民署不在其中**） |
| 保證金被強制執行 | 接到通知 **15 天**內繳足 |
| **解散** | 解散登記後 **15 天**內繳回執照、申請發還保證金 |

::: tip
**記法：** 大多是 **15 天**；**職員異動 10 天**；**緊急事故、證照遺失 24 小時**。
:::

### 7-5　旅行社和隨團人員要遵守的事

1. 不得有不利國家的言行
2. **不得擅離團體**或隨意解散旅客
3. 使用**合法**的遊樂、住宿設施
4. 注意旅客**安全**
5. 除不可抗力外，沒有旅客請求**不得變更旅程**
6. 除代辦必要事項外，**沒有旅客請求，不得保管旅客證照**
7. 持有旅客證照時要妥善保管，**不得遺失**
8. 使用**合法交通工具**和合格駕駛；租遊覽車要簽租車契約
9. 遊覽車要做**逃生安全解說和示範**，每天出發前檢查
10. 遊覽車只能載**自己的團員**
11. 妥善安排行程，揭露行程資訊

### 7-6　旅行社不能做的事（常考的幾項）

- 明知旅客證件不實還代辦
- **委由旅客攜帶物品圖利**
- 安排**未經旅客同意**的旅遊活動
- **強迫**旅客進入或留在購物店購物；安排價格品質不相當的物品
- 未揭露也未經同意，向旅客**兜售物品**
- 向旅客收取**中途離隊的離團費**
- **沒辦好簽證、機位、住宿就帶團出國**
- 調解旅遊糾紛時，經通知無正當理由**不到場**
- 賣機票沒寫旅客**姓名**；賣行程沒寫**出發日期**

### 7-7　其他

- 旅行社對**指派或僱用的人員**執行業務的行為，**推定**為旅行社的行為（員工做的，視同公司做的）。
- **航空票價、食宿、交通費用**行情，由**品保協會**按**季**發表，供消費者參考（114年考題）。
- 綜合、甲種代辦出入國手續，要請領**專任送件人員識別證**（證照費 200 元），**不能借給**別家使用。
- 在**大陸、香港、澳門**或國外設**分支機構**，或與當地旅行社合作，報**觀光署**備查。

## 8　發展觀光條例

### 8-1　重要定義與規定

| 項目 | 內容 |
|---|---|
| 制定時間 | 民國 **69 年 11 月 24 日**制定公布（108年考題） |
| 中央主管機關 | **交通部**；為主管全國觀光事務，設**觀光署** |
| **旅行業**的定義 | 經中央主管機關核准，為旅客設計安排旅程、食宿、領隊、導遊、代購代售客票、代辦簽證等服務而**收取報酬**的營利事業 |
| 經營**旅行業** | 向**中央**主管機關申請核准、領**旅行業執照** |
| 經營**民宿** | 向**直轄市或縣（市）政府**申請登記、領**登記證**（111年考題） |
| 旅行業**保證金** | 旅客因**旅遊糾紛**對旅行社的債權，對保證金有**優先受償權**（先拿到錢，108年考題） |
| **觀光專用標識** | 發給觀光旅館業、旅館業、觀光遊樂業、民宿；**旅行業沒有**（108年考題） |
| 表揚優良觀光產業 | 表揚辦法由**交通部**（中央主管機關）訂定 |
| 證照費 | 費額由**交通部**訂定 |
| **自然人文生態景觀區** | 要設**專業導覽人員**；國家公園的「**一般管制區**」不劃入（111年考題）；沒申請專業導覽人員陪同就進入，罰 **3 萬元以下** |
| 導遊、領隊 | 要經中央主管機關**評量及訓練合格**，領執業證，並受旅行業僱用（或政府機關團體臨時招請）才能執業 |
| 機場服務費 | 可以向出境航空旅客收取 |

### 8-2　罰則總表（背金額區間）

| 違規 | 罰鍰 |
|---|---|
| **沒有執業證**就帶團（導遊、領隊） | **1 萬～5 萬**，並禁止執業 |
| 領隊、導遊**違反管理規則**（例：華語領隊帶越南團、擅離團體）；經理人兼任 | **3 千～1 萬 5 千**；情節重大可停止執業或廢止執業證 |
| 受停止執業處分**仍繼續執業** | **廢止執業證** |
| 旅行社**沒和旅客簽書面契約**；停業沒報備、期滿沒申報復業 | **1 萬～5 萬** |
| 旅行社違反依條例發布的命令（例：出國團沒派合格領隊、讓領隊幫非旅行業帶團） | **1 萬～5 萬** |
| 旅行社經營**核准範圍外**業務 | 3 萬～15 萬；情節重大可廢照 |
| 旅行社**沒投保**責任保險或履約保證保險 | **3 萬～50 萬**；可**立即停止**出國及國內旅遊業務，限 **3 個月**內投保，逾期可**廢照** |
| 詐騙旅客、玷辱國家榮譽 | 3 萬～15 萬；情節重大 15 萬～50 萬 |
| 受**停業處分仍繼續營業** | **50 萬以上**，廢止執照 |
| **沒有執照**經營旅行業 | **10 萬～200 萬**，勒令歇業 |
| 沒執照卻刊登營業廣告 | 10 萬～150 萬 |
| 沒登記證經營**民宿** | **10 萬～100 萬**，勒令歇業 |
| 外國旅行業沒核准就在臺設代表人 | 代表人 1 萬～5 萬 |
| **損壞**觀光地區名勝、自然資源、觀光設施 | **50 萬以下**＋回復原狀；無法回復再罰 **500 萬以下** |
| 風景區**強行拍照收費**、強迫推銷、擅自擺攤 | **1 萬～5 萬** |
| 風景區亂丟垃圾、亂停車、擅入禁止區 | 5 千～10 萬 |

::: tip
**口訣：** **沒證 1～5 萬、有證違規 3 千～1 萬 5、沒照開業 10 萬～200 萬、沒保險 3 萬～50 萬。**
:::

::: exam
**考古題（114年）：** 只有華語領隊執業證卻帶越南團？答：**3 千～1 萬 5 千元**（有證但違規）。
**考古題（115、114年）：** 沒取得執業證就帶團？答：**1 萬～5 萬元**。
:::

## 9　領隊人員管理規則

### 9-1　執業證的種類與範圍

| 執業證 | 可以帶 |
|---|---|
| **外語**領隊執業證 | 國人**出國**，以及赴**香港、澳門、大陸** |
| **華語**領隊執業證 | **只能**帶國人赴**香港、澳門、大陸**；**不得**帶出國團（日本、越南、泰國都不行） |

### 9-2　評量測驗

| 項目 | 規定 |
|---|---|
| 主辦 | 交通部委任**觀光署**辦理 |
| 類科 | 外語領隊（分**通用制**、**專用制**）、華語領隊 |
| **報名資格** | 中華民國國民（以及外國人、港澳居民、在臺依親或長期居留的陸配），**高中職以上畢業**或同等學力 |
| **專用制**外語領隊 | 綜合、甲種旅行社**現職人員**，年資滿 **2 年**，由公司推薦；執業證會註明推薦的旅行社，**只能幫那家帶團**，離職就失效 |
| 報名費 | **1,300 元** |
| 華語領隊科目 | 領隊執業實務、領隊執業法規、觀光資源概要（全部選擇題） |
| 華語及格標準 | 各科**平均滿 60 分**；有一科 **0 分**不及格；缺考算 0 分 |
| 外語及格標準 | 平均滿 60 分，且外國語至少 **50 分** |
| 不能當領隊 | 違反規則被**廢止執業證未逾 5 年** |

### 9-3　職前訓練

| 項目 | 規定 |
|---|---|
| 完成期限（**通用制、華語**） | 成績公布日起算滿 **3 年**的 6 月 30 日前；逾期**及格資格不保留** |
| 完成期限（**專用制**） | 成績公布日起算滿 **1 年**的 6 月 30 日前 |
| 節數 | **56 節**，每節 **50 分鐘** |
| 先有華語、再考上外語 | 訓練**減半**＝ **28 節** |
| 先有外語、再考上另一種外語 | **免**再訓練 |
| 取消報名退費 | 開訓前 **7 天**取消，退 **7 成**；產假、重病等可全額退費 |
| **缺課** | 不得超過 **1/10**；遲到或早退超過 **10 分鐘**算缺課 1 節 |
| **測驗** | **70 分**及格；不及格 **7 天內補考 1 次**；補考還不及格**不得結業** |
| 延期測驗 | 因產假、重病等經核准延期，**1 年內**申請測驗 |
| 結業證書費 | **500 元**（補發也是 500 元） |
| 訓練機構陳報成績 | 結訓後 **10 天內** |

**退訓的情形**（已繳費用**不退**）：

1. 缺課超過 **1/10**
2. 對講座、輔導員**強暴脅迫**
3. 由他人**冒名頂替**
4. 資格證明文件**偽造、變造**
5. 品德操守違反倫理規範、情節重大

第 2～4 款被退訓的，**2 年內**不得再參加訓練。（產假、重病是**正當事由**，不是退訓事由。）

### 9-4　執業證

| 項目 | 規定 |
|---|---|
| 取得順序 | **評量及格 → 職前訓練合格 → 領結業證書 → 請領執業證 → 受旅行業僱用或指派**帶團 |
| 有效期間 | **3 年**，期滿前 **1 年內**申請換發 |
| 申請、換發、補發費用 | 都是 **200 元** |
| 換發或補發後 | 原執業證**失效** |
| 連續 **3 年**沒帶團 | 重新受訓 **28 節**，換領執業證才能帶團（天災、疫情時主管機關可公告延長） |

### 9-5　執業時要遵守的事

- 依旅行社安排的行程執業，非因不可抗力**不得擅自變更**。
- 執業證**掛在胸前明顯處**。
- 發生**特殊或意外事件**，**24 小時內**向**受僱的旅行社**和**觀光署**報備（115、110年考題）。

### 9-6　領隊的禁止行為（第 39 條）

1. 旅客**生病不照顧**、不注意旅客**安全**
2. 誘導購物收**回扣**、向旅客**額外需索**、向旅客**兜售或收購**物品、收取旅客財物、**委由旅客攜帶物品圖利**
3. 執業證**借給別人**、無故**延誤**、**擅自委託他人代為執業**、停止執業期間執業、擅自經營旅行業務、**幫非旅行業帶團**
4. **擅離團體**、擅自**解散**旅客、擅自使用**非法**交通工具或住宿設施
5. **非經旅客請求**保管旅客證照；或經旅客**請求保管卻遺失**
6. 言行不當

::: trap
**陷阱：** **旅客請你保管證照是可以的**（但弄丟就違規）；**沒有請求**、主動收走證照才違規（104年考題）。
:::

## 12　容易搞混總整理

| 容易搞混 | 正確說法 |
|---|---|
| 綜合 vs 甲種 | 綜合可以**包辦旅遊**、**委託**別家代招攬；甲種自己組團 |
| 資本額 vs 保證金 | 資本額 3000／600／120；保證金 1000／150／60 |
| 分公司增資 vs 分公司保證金 | 增資 150／100／60；保證金 30／30／15 |
| 責任保險 vs 履約保證保險 | 意外 vs 倒閉 |
| 一般 vs 品保會員履約險 | 1 億／3000 萬／1600 萬 vs 8000 萬／1500 萬／800 萬 |
| 請求順位 | 父母子女配偶 → **祖父母** → **孫子女** → 兄弟姊妹 |
| 經理人觀光科系 | **第 2～4 款**減 1 年 |
| 大專＋專任職員 vs 高中職＋專任職員 | 4 年 vs 6 年 |
| 職員異動 vs 其他變更 | **10 天** vs 15 天 |
| 緊急事故報備 | **24 小時**，向**觀光署** |
| 證照遺失報備 | 外交部領事事務局、警察機關、觀光署；**不含移民署** |
| 民宿 vs 旅行業申請 | 民宿向**縣市政府**；旅行業向**中央** |
| 觀光專用標識 | 旅行業**沒有** |
| 沒證 vs 有證違規 | 1 萬～5 萬 vs 3 千～1 萬 5 |
| 華語 vs 外語領隊 | 華語只能大陸港澳；外語全世界 |
| 職前訓練期限 | 通用制、華語 **3 年**；專用制 **1 年** |
