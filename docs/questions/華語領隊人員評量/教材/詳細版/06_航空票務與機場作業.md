## 1　基本名詞：先把字看懂

### 1-1　搭飛機的基本流程

先知道整個流程，後面的名詞就有地方放：

**訂位** → **開票** → 出發當天到機場**報到** → **託運**行李、拿**登機證** → **出境**（證照查驗）→ **安檢** → 到**登機門**登機 →（**轉機**）→ 抵達後**入境**（證照查驗、檢疫）→ **提領行李** → **海關**

### 1-2　名詞表

| 名詞 | 白話解釋 | 例子 |
|---|---|---|
| **航空公司** | 經營飛機載客的公司 | 中華航空、長榮航空 |
| **航班** | 一班飛機，有固定的班號 | CI 100、BR 075 |
| **航段** | 從一個機場飛到下一個機場的一段 | 臺北→東京是一個航段 |
| **直飛**（Non-stop） | 中間不停，一次飛到 | 臺北直飛羅馬 |
| **經停** | 同一班飛機中途降落再起飛，可能上下客 | 臺北經曼谷飛阿姆斯特丹 |
| **轉機** | 換搭另一班飛機 | 在香港換飛機去倫敦 |
| **艙等** | 座位等級：頭等艙（F）、商務艙（C 或 J）、經濟艙（Y）。同一艙等還會再分很多「訂位代號」，代表不同價格 | Y 艙、L 艙 |
| **訂位** | 先跟航空公司保留座位，還沒付錢 | — |
| **開票** | 付錢、正式開出機票 | — |
| **電子機票** | 現在的機票都是電腦裡的紀錄，不再有紙本；拿到的是「**電子機票收據**」 | — |
| **報到**（Check-in） | 到航空公司櫃檯或自助機器，確認搭機、託運行李、拿登機證 | — |
| **登機證**（Boarding Pass） | 寫有座位、登機門、登機時間的證件，憑它登機 | — |
| **託運行李** | 交給航空公司放在飛機**貨艙**的行李 | 大行李箱 |
| **手提行李**／**隨身行李** | 自己帶上飛機**客艙**的行李 | 背包 |
| **安檢** | 安全檢查：行李過 X 光機、人走過金屬探測門 | — |
| **登機門**（Gate） | 上飛機的出入口 | Gate C5 |
| **地勤** | 在機場地面工作的航空公司人員 | 櫃檯人員 |
| **空服員** | 在飛機上服務的人員 | — |
| **廉價航空**（LCC） | Low Cost Carrier，票價便宜、服務簡化（餐點、行李要另外付錢） | 虎航、樂桃 |
| **全服務航空** | 傳統航空公司，票價包含餐點、行李等 | 華航、長榮 |
| **包機** | 整架飛機租下來，飛特定航線 | 旅行社包機去北海道 |

## 2　航空組織與分區

### 2-1　兩個國際組織

| 簡稱 | 全名 | 是誰組成的 | 做什麼 |
|---|---|---|---|
| **IATA** | 國際**航空運輸協會**（International Air Transport Association） | **航空公司**組成的**民間**組織 | 訂代碼、票價規則、機票規定、清帳 |
| **ICAO** | 國際**民航組織**（International Civil Aviation Organization） | 各國**政府**組成的**官方**組織（聯合國專門機構） | 訂飛航安全、機場等國際標準 |

::: tip
**記法：** ICAO 的 **O** ＝ Organization，政府的「組織」；IATA 的 **A** ＝ Association，航空公司的「協會」。
:::

::: exam
**考古題（106年）：** 以各國政府為主體組成的官方組織？答：**ICAO**。
**考古題（107年）：** IATA 是？答：**國際航空運輸協會**。
:::

### 2-2　IATA 三大區域（Traffic Conference，簡稱 TC）

IATA 把全世界分成三大區，用來訂票價規則：

| 區 | 範圍 | 例子 |
|---|---|---|
| **TC1** | **南北美洲**（含夏威夷、格陵蘭） | SFO 舊金山、YVR 溫哥華 |
| **TC2** | **歐洲、非洲、中東** | MUC 慕尼黑、北歐三國（丹麥、挪威、瑞典） |
| **TC3** | **亞洲、大洋洲** | BKK 曼谷、SYD 雪梨、TPE 臺北 |

::: tip
**記法：** 從美洲開始往東數：**1 美洲 → 2 歐非中東 → 3 亞洲大洋洲**。臺灣在 TC3。
:::

::: exam
**考古題（114年）：** 北歐三小國（丹麥、挪威、瑞典）屬於哪一區？答：**TC2**。
**考古題（113年）：** MUC、SFO、BKK、SYD 哪些屬於 TC3？答：**BKK、SYD**。
:::

### 2-3　GMT 與 UTC

- **GMT**：格林威治標準時間，以英國倫敦格林威治天文台為基準（0 度經線）。
- **UTC**：國際標準時間（協調世界時），現在全球公認以 UTC 取代 GMT；兩者時間幾乎一樣，考試可視為相同。
- 臺灣是 **GMT+8**（UTC+8），比倫敦快 8 小時。

## 3　航空聯盟與合作

### 3-1　什麼是航空聯盟

好幾家航空公司結盟，互相**共用貴賓室**、**累積哩程**、**轉機行李直掛**、**共掛班號**，讓旅客像搭同一家公司。

### 3-2　三大航空聯盟

| 聯盟 | 臺灣成員 | 其他常見成員 |
|---|---|---|
| **星空聯盟** Star Alliance（1997 年成立，最大；總部在德國**法蘭克福 FRA**） | **長榮 BR** | 新航 SQ、泰航 TG、全日空 NH、國航 CA、漢莎 LH、聯合 UA、紐航 NZ、土航 TK |
| **天合聯盟** SkyTeam | **華航 CI** | 大韓 KE、法航 AF、荷航 KL、達美 DL、東航 MU、越航 VN、印尼航空 GA |
| **寰宇一家** oneworld | （無） | 國泰 CX、日航 JL、英航 BA、澳航 QF、美航 AA、卡達 QR、馬航 MH |

::: info
**近年變化：**

- 星宇航空（JX）**目前沒有加入**任何聯盟，但和美國航空、阿拉斯加航空等合作聯營。
- 韓亞航空（OZ）併入大韓航空，**2026 年 12 月 16 日**退出星空聯盟。
- 北歐航空（SK）已從星空聯盟改加入天合聯盟。

舊考題選項如果出現韓亞航空是星空聯盟成員，以題目年份當時為準。
:::

::: exam
**考古題（112、111年）：** 中華航空屬於哪個聯盟？答：**天合聯盟（SkyTeam）**。
**考古題（107年）：** 星空聯盟總部設在？答：**FRA**（法蘭克福）。
:::

### 3-3　其他合作方式

| 名詞 | 意思 |
|---|---|
| **共掛班號**（CODESHARE） | 一班飛機掛好幾家航空公司的班號。例如華航飛的班機，也用達美的班號賣票 |
| **聯營**、**互換艙位** | 兩家公司合作經營同一航線，或互相賣對方的座位；屬於航空公司的**聯合促銷**方式 |
| 聯營航線或加班機的班號 | 通常用 **4 位數**（一般班機是 3 位數以下） |
| **GSA** | General Sales Agent，航空公司在某地區的**銷售總代理** |
| **FAM TOUR** | Familiarization Tour，**熟悉之旅**。航空公司或觀光局招待旅行業者去考察新航線、新景點，屬於「**路線開發**」的合作 |
| **PAK** | 航空公司主導，**好幾家旅行社聯合**銷售同一產品、聯合出團 |
| 策略聯盟的內容 | 共用貴賓室、哩程互通、共掛班號、聯合維修等；「**航機獨立維修**」**不是**聯盟的內容 |

### 4-4　特殊服務代碼（SSR）

| 代碼 | 意思 |
|---|---|
| **UM** | 兒童**單獨**搭機（Unaccompanied Minor），航空公司派人照顧 |
| **WCHR** | 輪椅（R＝Ramp）：**可以走幾步、能上下階梯**，只是走不遠 |

:::

## 5　航權（每年必考）

### 5-1　什麼是航權

飛機要飛進別的國家、在別的國家上下客，要經過那個國家同意。國家之間談好「你可以在我這裡做什麼」，就叫**航權**（空中自由權）。

### 5-2　九種航權

用「臺灣的航空公司」當例子：

| 航權 | 名稱 | 白話 | 例子 |
|---|---|---|---|
| **第一** | 飛越權 | **飛過**別國的天空，不降落 | 國泰香港→洛杉磯，**飛越日本**領空 |
| 第二 | 技術降落權 | 在別國**降落加油、維修**，但**不上下客** | — |
| 第三 | 卸載權 | 從**本國**載客**到**別國 | 華航臺北→東京 |
| 第四 | 裝載權 | 從別國載客**回本國** | 華航東京→臺北 |
| **第五** | **延遠權** | 本國出發，在**第三國上下客**，再飛到另一國 | **長榮臺北→曼谷→阿姆斯特丹**，在曼谷可以上下客；**新航新加坡→臺北→洛杉磯** |
| 第六 | 橋樑權 | 經過**本國**中轉，連接兩個外國 | 美國客人搭華航，經臺北轉機去曼谷 |
| 第七 | 完全第三國運輸權 | 完全在國外兩個國家之間飛，不經過本國 | — |
| 第八 | 境內延伸權 | 從本國飛進別國，再在**那個國家境內**接著飛 | — |
| **第九** | **境內營運權** | 完全在**別國境內**飛國內線 | 華航飛**東京→福岡**（日本國內線）需要第九航權，所以**飛不了** |

::: tip
**記法：**

- 1 飛過、2 降落加油、3 去、4 回：最基本的四種。
- **5 延遠**：「延」長到更「遠」的地方，中途可以載客。
- **9 境內**：在別人家裡開公車，通常不會給。
:::

::: example
**考古題（111年）：** 旅客在首爾，臨時想去大阪，**最不可能**搭哪家航空？答：**CI**。
**為什麼？** 華航飛首爾→大阪需要第五航權（兩個外國之間載客），一般沒有這條航線；大韓、韓亞、日航、全日空都有。
:::

::: exam
**考古題（114年）：** 新航 SIN→TPE 上下客後再飛 LAX？答：**第五航權**。
**考古題（113、112年）：** 長榮臺北→曼谷→阿姆斯特丹（倫敦），曼谷可上下客？答：**第五航權（延遠權）**。
**考古題（110年）：** 國泰香港直飛洛杉磯飛越日本？答：**第一航權**。
**考古題（109年）：** 華航無法飛東京→福岡國內線，受哪個航權限制？答：**第九航權**。
:::

## 6　機票與票價

### 6-1　機票上的重要欄位

| 欄位 | 意思 |
|---|---|
| **NAME OF PASSENGER** | 旅客姓名，寫法是「**姓／名＋稱謂**」，例如 **LIN/JEREMYMR**（林書豪先生） |
| **NOT VALID BEFORE** | 在這天**以前**不能用 |
| **NOT VALID AFTER** | 機票**最後使用期限**，過了這天就不能用 |
| FARE BASIS | 票價基礎代碼，例如 YLAP21 |
| STATUS | 訂位狀態，例如 OK、NS |
| 機票號碼 | 前三碼是航空公司數字代碼，後面是序號。實體票最後還有一碼「**檢查號碼**」，**電子機票沒有** |

稱謂：MR 先生、MS 女士、MISS 小姐（女童）、MSTR 男童。

::: exam
**考古題（107年）：** 林書豪機票姓名欄的正確寫法？答：**LIN/JEREMYMR**。
**考古題（107年）：** 機票最後使用期限填在哪個欄位？答：**NOT VALID AFTER**。
**考古題（114年）：** 電子機票和實體機票號碼的差別，電子機票沒有？答：**檢查號碼**。
:::

### 6-2　機票效期

| 情況 | 效期 |
|---|---|
| 一般機票**完全沒用過** | 從**開票日**起 **1 年** |
| 已經用了第一段 | 從**第一段搭乘日**起 **1 年** |
| 有特別限制的票（例如 YEE14） | 依票價規定。YEE14 ＝最多停留 **14 天**，從**開始搭機**那天算 |

::: example
**例子（106年考題）：** 8 月 1 日買了 YEE14 的票，8 月 3 日開始搭機。效期到哪天？
→ 從 8 月 3 日開始算 14 天 → **8 月 17 日**。
:::

### 6-3　團體票

| 名詞 | 意思 | 例子 |
|---|---|---|
| **GV** | Group Inclusive Tour，團體票，**後面的數字是最低人數** | **GV10**＝至少 10 人；**GV15**＝至少 15 人 |
| **IT** | Inclusive Tour，**旅遊套裝票**，機票和地面行程綁在一起賣 | IT8**CX**3PG43：中間的 **CX** 代表**國泰航空** |
| **FOC** | **Free of Charge**，**免費票**。團體人數達到一定數量，航空公司送一張（常給領隊用） | 每 15 人送 1 張 |
| **OJ** | **Open Jaw**，**開口式**行程：去程的目的地和回程的出發地**不同** | 臺北→羅馬，巴黎→臺北 |
| **Sub-load** | **Subject to Load**，**限空位搭乘** | 航空公司員工票 |
| 包機票 | 價格和營運條件由航空公司和旅行社**約定**，並要經主管機關核准；**不是**航空公司自己說了算 | — |

::: trap
**陷阱：** FOC 是免費「機票」，但**機場稅、燃油附加費通常還是要付**（107年考題）。
:::

### 6-4　票價代碼怎麼看

用 **YLAP21** 當例子：

| 部分 | 意思 |
|---|---|
| Y | 經濟艙 |
| L | **淡季**（Low season）；旺季是 H（High） |
| AP | **Advance Purchase**，**預購票**（APEX） |
| 21 | 出發前 **21 天**要買票 |

::: trap
**陷阱：** YLAP21 的 21 **不是**「限 21 人以下」，是「**出發前 21 天購票**」（111年考題）。
:::

### 6-5　嬰兒和兒童票

| 對象 | 年齡 | 票價 | 座位 |
|---|---|---|---|
| **嬰兒**（INF） | **未滿 2 歲** | 成人票的 **10%**（代碼例如 IN90，表示打 1 折） | **不占座位**（抱在大人身上） |
| 兒童（CHD） | 2 歲～未滿 12 歲 | 成人票的約 75% | 占座位 |

- 一個大人只能抱**一個**嬰兒。帶**第二個**嬰兒，第二個要買**兒童票**（占座位），**不是成人票**（110年考題）。
- 嬰兒在旅途中**滿 2 歲**：依**開票航空公司**的規定決定要不要補票（113年考題）。
- 帶嬰兒、行動不便的旅客，可要求安排 **Bulkhead** 座位（每個艙段**最前排**、前面是隔板的座位，前方空間大，可以掛**嬰兒搖籃**）。
- 全服務航空可以在搭機前**要求提供奶粉**、嬰兒餐。

### 6-6　里程計價（比較難，了解原理即可）

機票價格有時是依「飛了多遠」來算：

| 名詞 | 意思 |
|---|---|
| **TPM** | Ticketed Point Mileage，**實際飛的里程** |
| **MPM** | Maximum Permitted Mileage，**最高允許里程** |
| **EMS** | Excess Mileage Surcharge，**超哩數附加費**：TPM 超過 MPM 時要加收，**上限 25%** |
| **EMA** | Extra Mileage Allowance，**哩程寬減**：經過某些特定城市時，航空公司**送**一些里程，不算超過 |

**計算方法：** TPM ÷ MPM

- 商數 ≤ 1：不用加價
- 商數超過 1：依超過的比例加收 5%、10%、15%、20%、**25%**
- 商數**超過 1.25**：不能用里程計價，改用**分段計價**（把行程拆開分別算）

::: trap
**陷阱：** 里程計價的基本要素有 TPM、MPM、EMS、EMA；「**EMX**」**不是**（109年考題）。
:::

### 6-7　附加費用

旅行社常把以下項目從團費拆出來另外收：**燃油附加費**、**機場稅**、**簽證費**、**小費**等。**機票本身**是團費的主體，**不是**附加費用（115、112年考題）。

## 7　訂位系統與 PNR

### 7-1　名詞

| 名詞 | 意思 |
|---|---|
| **CRS／GDS** | 電腦訂位系統，例如 **ABACUS**、Amadeus、Galileo |
| **PNR** | Passenger Name Record，**電腦訂位紀錄**。一筆訂位的所有資料 |
| **BSP** | 銀行清帳計畫：旅行社開票後，透過 BSP 和各航空公司結帳 |
| OVER BOOKING | **超額訂位**：航空公司賣出比座位多的票（預估有人不來） |
| STAND BY | **候補**：在機場等有沒有空位 |

### 7-2　PNR 的五大要素

一筆訂位紀錄至少要有：

1. **姓名**（Name）
2. **航段**（Itinerary）：班號、艙等、日期、起訖點、狀態、時間
3. **電話**（Phone）
4. **開票期限**（Ticketing）
5. **訂位人**（Received from）

PNR 最後還會有一行**訂位日期**（例如 23OCT 代表 10 月 23 日訂的）。

### 7-3　查詢指令（了解即可）

ABACUS 查空位：**123NOVSFOTPE11PYVR**

| 部分 | 意思 |
|---|---|
| 1 | 查詢空位的指令 |
| 23NOV | 11 月 23 日 |
| SFO TPE | 舊金山飛臺北 |
| 11P | 晚上 11 點左右 |
| **YVR** | **指定轉機點**（溫哥華） |

::: exam
**考古題（115年）：** 123NOVSFOTPE11PYVR 指定的轉機點？答：**YVR**。
**考古題（109年）：** 何者正確？①PNR 電腦訂位紀錄 ②RQ 機位候補 ③STAND BY 登機手續 ④OVER BOOKING 限空位搭乘。答：**只有①②**（STAND BY 是候補、OVER BOOKING 是超額訂位）。
:::

## 8　時差計算

### 8-1　時區的觀念

- 地球自轉一圈 360 度、24 小時 → 每 **15 度**經線差 **1 小時**。
- 以英國格林威治（0 度）為 GMT±0。往**東**時間越**早**到（＋），往**西**越晚（－）。
- 臺灣在東經約 120 度 → 120 ÷ 15 ＝ 8 → **GMT+8**。
- 各國可以自己決定用哪個時區，所以不一定照經線。例如新加坡理論上是 GMT+7，實際用 **GMT+8**。
- **美國本土**有 **4 個時區**（東部、中部、山區、太平洋）。
- 有些國家夏天會撥快一小時，叫**日光節約時間**（夏令時間），例如美國、歐洲。

### 8-2　計算方法：全部換成 GMT

**步驟：**

1. 出發時間 − 出發地時區 ＝ 出發的 GMT 時間
2. 抵達時間 − 抵達地時區 ＝ 抵達的 GMT 時間
3. 抵達 GMT − 出發 GMT ＝ **飛行時間**

（時區是負的，減負數就是加。例如 GMT−8，就是 ＋8。）

::: example
**例 1（115年考題）：** 臺北 2 月 8 日 23:25 起飛（GMT+8），直飛羅馬，2 月 9 日 07:15 抵達（GMT+1）。飛多久？

1. 出發 GMT：23:25 − 8 ＝ 2 月 8 日 **15:25**
2. 抵達 GMT：07:15 − 1 ＝ 2 月 9 日 **06:15**
3. 飛行時間：從 2/8 15:25 到 2/9 06:15 ＝ **14 小時 50 分**
:::

::: example
**例 2（108年考題）：** 臺北（GMT+8）飛美西（GMT−8）要 12 小時。要在**同一天**下午 6 點抵達，應該搭幾點的班機？

1. 兩地時差：8 −（−8）＝ **16 小時**（臺北比美西快 16 小時）
2. 抵達美西 18:00 → 換成臺北時間 ＝ 18:00 ＋ 16 ＝ 隔天 10:00
3. 往回推 12 小時飛行 → 臺北出發 ＝ 前一天 **22:00**
4. 所以應該選臺北**晚上 8～10 點**起飛的班機
:::

::: example
**例 3：** 東京（GMT+9）10:00 起飛，飛 2 小時 30 分到臺北（GMT+8），臺北當地幾點？

1. 出發 GMT：10:00 − 9 ＝ 01:00
2. 抵達 GMT：01:00 ＋ 2:30 ＝ 03:30
3. 臺北時間：03:30 ＋ 8 ＝ **11:30**
:::

::: tip
**快速心算：** 兩地時差 ＝ 時區相減。從快的地方飛到慢的地方，當地時間會「變早」；反過來會「變晚」。
:::

### 8-3　國際換日線

- 大致沿著 **180 度經線**，但為了不把同一個國家切成兩天，所以**彎彎曲曲，不是直線**。
- 從西往東越過（例如臺灣飛美國）：日期**減一天**。
- 從東往西越過（例如美國飛臺灣）：日期**加一天**。

::: exam
**考古題（114年）：** 國際換日線的敘述何者錯誤？答：「**是一條作為變更日期的直線**」——錯，它不是直線。
:::

## 9　機場流程

### 9-1　報到

- 團體通常在**起飛前 2～3 小時**集合報到。
- **團體自助報到**流程（113年考題）：**自助選位 → 護照自動掃描 → 團體自助報到 → 刷出登機證**。
- 電子機票**不包含登機證**，登機證要報到後才拿到（108年考題）。
- 旅客可以**自己保管護照**到機場報到，旅行社**不能堅持**收走護照（107年考題）。
- 報到後超過集合時間 1 小時，還有團員沒到：把那位團員的**機票、護照、登機證**交給該團的**送機人員**轉交，領隊先帶其他人進關（106年考題）。

### 9-2　C.I.Q.：出入境的三道關卡

| 字母 | 英文 | 中文 | 檢查什麼 |
|---|---|---|---|
| **C** | Customs | **海關** | 有沒有帶違禁品、要繳稅的東西 |
| **I** | Immigration | **移民**（證照查驗） | 護照、簽證 |
| **Q** | Quarantine | **檢疫** | 人的健康、動植物 |

::: trap
**陷阱：** 入境卡、海關申報單要**旅客自己簽名**，領隊可以幫忙填寫，但**不能代簽**（108年考題）。
:::

### 9-3　安檢與液體規定

- **液體、膠狀、噴霧類**放手提行李：每瓶 **100 毫升**以下，全部裝進 **1 公升**以內的**透明夾鏈袋**，每人 1 袋。
- 安檢時要把液體袋**從包包裡拿出來**，放在置物盤上過 X 光機（113年考題）。
- 嬰兒奶粉、牛奶、藥品，數量合理可以帶，但要主動申報。

### 9-4　手提還是託運？

| 物品 | 手提 | 託運 | 說明 |
|---|---|---|---|
| **行動電源**、備用鋰電池 | ✔ | ✘ | **只能手提**，怕在貨艙起火沒人發現 |
| 手機、筆電 | ✔ | （不建議） | — |
| **水銀溫度計** | ✘ | ✘ | **完全不能帶**（水銀會腐蝕飛機） |
| 刀子、剪刀（刃長超過規定） | ✘ | ✔ | — |
| **三腳架**（收合後超過 **60 公分**） | ✘ | ✔ | — |
| 髮梳 | ✔ | ✔ | 不受限制 |
| 打火機 | 每人限 1 個隨身 | ✘ | — |
| 貴重物品、易碎品 | ✔ | — | 建議隨身；一定要託運可用「**報值行李**」 |

::: plain
**報值行李：** 託運時先申報行李的價值並付一點費用，萬一遺失，航空公司就照申報的價值賠，而不是照一般上限賠。
:::

### 9-5　轉機

| 名詞 | 意思 |
|---|---|
| **MCT** | **Minimum Connecting Time**，**最短轉機時間**。每個機場規定前後班機至少要隔多久，才來得及轉機 |
| **STPC** | Stopover Paid by Carrier：因**航空公司**的原因（例如延誤）害旅客當天轉不上班機，由**航空公司**負擔**食宿交通** |
| **In Bond Baggage** | **存關行李**：入境時寄放在海關保稅倉庫，出境時再領走的行李 |

### 9-6　機場服務費

- 從臺灣出境的旅客，每人 **新臺幣 500 元**，由航空公司**隨機票代收**。
- **未滿 2 歲**免繳（不是未滿 3 歲，111年考題）。

## 10　行李

### 10-1　免費託運行李的兩種算法

| 制度 | 算法 | 適用 |
|---|---|---|
| **計重制** | 算**總重量**，例如經濟艙 20～30 公斤 | 大部分航線（亞洲、歐洲） |
| **計件制** | 算**件數**，例如每人 2 件、每件 23 公斤 | **美洲相關航線**（進出美國、加拿大），例如**夏威夷到紐西蘭** |

### 10-2　跨好幾家航空公司的行李規定

一張機票有好幾家航空公司時，行李規定依「**最主要航段**」的航空公司（通常是**飛最遠、跨越 IATA 大區**的那段）。

::: example
**例子（113年考題）：** 第一段臺北→東京搭長榮，第二段東京→洛杉磯搭日航。行李規定依誰？
→ **日本航空**（跨太平洋那段最主要）。
:::

### 10-3　行李牌

託運後櫃檯會給**行李收據**（貼在登機證或機票上），要核對**姓名、目的地、件數、航班**；**出發地不用核對**（111年考題）。

### 10-4　行李沒到怎麼辦（每年必考）

**行李延誤（晚到）或遺失時，領隊的處理步驟：**

1. 請旅客準備**行李收據**、**護照**、**登機證**（或機票）
2. 到**入境機場**的航空公司**行李服務櫃檯**，填寫 **PIR**（Property Irregularity Report，**行李意外報告表**）
3. PIR 要寫：**行李外觀**（顏色、大小、品牌）、**內容物**、**聯絡電話與地址**、**之後的行程與住宿**。**不用寫賠償價格**
4. 請航空公司找到後**送到**旅客下一站的飯店，或回國後**送到旅客家**
5. 向航空公司爭取**零用金**（日用品補助），買盥洗用品、換洗衣物
6. 保留收據，日後申請賠償
7. 跨好幾家航空公司轉機：向**最後一段**的航空公司申報，**不用報警**（112年考題）

::: trap
**陷阱：**

1. 填的是 **PIR**，不是報案單（112、109、108年考題）。
2. 行李遺失是航空公司的責任，回國後找不到，要向**航空公司**求償，**不是**向旅行社（106年考題）。
3. 「請航空公司立刻提供一個新行李箱」**不是**標準流程（114年考題）。
:::

### 10-5　行李損壞與申訴期限

| 狀況 | 向航空公司書面申訴的期限 |
|---|---|
| 行李**損壞** | 拿到行李後 **7 天**內 |
| 行李**延誤** | 拿到行李後 **21 天**內 |

國際航空行李賠償的規定，最早是**華沙公約**，現在多數國家用**蒙特婁公約**。

### 10-6　我國的賠償標準（航空客貨損害賠償辦法）

| 項目 | 賠償 |
|---|---|
| 旅客**死亡** | 新臺幣 **300 萬元** |
| 旅客重傷 | 新臺幣 150 萬元 |
| **託運行李** | 每公斤新臺幣 **1,000 元** |
| **隨身行李** | 每位旅客最高新臺幣 **2 萬元** |

::: example
**例子（113、108年考題）：** 旅客的隨身行李損壞，損失 5 萬元（或 3 萬元），航空公司賠多少？
→ 隨身行李最高 **2 萬元**，所以賠 **2 萬元**。
:::

### 10-7　預防行李出問題

- 每件行李掛上**名牌**，寫英文姓名、電話。
- **貴重物品隨身帶**，不要放在託運行李或遊覽車上（109年考題）。
- 讓**行李員**統一搬運、清點件數，不要為了省小費叫客人自己提（108年考題）。
- 銀髮團入住飯店，在**行李牌上寫房號**，行李員才能很快送到房間（115年考題）。
- **Porterage** ＝ **行李搬運費**（行李小費）。

## 12　領隊實務情境

| 情境 | 正確作法 | 常見錯誤選項 |
|---|---|---|
| **班機取消**，全團滯留機場、飯店全滿 | 先**安撫團員**，聯繫旅行社和航空公司安排**餐券、臨時住宿** | — |
| 航空公司**空服員罷工**，回程可能取消 | 屬不可抗力，但增加的費用**不能一律要旅客負擔**；要積極協調航空公司改搭其他班機 | 「所有增加的費用都由旅客負擔」 |
| **機場員工罷工**，多住一晚 | 依**航空運送約款**，額外的住宿費用由**旅客**負擔（航空公司不負責）；旅客可用旅遊不便險申請 | — |
| 天候不佳**班機延誤**，要改行程 | 依定型化契約，增加的費用**不能向旅客收**、減少的要退 | 「超過的費用旅客和旅行社合力分擔」 |
| 要去機場時**遊覽車沒來** | 聯繫公司和車行、叫**合法的計程車**或其他合法營業車 | 用導遊朋友的**私人轎車**載客 |
| 團員**生病要提早回國** | 團體票通常不能單獨改期，一般是**另外買單程機票** | — |
| **回國後行李沒到** | 填 PIR，請航空公司把行李**送到團員家** | — |
| 臥鋪火車的**門鎖壞了** | **貴重物品隨身**，請**列車乘務員**協助 | — |
| 團員在**餐廳**因自己疏失掉東西 | 領隊協助找、報案，但旅行社**不用賠償** | 「旅行社必須負賠償責任」 |
| 帶**銀髮團**入住 | 在**行李牌上寫房號** | — |

## 13　容易搞混總整理

| 容易搞混 | 正確說法 |
|---|---|
| IATA vs ICAO | IATA：航空公司組成的**民間協會**；ICAO：**政府**組成的**官方組織** |
| TC1／TC2／TC3 | 美洲／歐非中東／亞洲大洋洲；北歐三國在 **TC2** |
| 華航 vs 長榮的聯盟 | 華航**天合**；長榮**星空** |
| 第一 vs 第五 vs 第九航權 | 一＝**飛越**；五＝**延遠**（中途在第三國上下客）；九＝**境內**營運 |
| OK／HK vs RQ／HL | 確認 vs 候補 |
| NS vs SA | NS：**嬰兒不占位**；SA：**空位搭乘**（業界優惠票） |
| WCHR／WCHS／WCHC | 能爬階梯／不能爬階梯／完全不能走 |
| PETC vs AVIH | 寵物在**客艙** vs 寵物在**貨艙** |
| GV15 | 至少 **15 人**的團體票 |
| YLAP21 的 21 | 出發前 **21 天**購票，不是 21 人 |
| 機票效期 | 沒用過：開票日起 1 年；用過：第一段搭乘日起 1 年 |
| 第二個嬰兒 | 買**兒童票**，不是成人票 |
| EMS 上限 vs 分段計價 | 加收上限 **25%**；TPM÷MPM 超過 **1.25** 改分段 |
| CNX vs CXM | 清邁是 **CNX** |
| BNE | 布里斯本在**澳洲**，不是紐西蘭 |
| 行李損壞 vs 延誤申訴 | **7 天** vs **21 天** |
| 隨身 vs 託運行李賠償 | 隨身最高 **2 萬**；託運每公斤 **1,000 元** |
| 機場服務費免繳 | **未滿 2 歲**，不是 3 歲 |
| 行動電源 | **只能手提** |
| 水銀溫度計 | **完全不能帶** |
