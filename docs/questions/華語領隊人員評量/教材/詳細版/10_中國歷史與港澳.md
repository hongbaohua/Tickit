## 1　基本名詞：先把字看懂

| 名詞 | 白話解釋 |
|---|---|
| **朝代** | 一個家族當皇帝的時期，例如「唐朝」 |
| **西元／公元** | 世界通用的年份算法；西元前（B.C.）是耶穌出生以前 |
| **世界遺產** | 聯合國教科文組織（UNESCO）認定「全人類都該保護」的地方，分**文化**、**自然**、**複合**（兩者都是）三種 |
| **青銅器** | 用銅和錫做的器物，商周時代最重要，常用來祭祀；**鼎**是有三隻腳或四隻腳的煮食、祭祀器 |
| **甲骨文** | 刻在烏龜殼、牛骨上的文字，是商朝占卜用的，中國最早的成熟文字 |
| **石窟** | 在山壁上挖出洞窟，裡面雕佛像、畫壁畫 |
| **絲綢之路（絲路）** | 古代中國和中亞、西亞、歐洲做生意的路線，因為中國賣絲綢出名 |
| **西域** | 漢代對玉門關、陽關以西（新疆、中亞）的稱呼 |
| **條約** | 國家之間簽的正式協議；清末很多是戰敗後被迫簽的「不平等條約」 |
| **割讓** | 把土地**永久**送給別國 |
| **租借** | 把土地**借**給別國一段時間 |
| **特別行政區** | 香港、澳門回歸後的地位，實行「**一國兩制**」：同屬中國，但保留原本的制度 |
| **皇陵** | 皇帝的墳墓 |
| **道場** | 佛教菩薩說法、受信徒參拜的聖地 |

## 2　朝代順序（先背這個）

**夏 → 商 → 周（西周、東周＝春秋＋戰國）→ 秦 → 漢（西漢、東漢）→ 三國 → 晉（西晉、東晉）→ 南北朝 → 隋 → 唐 → 五代十國 → 宋（北宋、南宋）→ 元 → 明 → 清 → 中華民國**

::: tip
**口訣：** 夏商周、秦漢三國、晉南北、隋唐五代、宋元明清。
:::

| 朝代 | 一句話記住 |
|---|---|
| 商 | 甲骨文、青銅器 |
| 西周 | 封建、禮樂；毛公鼎 |
| 春秋戰國 | 百家爭鳴：孔子、老子；都江堰 |
| 秦 | 第一個統一的帝國；兵馬俑、長城 |
| 漢 | 獨尊儒術、張騫通西域 → 絲路 |
| 三國 | 魏蜀吳；關羽、諸葛亮 |
| 晉、南北朝 | 王羲之書法；北魏開石窟 |
| 隋 | 大運河 |
| 唐 | 長安國際大都市；玄奘、鑑真 |
| 宋 | 經濟文化發達、海上貿易；山水畫 |
| 元 | 蒙古人；馬可波羅 |
| 明 | 遷都北京、建故宮；鄭和下西洋 |
| 清 | 承德避暑山莊；鴉片戰爭、割香港 |

## 3　上古到秦漢

### 3-1　商朝與古蜀文明

| 遺址或文物 | 重點 |
|---|---|
| **殷墟**（河南安陽） | 商朝後期首都，出土**甲骨文** |
| **三星堆**（四川廣漢，成都北方） | 和商朝**同時期**的**古蜀文明**；代表文物：**金面罩青銅人頭像**、青銅獸面具、青銅神樹（109、113年考題） |
| 后母戊鼎、四羊方尊 | 商代青銅器 |

### 3-2　西周

- **毛公鼎**：**西周晚期**青銅器，內壁有 500 字左右的銘文，是**臺北故宮**的鎮院之寶（111年考題）。

### 3-3　春秋戰國

- **孔子**：春秋時代魯國人，**儒家**創始人。故鄉山東**曲阜**的「**三孔**」──**孔廟、孔府、孔林**──是世界文化遺產（113年考題）。
- **都江堰**（四川）：戰國時秦國蜀郡太守**李冰**修建，到現在還在用（112年考題）：
    - **魚嘴**：把岷江分成內江、外江（分水）
    - **飛沙堰**：洪水時溢洪、排沙
    - **寶瓶口**：把水引進成都平原灌溉
- **京杭大運河**最早的一段「**邗溝**」：春秋時**吳國**開鑿，連接**長江**和**淮河**（108年考題）。

### 3-4　秦

- **秦始皇**統一六國，統一**文字、度量衡、貨幣**；修**長城**。
- 西安**兵馬俑**：秦始皇陵的陪葬坑。
- 秦漢以後「**編戶齊民**」：**編戶**＝被國家登記戶口的人；**齊民**＝理論上身分平等的人民（代表封建制度瓦解）。

### 3-5　漢

- **漢武帝**「**罷黜百家，獨尊儒術**」：儒家從此成為正統思想（115年考題）。
- **張騫通西域**（西漢）：打通往中亞的路 → 形成**絲綢之路**。
- 2014 年列入世界遺產：「**絲綢之路：長安－天山廊道路網**」（112年考題）。
- 東漢：佛教傳入中國（洛陽**白馬寺**是中國第一座佛寺）。

## 4　魏晉到隋唐

### 4-1　三國

- 魏（曹操）、蜀（劉備）、吳（孫權）三國鼎立。
- **關羽**：死後歷代皇帝一再加封（最後成為「關聖帝君」），目的是用他的**忠義**形象收攏民心、加強對地方的控制（114年考題）。
- 「滾滾長江東逝水，浪花淘盡英雄」：明代**楊慎**《廿一史彈詞》，後來成為《三國演義》開篇詞（113年考題）。
- 成都**武侯祠**（紀念諸葛亮）、長江三峽、赤壁。

### 4-2　晉、南北朝

- **王羲之**（東晉）：書聖；〈**快雪時晴帖**〉是臺北故宮鎮院之寶，故宮收藏的是**唐代摹本**（106年考題）。
- **北魏**：
    - 開鑿大同**雲岡石窟**、洛陽**龍門石窟**
    - **賈思勰**《**齊民要術**》：中國現存最早、最完整的**農書**（111年考題）

### 4-3　隋

- 開鑿**大運河**，連接南北。**京杭大運河**是 2014 年世界遺產。

### 4-4　唐

| 人物或事物 | 重點 |
|---|---|
| **長安**（今**西安**） | 唐代首都、國際大都市、**絲路起點**（106年考題）；日本**平安京**（京都）仿照長安棋盤式街道規劃 |
| **玄奘** | 從長安出發，經**甘肅河西走廊**（武威、張掖、酒泉、敦煌）、新疆，再穿越**中亞**（今烏茲別克等地）南下**印度**取經（110、112年考題）；西安**大雁塔**存放他帶回的經書 |
| **鑑真** | 唐朝高僧，東渡**日本**，成為日本**律宗**初祖，建奈良**唐招提寺**（108年考題） |
| **王維** | 〈送元二使安西〉：「勸君更盡一杯酒，**西出陽關無故人**」（陽關三疊） |

## 5　宋元

### 5-1　宋

**北宋山水畫三大名作**（都在**臺北故宮**，112年考題）：

| 作品 | 畫家 |
|---|---|
| 〈**谿山行旅圖**〉 | **范寬** |
| 〈**早春圖**〉 | **郭熙** |
| 〈**萬壑松風圖**〉 | **李唐** |

- 〈**清明上河圖**〉：**張擇端**，畫北宋首都**汴京**（今河南**開封**）的街景（106年考題）。
- 開封有一群**猶太人後裔**，祖先在**宋代**來到中國（110年考題）。

### 5-2　海上絲路

- 唐宋時南海貿易興盛，港口從**廣州**往北延伸到**泉州**、**明州**（寧波）。外國商人以**阿拉伯人**最多（114年考題）。
- 古代帆船靠季風：**西南季風**（夏天）把外國船送進廣州，**東北季風**（冬天）再送他們回去（107年考題）。福建人移民南洋也是**冬季東北風**出海（106年考題）。
- **泉州**：宋元時稱「**刺桐**」，**海上絲路起點**，有中國現存最早的清真寺**清淨寺**；2021 年列入世界遺產（108、114年考題）。
- 「**南海一號**」：**南宋**沉船，見證宋代海上貿易（106年考題）。

### 5-3　元與蒙古

- **蒙古四大汗國**（108年考題）：

| 汗國 | 位置 |
|---|---|
| **察合臺**汗國 | **中亞** |
| 窩闊臺汗國 | 新疆北部、蒙古西部 |
| **欽察**汗國 | **俄羅斯** |
| **伊兒**汗國 | **波斯**（伊朗） |

- 13 世紀蒙古西征，**屠城**中亞城市（例如土庫曼的梅爾夫，112年考題）。
- **馬可波羅**：13 世紀末來到元朝；那時中亞由**蒙古人**統治（111年考題）。

## 6　明清

### 6-1　明

| 項目 | 重點 |
|---|---|
| **明太祖朱元璋** | 定都**南京**，陵墓是南京**明孝陵**（110年考題） |
| **明成祖** | 遷都**北京**、興建**紫禁城**（故宮）；派**鄭和下西洋** |
| **鄭和下西洋** | 目的：**擴大海外貿易、宣揚國威**，不是找新大陸（108年考題）；鄭和船隊信奉**媽祖**（天妃）保佑航行（106年考題） |
| **利瑪竇** | **萬曆**年間來華的**耶穌會**傳教士，進呈《**坤輿萬國全圖**》（世界地圖），死後葬在北京（113年考題） |
| 明十三陵 | **明朝**皇帝陵墓（北京），不是清朝 |
| 玉米、番薯 | 明代中葉以後從**美洲**輾轉傳入，成為重要糧食作物（106年考題） |
| 「**湖廣熟，天下足**」 | 明代湖南、湖北成為全國糧倉（107年考題） |

### 6-2　清

| 項目 | 重點 |
|---|---|
| **清朝皇陵** | 關外「盛京三陵」、河北遵化**清東陵**、河北易縣**清西陵**（113年考題） |
| **承德** | **避暑山莊**（皇家園林）＋**外八廟**（御用寺廟），是清朝和**蒙古**、西藏等北方民族交流的要地（106、113年考題） |
| **揚州鹽商** | 明清時揚州鹽商聚集，講究飲食 → 精緻的**淮揚菜**（113年考題） |
| **天花** | 清**順治**皇帝、法王**路易十五**都死於天花（114年考題） |
| 1684 年開海禁 | 允許人民出海捕魚、貿易；但渡海來臺要**報官核可**、**不得攜眷**（107年考題） |

## 7　絲綢之路與中亞

### 7-1　路線

**長安（西安）／洛陽 → 甘肅河西走廊（武威、張掖、酒泉、敦煌）→ 陽關、玉門關 → 新疆 → 中亞 → 西亞、歐洲**

| 地點 | 重點 |
|---|---|
| **蘭州** | 甘肅省會，中國陸地版圖的幾何中心；**隴海鐵路**和**蘭新鐵路**交會處（110年考題） |
| **河西走廊**綠洲（酒泉等） | 靠**祁連山**高山融雪灌溉 |
| **陽關** | 敦煌**西南**約 60 公里；「西出陽關無故人」（113年考題） |
| **玉門關** | 敦煌**西北**；和陽關同為漢代出西域的關口 |

### 7-2　中亞歷史（111、112年考題）

1. 古代：安息帝國、絲路驛站
2. **阿拉伯人**統治後，知識分子大量翻譯**希臘文**著作
3. 13 世紀：**蒙古**西征
4. 14 世紀以後：**帖木兒**帝國建築
5. 20 世紀：屬**蘇聯** → 現在四十多歲以上的人都會說**俄語**

### 7-3　其他

- **一帶一路**：「一帶」＝絲綢之路經濟帶，核心都市之一是**西安**（107年考題）。
- **茶馬古道**：**雲南、四川**通往**西藏**的商貿路線，用茶葉換馬匹（112年考題）。

## 8　宗教與思想

| 宗教 | 重點 |
|---|---|
| **儒家** | 孔子；漢武帝起成為正統 |
| **道教** | 中國本土宗教；「**功過格**」＝魏晉以來道教信徒用**計分**的方式記錄善惡、自我約束（112年考題） |
| **佛教** | 東漢傳入；「**種福田**」＝誠心行善、布施，未來就能得福報，所以佛教徒常辦慈善（112年考題） |
| **伊斯蘭教** | 唐宋時阿拉伯、波斯商人從海上帶來；泉州**清淨寺**（114年考題）；新疆**維吾爾族**信伊斯蘭教、**不飲酒**（107年考題） |
| **天主教** | 明末**耶穌會**隨葡萄牙等海權國家東來，利瑪竇是代表（111年考題） |
| **媽祖**（天妃） | 航海守護神，鄭和船隊也祭拜 |

## 9　近代史

### 9-1　清末

| 年代 | 事件 | 結果 |
|---|---|---|
| 1840–1842 | **鴉片戰爭** | **南京條約**：割讓**香港島**、五口通商（113、115年考題） |
| 1856–1860 | 英法聯軍 | **北京條約**：割讓**九龍半島**南端 |
| 1894–1895 | 甲午戰爭 | **馬關條約**：割讓臺灣、澎湖給日本 |
| 1898 | — | 《展拓香港界址專條》：租借**新界** 99 年 |
| 1900 | 八國聯軍 | 南方督撫和列強約定「**東南互保**」，不聽朝廷宣戰命令 → 顯示清末**地方勢力上升**（109、115年考題） |
| 1911 | 辛亥革命 | 隔年中華民國成立 |

**自強運動：**

- **魏源**《海國圖志》：「**師夷之長技以制夷**」，學習西方技術來抵抗列強（110年考題）。
- **福州船政局**：左宗棠、沈葆楨主持，晚清規模最大的新式造船廠（107年考題）。

### 9-2　民國以後

| 事件 | 重點 |
|---|---|
| 1912 年郵票加蓋「臨時中立」 | 民國初年**在華列強**的態度（109年考題） |
| **二十一條要求**（1915） | 日本要求：「中國沿岸港灣及島嶼，概不讓與或租與他國」（109年考題） |
| 洪憲帝制 | **袁世凱**稱帝，**籌安會**支持（108年考題） |
| **五卅慘案**（1925） | 上海英國巡捕槍殺示威群眾（109年考題） |
| **西安事變**（1936） | 張學良、楊虎城扣押蔣介石；華清池「兵諫亭」（109年考題） |
| **大躍進** | 1950 年代末中共推動，全民大煉鋼、土高爐（108年考題） |
| 1997、1999 | 香港、澳門回歸，一國兩制 |

## 10　古都、建築與文化

### 10-1　古都與城市

- **五大古都**：**西安、洛陽、開封**、南京、北京；前三個都在**黃河**流域（112年考題）。
- 「**十年看深圳、百年看上海、千年看北京、三千年看西安**」（106、113年考題）：

| 城市 | 代表 |
|---|---|
| 深圳 | 改革開放後的**經濟特區** |
| 上海 | 開埠後的近代大城；簡稱「**滬**」，來自漁民的竹編捕魚工具「扈」（108年考題） |
| 北京 | 元明清首都 |
| 西安 | 周秦漢唐古都 |

- 老北京的庶民生活空間：**胡同**（巷弄）和**四合院**（113年考題）。

### 10-2　北京故宮

- **明成祖**興建；世界現存規模最大、最完整的古代**木結構**建築群（114年考題）。
- 中軸線**由北到南**：**保和殿 → 中和殿 → 太和殿 → 午門**（午門是**南**邊正門，113年考題）。
- 越南**順化皇城**（阮朝）模仿北京紫禁城（114年考題）。

### 10-3　石窟

| 分類 | 內容 |
|---|---|
| **三大石窟** | **敦煌莫高窟**、大同**雲岡**、洛陽**龍門**（109年考題） |
| **四大石窟**（依開鑿年代） | **敦煌莫高窟**（前秦 366 年）→ 天水**麥積山** → 大同**雲岡**（北魏）→ 洛陽**龍門**（北魏遷都洛陽後）（114年考題） |

### 10-4　名樓與名園

| 分類 | 內容 |
|---|---|
| **江南三大名樓** | 湖北**黃鶴樓**、湖南**岳陽樓**、江西**滕王閣**（114年考題） |
| **中國四大名園** | 蘇州**拙政園**、蘇州**留園**、北京**頤和園**、承德**避暑山莊**（無錫寄暢園不是，113年考題） |

### 10-5　古籍

- 《**山海經**》：先秦古籍，18 篇，記載山川、異獸、邦國、神話（113年考題）。

## 11　香港

### 11-1　怎麼變成英國的

| 地區 | 條約 | 方式 |
|---|---|---|
| **香港島** | **南京條約**（1842） | 割讓 |
| **九龍半島**南端 | **北京條約**（1860） | 割讓 |
| **新界** | 展拓香港界址專條（1898） | **租借 99 年** |

1997 年 7 月 1 日回歸中國，成為**特別行政區**。

### 11-2　現況（114年考題）

- 經濟主要靠**金融業**，國際金融與貿易中心；中國對香港經濟影響越來越大。
- 政治上實行一國兩制，但**沒有**完全的普選。

### 11-3　夜景

- 維多利亞港夜景被日本「夜景觀光會議局」評為「**世界三大夜景**」之一（另兩個是日本**長崎**、**摩納哥**）。
- 夜遊熱點：**維多利亞港**、**太平山頂**、「**幻彩詠香江**」燈光秀、星光大道（「倫敦人購物中心」在**澳門**，不是香港，113年考題）。

## 12　澳門

| 項目 | 重點 |
|---|---|
| 歷史 | 16 世紀中葉**葡萄牙**人取得居住權，東西方交流的門戶；**1999 年**回歸 |
| **澳門歷史城區** | **2005 年**列入世界文化遺產（113年考題）：**大三巴牌坊**、議事亭前地、**媽閣廟**等 |
| **大三巴牌坊** | **聖保祿教堂**遺址，屬**天主教**建築；教堂燒毀後只剩前壁，形狀像中國牌坊（114年考題） |
| 經濟 | 以**博弈**（賭場）觀光為主 |
| 交通政策 | 「**公交優先、綠色出行**」：減少車流和廢氣，保護歷史城區的古建築（114年考題） |

### 港珠澳大橋

- **2018 年**完工，連接**香港、澳門**兩個特別行政區和**珠海**經濟特區（115年考題）。
- 橫跨**珠江**口；往來三地只要幾十分鐘。
