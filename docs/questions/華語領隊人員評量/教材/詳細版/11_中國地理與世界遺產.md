## 1　基本名詞：先把字看懂

| 名詞 | 白話解釋 |
|---|---|
| **地形** | 地表的高低形狀：山地、高原、盆地、平原、丘陵 |
| **高原** | 又高又平的大片地面 |
| **盆地** | 四周高、中間低，像臉盆 |
| **季風** | 隨季節改變方向的風。中國**夏天吹東南（西南）季風**，帶來雨；**冬天吹西北（東北）季風**，又冷又乾 |
| **溫差** | 最高溫和最低溫差多少；沙漠、高原**日夜溫差大** |
| **喀斯特（岩溶）** | **石灰岩**被含二氧化碳的雨水**溶蝕**，形成奇峰、溶洞、地下河 |
| **鈣華** | 含鈣的水流動時，鈣質**沉澱堆積**，形成梯田狀的池子 |
| **綠洲** | 沙漠中有水、能種田住人的地方 |
| **沖積扇** | 河流從山裡流出到平地，帶來的泥沙堆成扇形 |
| **融雪** | 高山上的冰雪夏天融化成水 |
| **溼地** | 長期積水的地方，如沼澤，是鳥類棲息地 |
| **複合遺產** | 同時是**文化**和**自然**遺產 |

## 2　地形骨架

### 2-1　三級階梯（西高東低）

| 階梯 | 地形 |
|---|---|
| 第一級（最高） | **青藏高原**（世界屋脊） |
| 第二級 | 內蒙古高原、黃土高原、雲貴高原、四川盆地、新疆盆地 |
| 第三級（最低） | 東部平原、丘陵 |

### 2-2　高原、盆地、平原

| 分類 | 內容 |
|---|---|
| **四大高原** | **青藏**（最高）、**內蒙古**（草原）、**黃土**（窯洞）、**雲貴**（喀斯特） |
| **四大盆地** | **塔里木**（新疆南）、**準噶爾**（新疆北）、柴達木（青海）、**四川**（天府之國） |
| **三大平原** | 東北、華北、長江中下游 |

### 2-3　重要分界線

**秦嶺－淮河**：華北和華中的分界，大致等於一月均溫 **0℃** 等溫線、年雨量 **800 公釐**線（106年考題）。北邊種小麥、吃麵；南邊種稻、吃米。

## 3　河流與水利

| 河流 | 重點 |
|---|---|
| **長江** | 中國最長；發源**青藏高原**；三峽；中下游「魚米之鄉」 |
| **黃河** | 流經**黃土高原**，含沙量大；五大古都多在黃河流域 |
| **珠江** | 華南；出海口有香港、澳門（港珠澳大橋） |
| **黑龍江** | 中俄界河；最大支流**松花江**（滿語 sunggari ula＝**天河**，113年考題） |
| **瀾滄江** | 雲南，流經**西雙版納**，出境後叫**湄公河**（111年考題） |
| **鴨綠江** | 中國和北韓界河；**丹東**對岸是北韓**新義州**，可感受邊境貿易（109年考題） |

- **三江源**：長江、黃河、瀾滄江都發源於青藏高原，被稱為「**中華水塔**」（109年考題）。
- **南水北調**：中國**南方水多、北方缺水**，把長江的水調往華北（109年考題）；分東線、中線、西線（東線沿京杭大運河）。
- **黃河斷流**原因：集水區**濫墾濫伐**、上游**興建水庫**大量引水（108年考題）。

## 4　各區地理

### 4-1　東北

| 項目 | 重點 |
|---|---|
| **哈爾濱** | 黑龍江省中心，每年**國際冰雪節**（111年考題） |
| **三江平原**（黑龍江、松花江、烏蘇里江） | 緯度高，農業最大威脅是**寒害**（108年考題） |
| **扎龍溼地**（松嫩平原） | **丹頂鶴**棲息的高草沼澤（112年考題） |
| **長白山** | **火山**：火山錐、火口湖（**天池**）、熔岩台地（107年考題） |

### 4-2　華北

- **北京**：秋冬常有**霧霾**（燒煤取暖）、春天**沙塵暴**（109、107年考題）。
- **河北、山東**成為重要蔬果產地：靠溫室等**技術革新，克服氣候限制**（112年考題）。
- **濟南**「泉城」：濟水在石灰岩區潛入地下再冒出成泉，屬**岩溶**地形（107年考題）。

### 4-3　華中、華東

- **長江三角洲**水鄉：小河穿鎮、石橋、民居臨水（例：周莊、同里、烏鎮，109年考題）。
- **上海**向浙江租借大、小洋山島建**深水港**，因為上海海岸多為**沙岸**、水淺（108年考題）。

### 4-4　華南

- **多雨潮溼** → 常見**騎樓**、**高腳屋**（115年考題）。
- **海南島**：熱帶季風氣候，受**海洋**影響強（114年考題）。

### 4-5　西南

| 地方 | 重點 |
|---|---|
| **四川盆地** | 「**蜀犬吠日**」：常年雲霧多、少見太陽（109年考題） |
| **西雙版納**（雲南） | 熱帶季風雨林；「孔雀之鄉」「中國熱帶動植物王國」；**傣族**（111年考題） |
| **麗江**（雲南） | **納西族**，東巴文化、納西古樂（109年考題）；附近瀘沽湖**摩梭族**「走婚」：男子晚上到女方家，各居母家（106年考題） |
| **大理洱海** | **斷層陷落**形成的湖（112年考題） |
| **康定**（四川甘孜） | 藏族**康巴**人文化中心，附近**貢嘎山**（113年考題） |

### 4-6　西北、新疆

| 項目 | 重點 |
|---|---|
| **三山夾兩盆** | **阿爾泰山**、**天山**、**崑崙山** 夾著**準噶爾盆地**、**塔里木盆地**（110年考題） |
| **吐魯番**綠洲 | 在**山麓沖積扇**上，靠**天山融雪**滲入的地下水（111年考題）；「火州」 |
| **坎兒井** | 吐魯番、哈密的古代**地下水灌溉**工程：**豎井、暗渠、明渠、澇壩**四部分；是渠道，**不是河流**（110、111年考題） |
| **河西走廊**綠洲（酒泉） | 靠**祁連山**融雪（111年考題） |
| **胡楊林** | **塔里木河**沿岸（108年考題） |
| **雅丹**地形 | **羅布泊**的長條狀**風蝕**小丘（109年考題） |
| 沙漠公路 | 塔里木盆地輪民沙漠公路，常被**流動沙丘**淹沒（106年考題） |
| 生活 | 瓜果之鄉；吃太多哈密瓜「上火」（107年考題）；街頭有樂器演奏、瓜果市場（112年考題） |
| **喀什** | 「五口通八國，一路連歐亞」，**終年乾燥少雨**（106年考題） |

### 4-7　青藏高原

- 「**一年無四季，一日見四季**」：海拔高、空氣稀薄，**日夜溫差極大**（110年考題）。
- **青藏鐵路**：車廂全封閉、雙層防壓玻璃、座位有**供氧口**（110年考題）。
- 只分布在高原、受保護的動物：**雪豹**、**藏羚羊**（可可西里）（114年考題）。

### 4-8　內蒙古高原

- 岩石因**日夜溫差大**熱脹冷縮而碎裂（106年考題）。
- **那達慕**大會、蒙古包。

| 地貌 | 成因 | 代表景點 |
|---|---|---|
| **喀斯特（岩溶）** | 石灰岩被雨水**溶蝕** | **桂林、陽朔**（灕江，「桂林山水甲天下」）、雲南**石林**、貴州**黃果樹瀑布**（在**打幫河**，115年考題）、**九寨溝**；越南**下龍灣**「水上桂林」（115年考題） |

| **雅丹** | 風蝕 | 新疆**羅布泊** |
| **黃土** | 風吹來的細土堆積 | **黃土高原**：窯洞 |

## 9　中國的世界遺產

### 9-1　分類總表

| 類別 | 遺產 |
|---|---|
| 皇家 | 北京故宮、天壇、頤和園、明清皇家陵寢、承德避暑山莊、**北京中軸線** |
| 古城、古村 | **平遙古城**（山西）、**麗江古城**（**1997** 年一起列入，114年考題）、皖南古村落（宏村、西遞）、**福建土樓**、開平碉樓、**鼓浪嶼** |
| 宗教、石窟 | **莫高窟**、雲岡、龍門、大足石刻、**武當山**、曲阜三孔、五臺山、布達拉宮 |
| 自然 | 黃山、九寨溝、黃龍、**武陵源**（張家界）、**三江併流**、可可西里、梵淨山 |
| **複合**（文化＋自然） | **泰山**、**黃山**、**峨眉山－樂山大佛**、**武夷山**（107年考題） |
| 線性、跨國 | **絲綢之路**（2014）、**大運河**（2014） |
| 其他 | 杭州**西湖**、蘇州古典園林、**澳門歷史城區**（2005）、良渚古城、**泉州**（2021）、都江堰－青城山 |

### 9-2　常考細節

- **平遙古城**：清代**票號**林立，「古代中國華爾街」（112年考題）。
- **武夷山**（福建）：有**閩越國王城遺址**和亞熱帶原生森林，所以是複合遺產（109年考題）。
- **武當山**只是**文化**遺產，不是複合遺產。
- **三江併流**（**金沙江、瀾滄江、怒江**）：中國**面積最大**的世界遺產，在雲南，位於湄公河等東南亞河流的上游（114年考題）。
- **揚州瘦西湖**：屬「**大運河**」世界遺產的一部分（112年考題）。

## 11　容易搞混總整理

| 容易搞混 | 正確說法 |
|---|---|
| 喀斯特 vs 鈣華 | 溶蝕（桂林）vs 沉澱（黃龍） |
| 張家界 vs 桂林 | 砂岩峰林 vs 石灰岩喀斯特 |
| 洱海 vs 天池 | 斷層湖 vs 火山口湖 |
| 雅丹 vs 喀斯特 | 風蝕 vs 水溶蝕 |
