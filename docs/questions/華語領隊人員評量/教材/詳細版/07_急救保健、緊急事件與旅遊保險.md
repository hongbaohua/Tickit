## 1　基本名詞：先把字看懂

### 1-1　急救相關

| 名詞 | 白話解釋 |
|---|---|
| **意識** | 人是不是清醒、叫他有沒有反應 |
| **生命徵象** | 判斷一個人狀況的基本數值：**體溫、脈搏、呼吸、血壓**（**血糖不是**） |
| **CPR** | 心肺復甦術：心跳停止時，用**壓胸**讓血液繼續流動，必要時加上**人工呼吸** |
| **AED** | 自動體外心臟電擊去顫器：機器會自己判斷心律，必要時**電擊**讓心臟恢復正常跳動。機場、車站、飯店常有 |
| **哈姆立克法** | 用力推擠肚子，把卡在喉嚨的東西擠出來的方法 |
| **急症** | 突然發生、可能危及生命的疾病，例如中風、心臟病發作 |
| **中風** | 腦部血管**阻塞或破裂**，腦細胞缺血受損 |
| **心肌梗塞** | 供應心臟的血管**阻塞**，心肌缺氧壞死，就是常說的「心臟病發作」 |
| **癲癇** | 腦部異常放電，造成**突然失去意識、全身抽搐** |
| **熱傷害** | 天氣太熱、身體散熱不了造成的傷害，嚴重的叫**中暑** |
| **止血帶** | 綁在手臂或腿上、勒緊阻止血流的帶子 |
| **開放性骨折** | 骨頭斷了而且**刺破皮膚**露出來 |
| **栓塞** | 血塊（血栓）跑到血管裡塞住，例如**肺栓塞** |

### 1-2　疾病與衛生

| 名詞 | 白話解釋 |
|---|---|
| **傳染病** | 會從一個人（或動物）傳給另一個人的病 |
| **傳染途徑** | 病菌怎麼傳過來：飲食、飛沫、蚊蟲、血液等 |
| **飛沫傳染** | 咳嗽、打噴嚏噴出的小水滴把病毒傳給別人 |
| **病媒蚊** | 會傳播疾病的蚊子 |
| **疫苗** | 事先打進身體，讓身體產生抵抗力的藥劑 |
| **檢疫** | 入境時檢查人、動植物有沒有帶傳染病 |
| **疫區** | 某種傳染病正在流行的地區 |
| **旅遊醫學門診** | 醫院專門提供出國前打疫苗、拿預防藥、做健康諮詢的門診 |

### 1-3　緊急事件與保險

| 名詞 | 白話解釋 |
|---|---|
| **緊急事件** | 旅途中突然發生、需要立刻處理的事，例如車禍、生病、證件遺失、天災 |
| **駐外館處** | 我國在外國設立的**大使館、代表處、辦事處**，負責護照、簽證和協助在當地的國人 |
| **急難救助** | 國人在國外遇到重大困難時，政府提供的協助 |
| **入國證明書** | 護照在國外遺失、來不及補發時，駐外館處發給的**只能用來回臺灣**的證明文件 |
| **旅遊警示** | 政府提醒民眾某個國家可能有危險的燈號 |
| **理賠** | 保險公司依約付錢 |
| **責任保險** | 旅行社依法一定要買，旅客發生**意外**時由保險公司賠 |
| **履約保證保險** | 旅行社依法一定要買，旅行社**倒閉、出不了團**時賠旅客團費 |
| **核退** | 先自己付醫藥費，之後拿收據申請退一部分錢 |

## 2　急救的總原則

1. **先確認環境安全**：自己也要安全，例如車禍現場先注意來車。
2. **評估意識**：拍肩膀、大聲叫他。發現路倒的人，**第一步就是評估意識**（112年考題）。
3. **求救**：打當地緊急電話（各國不同，例如歐盟 112、美國 911、日本 119），請旁人拿 AED。
4. **不要隨便移動傷患**：尤其可能骨折、頭頸受傷的人，等救護人員處理。
5. **不要脫光傷患的衣服**：只脫掉妨礙處理的部分，並注意保暖（108年考題）。
6. **頭部重傷不要抬高腳**：抬腳會讓血液衝向頭部（106年考題）。
7. **描述病情給醫師聽**：從**主要症狀**講起、**由頭部往下**依序說明，**不是由腳往上**（115年考題）。也要說明過去病史、正在吃的藥、過敏。

::: tip
**常用英文：** 高血壓 **Hypertension**、腹瀉 **diarrhea**（一天兩次：diarrhea two times a day）、霍亂 **Cholera**。
:::

## 3　CPR 與 AED

### 3-1　什麼時候要做 CPR

對方**沒有意識、沒有呼吸（或只有喘息）**，就要做。中暑、體力不支但還有意識的人，**不需要**做 CPR（107年考題）。

### 3-2　步驟口訣：叫叫 C-A-B-D

| 步驟 | 做什麼 |
|---|---|
| **叫** | 叫叫看：拍肩、大聲叫，確認有沒有**意識** |
| **叫** | 叫人幫忙：打**緊急電話**、請人拿 **AED** |
| **C**（Compressions） | **胸部按壓**（最重要） |
| **A**（Airway） | **暢通呼吸道**：壓額抬下巴 |
| **B**（Breathing） | **人工呼吸**：吹 2 口氣 |
| **D**（Defibrillation） | **AED 電擊** |

### 3-3　胸部按壓的標準（每年必考）

| 項目 | 標準 |
|---|---|
| 位置 | **胸骨下半段**（兩乳頭連線中央）；**不是劍突**（胸骨最下面的尖端，壓了會傷內臟） |
| 手勢 | **雙手手指互扣**、手指微翹，用**掌根**按壓，手臂打直 |
| 深度 | **5～6 公分** |
| 速度 | 每分鐘 **100～120 下** |
| 壓胸：吹氣 | **30：2**（會人工呼吸的話） |
| 換人 | 每 **2 分鐘**換人按壓，避免疲勞 |

**有效按壓五口訣：** **用力壓、快快壓、胸回彈、莫中斷、二分換**。

::: plain
**為什麼不檢查脈搏？** 一般人很難在短時間內摸準脈搏，浪費時間。所以**民眾版 CPR 已經不教檢查脈搏**，只要沒意識、沒正常呼吸就直接壓胸。
**高品質 CPR 不包括**「用力吹氣、每次至少 2 秒」——吹氣只要讓胸部微微隆起，約 1 秒，太用力反而會把氣吹進胃（106年考題）。
:::

### 3-4　AED 怎麼用

1. **開機**，照著機器的語音指示做
2. **貼上貼片**（照貼片上的圖示位置）
3. 機器**分析心律**時，大家不要碰病人
4. 機器說要電擊，確認沒人碰觸病人後按電擊鈕
5. 電擊後**立刻繼續 CPR**，**不要關機**，AED 每 2 分鐘會再自動分析

- 1～8 歲兒童：優先用兒童貼片；沒有兒童貼片時**可以用成人貼片**（「禁止使用」是錯的，109年考題）。

::: trap
**陷阱：** 「電擊後關閉電源，以利 CPR 進行並節約用電」是**錯的**（114年考題）。
:::

## 4　呼吸道異物哽塞（哈姆立克法）

| 狀況 | 怎麼辦 |
|---|---|
| **部分阻塞**：還能說話、**能用力咳嗽** | **鼓勵他用力咳**，不要做哈姆立克法（113年考題） |
| **完全阻塞**：不能說話、不能咳、不能呼吸，常**雙手抓住喉嚨** | 立刻做**哈姆立克法**（115年考題） |
| 病人**失去意識** | 改做 **CPR** |

**哈姆立克法做法（成人）：** 站在病人背後，雙手環抱他的腰，一手握拳放在**肚臍上方**，另一手包住拳頭，**快速向內、向上**擠壓，直到異物吐出。

## 5　常見急症

### 5-1　中風

**辨識口訣 FAST：**

| 字母 | 檢查 |
|---|---|
| **F**ace | 請他微笑，**臉歪**一邊嗎？ |
| **A**rm | 請他雙手平舉，**一手無力**垂下嗎？ |
| **S**peech | 請他說一句話，**口齒不清**嗎？ |
| **T**ime | 有上述任一症狀，**記下發作時間**，立刻送醫 |

**處理：** 讓病人躺下或半坐臥、保持呼吸道通暢、立刻送醫；**不可給水或食物**（可能吞嚥困難而嗆到，115年考題）。

::: trap
**陷阱：** 「起身後突然**天旋地轉站不穩**」比較像**姿勢性眩暈**，不是典型的中風前兆，可以先休息觀察（114年考題）。
:::

### 5-2　心臟病發作（心肌梗塞）

**症狀：** **胸口中央壓迫、緊縮的痛**，持續**數分鐘以上**；常伴隨**冒冷汗、臉色蒼白、呼吸急促、心悸、噁心嘔吐**，痛感可能延伸到**肩頸、左手臂、下巴**。

**處理：** 停止活動、讓病人休息（半坐臥最舒服）、**立刻打當地緊急電話**（115年考題）；如果失去意識，做 CPR。

### 5-3　心絞痛與硝酸甘油（NTG）

心絞痛是心臟暫時缺氧引起的胸痛。病人如果有醫師開的**硝酸甘油（NTG）舌下錠**，要**放在舌頭下面含著溶化**，**不是**用開水吞服（110年考題）。

### 5-4　癲癇

**症狀：** 突然失去意識、倒地、**全身抽搐**、咬牙、口吐白沫。

**處理：**

1. **移開周圍的危險物品**，保護頭部
2. 抽搐停止後讓他**側躺**，讓口水流出、保持呼吸道通暢
3. 記錄發作時間

**絕對不可以：** 用手撬開牙關、塞毛巾或東西進嘴巴、用力壓住四肢（114年考題）。

### 5-5　熱傷害與中暑

**處理順序（114年考題）：** **蔭涼 → 脫衣 → 散熱 → 喝水 → 送醫**

1. 移到**陰涼**通風處
2. **脫掉**多餘的衣物
3. 用冷水擦身體、搧風**散熱**
4. **意識清楚**才給他**喝水**（失去意識不能餵水）
5. **送醫**

### 5-6　其他慢性病與急症

| 狀況 | 重點 |
|---|---|
| **糖尿病** | 隨身帶糖果防低血糖；**濃湯、碎肉製品**（脂肪、鈉含量高）要少吃（112年考題）；機上糖尿病餐代碼 **DBML** |
| 糖尿病人要在機上**打胰島素** | 在機場向**航空警察局安檢人員**申報，同意後才能帶針具上機（108年考題） |
| **氣喘** | 讓病人**坐起來、身體前傾**比較好呼吸、好排痰；**不要平躺**（106年考題） |
| **肺栓塞** | 長時間不動（例如長途飛行）後，突然**呼吸困難、胸痛、心跳加快**；「心跳變很慢」**不是**肺栓塞的症狀（111年考題） |
| **誤食有毒動植物** | 噁心、嘔吐、腹痛、腹瀉、頭暈；「**發燒**」通常不是中毒的直接症狀（106年考題） |

## 6　外傷

### 6-1　燒燙傷：沖、脫、泡、蓋、送

| 步驟 | 做法 |
|---|---|
| **沖** | 用**流動的冷水**沖傷處 **15～30 分鐘**（不是只沖 10 分鐘） |
| **脫** | 在水中小心**脫掉**衣物，黏住的不要硬扯，可用剪刀剪開 |
| **泡** | 用冷水**泡** 15～30 分鐘，減輕疼痛 |
| **蓋** | 用**乾淨的布**或紗布**蓋住**傷處 |
| **送** | **送醫**治療 |

- **水泡不要刺破**，避免感染（110年考題）。
- **燒燙傷分度：**
    - 一度：皮膚**紅、痛**
    - 二度：**起水泡**、很痛
    - **三度**：皮膚**黑色或白色**、組織壞死，**幾乎不痛、麻木**（神經也壞了，106年考題）
- 成人**三度燒傷超過體表面積 10%**，就有生命危險（112年考題）。
- 火災初期最容易致命的是**呼吸道吸入性燒傷**（吸入熱煙，呼吸道腫起來無法呼吸，115年考題）。

### 6-2　出血

| 方法 | 什麼時候用 |
|---|---|
| **直接加壓止血**（最常用、優先） | 用乾淨紗布直接壓住傷口 |
| **抬高**受傷部位 | 配合加壓 |
| **止血點加壓** | 壓住傷口**上游**的動脈。例：**前臂出血**壓上臂內側的**肱動脈**（106年考題） |
| **止血帶** | **最後手段**：只用在**四肢大動脈出血、加壓止不住**時，例如**大腿遠端動脈出血**（114年考題）；綁在傷口**靠近心臟**的那一側，並記錄時間 |

### 6-3　骨折

- **固定**範圍要包含骨折處**上下兩個關節**，不是只固定骨折部位（111年考題）。
- 不要隨便移動、不要試著把骨頭推回去。
- **開放性骨折**：用乾淨紗布蓋住傷口，固定後送醫。

### 6-4　其他外傷

| 狀況 | 處理 |
|---|---|
| **斷指、斷肢** | 用**生理食鹽水沾溼的紗布**包好，裝進塑膠袋，再放進**冰水**裡**低溫保存**（不可直接碰冰塊），和傷者一起送醫（108年考題） |
| **腹部撕裂、腸子外露** | **不可**把腸子塞回去；用**生理食鹽水沾溼的紗布**蓋住保護（109年考題） |
| **扭傷** | **冰敷**最能立刻減輕腫脹（107年考題）；記法 **RICE**：休息（Rest）、冰敷（Ice）、壓迫（Compression）、抬高（Elevation） |
| **傷口消毒** | 以**傷口為中心，環形往外**擦（107年考題），不要從外往內把髒東西帶進傷口 |

**急救箱該有的東西：** 紗布、繃帶、OK 繃、消毒用品、剪刀、膠帶、體溫計、常備藥等；**保險套不是**急救箱的物品（107年考題）。

## 7　戶外與特殊環境

### 7-1　毒蛇咬傷

**要做：**

- 保持**冷靜**、減少活動（心跳越快，毒越快擴散）
- 記住蛇的**外觀特徵**（或拍照），方便醫院選對**血清**
- 患肢**放低**（低於心臟）、拿掉戒指手錶
- 包紮**不可太緊**，要能伸進一根手指
- 儘快送醫

**不要做：** **切開傷口**放血、用嘴吸毒、冰敷、綁太緊（106、113年考題）。

### 7-2　蜂螫

- 虎頭蜂螫傷可能引起**過敏反應**：眼皮浮腫、全身起疹、**呼吸困難**，嚴重會休克，要儘快送醫（113年考題）。
- 遇到蜂群：用衣物保護頭部，**往低處、快速離開**；**不要就地臥倒**（蜂群會一直攻擊，114年考題）。

### 7-3　高山症

到了**高海拔**地區（約 2,500 公尺以上，例如**西藏**、**瑞士少女峰**），空氣稀薄、氧氣少，身體適應不了。

| 項目 | 內容 |
|---|---|
| 典型症狀 | **頭痛**、**噁心**、嘔吐、頭暈、疲倦、失眠（111年考題） |
| 嚴重、會致命的 | **高海拔肺水腫**（呼吸困難、咳粉紅色痰）、**高海拔腦水腫**（意識不清、走路不穩）；「發燒嘔吐」**不是**致命原因（106年考題） |
| 預防 | 慢慢上升、**避免劇烈運動和喝酒**、多喝水（107年考題） |
| 處理 | **休息、不要再往上**、給氧氣、**下降**到低海拔、請當地人員協助**送醫**；**不要**「增加活動避免昏睡」（108年考題） |

### 7-4　潛水夫症（減壓病）

潛水後太快浮上水面，溶在血液裡的氣體變成氣泡。症狀：**關節深部疼痛**、皮膚癢、麻木、**抽搐**、呼吸困難；**淋巴結腫大、打噴嚏不是**（111年考題）。處理：送有**高壓氧艙**的醫院。

### 7-5　水域與沙灘活動

- 下水前做暖身、穿救生衣、不在禁止區游泳、不單獨行動。
- 垃圾要**帶走**，不能就地掩埋（112年考題）。

## 8　傳染病與旅遊保健

### 8-1　傳染途徑總表（必背）

| 疾病 | 傳染途徑 | 預防 |
|---|---|---|
| **A 型肝炎** | **不潔的食物、飲水**（糞口傳染） | 打疫苗、注意飲食衛生 |
| B、C 型肝炎 | **血液、體液** | B 肝打疫苗 |
| **新冠肺炎、流感** | **空氣或飛沫** | 戴口罩、勤洗手、打疫苗 |
| **登革熱** | **埃及斑蚊**、白線斑蚊 | 防蚊 |
| **日本腦炎** | **三斑家蚊**等家蚊（**不是**埃及斑蚊） | 打疫苗、防蚊 |
| **瘧疾** | **瘧蚊** | 吃預防藥、防蚊 |
| 霍亂 | 不潔的水、海鮮 | 飲食衛生 |
| **沙門氏菌** | 沒煮熟的蛋、肉、受汙染的食物 | 食物煮熟、生熟分開；**不是**完全不能吃沙拉冷盤（113年考題） |
| 愛滋病 | 性行為、血液、母子垂直傳染 | 安全性行為、不共用針具；**一起吃飯不會傳染**（109年考題） |
| 麻疹 | 空氣、飛沫（傳染力極強） | 打 MMR 疫苗；**不是所有旅客都要打**（例如已有抗體者，110年考題） |

::: tip
**蚊子記法：** 「**登革熱→埃及斑蚊**」，「**日本腦炎→家蚊**」，「**瘧疾→瘧蚊**」。
:::

**流行性感冒：** 由流感病毒引起，在臺灣主要流行的是 **A 型、B 型**；「主要是 C 型」是錯的（109年考題）。

### 8-2　國際檢疫傳染病

**霍亂、鼠疫、黃熱病**（**瘧疾不是**，112年考題）。

- 去**非洲、南美洲**部分國家，要有**黃熱病疫苗**接種證明（國際預防接種證明書，俗稱「黃皮書」）。
- 去**沙烏地阿拉伯**（例如朝聖），要有**流行性腦脊髓膜炎**疫苗接種證明（106年考題）。

### 8-3　瘧疾預防 ABCD

| 字母 | 意思 |
|---|---|
| **A**（Awareness） | **認識風險**：知道要去的地方有沒有瘧疾 |
| **B**（Bite prevention） | **防蚊叮咬**：穿**淺色**長袖長褲、擦防蚊液、睡蚊帳 |
| **C**（Chemoprophylaxis） | **吃預防藥** |
| **D**（Diagnosis） | **儘早診斷**：出現發燒就立刻**就醫**，並告訴醫師去過疫區 |

::: trap
**陷阱：**

1. 瘧疾**沒有**可以普遍施打的「預防疫苗」，是吃**預防藥**（「進入疫區前應施打瘧疾預防疫苗」是錯的，111年考題）。
2. 晚上外出穿**淺色**衣物，**不是深色**（蚊子喜歡深色，108年考題）。
3. 在疫區發燒、發冷、頭痛，要**立刻到當地醫院就醫**，不要等回國（107年考題）。
:::

### 8-4　旅行者腹瀉

- 喝**瓶裝水**或**煮沸的水**、吃**熟食**；**不要喝自來水**、少吃生冷食物、不加來路不明的冰塊。
- 最安全的食物：**還沒剝皮的香蕉、還沒削皮的蘋果**（自己剝皮，裡面沒被汙染，106年考題）。

### 8-5　出國前與旅途中的保健

| 項目 | 重點 |
|---|---|
| **旅遊醫學門診** | 疾管署建議出國前 **2～4 週**就診（打疫苗要時間產生抗體，112年考題） |
| 傳染病防治原則 | 預防為主（疫苗、衛生、防蚊）；**不是**「優先使用抗生素」（113年考題） |
| **時差調適** | 出發前**逐步調整睡眠時間**；抵達後**白天多曬太陽、晚上避免光照**（115年考題） |
| **經濟艙症候群** | 長時間坐著，腿部形成血栓。預防：**每小時活動下肢幾分鐘**、多喝水、不喝酒、穿寬鬆衣物 |
| 飛機上發現**疑似傳染病**的旅客 | 機組人員要**立刻通報**目的地的檢疫單位，**不是**等落地再說（108年考題） |

## 9　緊急事件處理原則

### 9-1　CRISIS 六步驟

| 字母 | 英文 | 意思 |
|---|---|---|
| **C** | Calm | **冷靜**：領隊先穩住自己 |
| **R** | **Report** | **報告**：通報旅行社、當地警察、駐外館處等 |
| **I** | Interpretation | **說明**：向團員說明狀況，**控制、掌握客人的行動和心態**（115年考題） |
| **S** | Solution | **解決**：處理問題 |
| **I** | Inspection | **檢查**：追蹤處理結果 |
| **S** | Summary | **總結**：寫報告、檢討 |

::: trap
**陷阱：** R 是 **Report（報告）**，**不是** Repeat（覆述）（111年考題）。
:::

### 9-2　通報時限與文件

- 領隊遇到**緊急事故**，要在 **24 小時內**向**受僱的旅行社**及**交通部觀光署**報備（**不是** 48 小時，114年考題）。
- 旅行社向觀光署通報的「**旅遊團緊急事故報告書**」，要附：**該團行程**、**團體名冊**、**出團責任保險單**（114年考題）。
- 航空公司人員也可以協助和班機**無關**的緊急事件，有需要就請他們幫忙（110年考題）。

### 9-3　旅遊警示

**外交部**發布國外旅遊警示，大陸港澳由**陸委會**發布（見第二章）：

| 燈號 | 意思 |
|---|---|
| **灰色** | **提醒注意** |
| **黃色** | **特別注意**旅遊安全，並檢討應否前往 |
| **橙色** | **避免非必要旅行**（例如政局不安、恐攻威脅，108年考題） |
| **紅色** | **不宜前往**，已在當地的應儘速離境 |

::: trap
**陷阱：** 灰色只是「提醒注意」；「行程無法更改應儘量縮短天數」**不是**灰色的建議（113年考題）。
:::

## 10　證件與財物遺失

### 10-1　護照遺失（每年必考）

**步驟：**

1. 向**當地警察**報案，拿**報案證明**
2. 向**駐外館處**申請：
    - 要**直接回臺灣** → 申請「**入國證明書**」（只能用來回臺灣）
    - 還要**去下一個國家** → 申請**補發護照**（入國證明書不能用來入境別的國家）
3. 回國後補辦護照：因為已經有**國外的報案證明**，**免附**我國警察機關的報案證明（114、112年考題）

| 補充規定 | 內容 |
|---|---|
| 遺失補發護照的效期 | 一般 **5 年**；**未滿 14 歲 3 年**（不是 2 年） |
| 申報遺失後**找回來** | 護照**已作廢**，**不能再用**，要重新申請（110年考題） |
| 責任保險理賠 | 護照遺失要在 **24 小時內**向警方或駐外單位報案，重製的合理費用才能理賠（最高 **2,000 元**） |
| 申請的名稱 | 是「**入國證明書**」；「出國證明書」「入境證明書」都是錯的名稱 |

::: example
**例子（109年考題）：** 回程班機很早，導遊前一晚把全團護照收走，結果搞丟，全團滯留好幾天。
→ 這是**可歸責於旅行社**（導遊是履行輔助人），旅行社除了負擔滯留期間的費用，**還要賠償旅客**（依定型化契約的違約金規定）。「行程已執行完畢，只需付滯留費用、不用賠償」是錯的。
:::

### 10-2　簽證遺失

1. 查明原簽證的**批准號碼、核發日期、地點**（核准者的名字**不用**查）
2. 確認能不能在**當地或下一個國家**補辦，考慮時間和入境方式

**不用**向交通機關報案（113年考題）。

### 10-3　其他財物遺失

| 遺失物 | 處理 |
|---|---|
| **機票** | 現在多是電子機票，向**航空公司**查詢補發 |
| **信用卡** | 立刻打電話給**發卡銀行**掛失止付 |
| **旅行支票** | 向**發行機構**（例如發行銀行）報失，**不是**向駐外館處申報；就算有簽名也要**馬上報失**（106、108年考題） |
| **現金** | 通常**找不回來**；「有外幣兌換單就能先拿回部分還款」是錯的（111年考題） |
| 在飯店、餐廳因**自己疏失**遺失物品 | 協助報案、向店家查詢；旅行社**不用賠償** |

**一定要向當地警察報案的：** **遺失護照**、**旅客走失**（108年考題）。

## 11　人員事故

### 11-1　團員走失

**最好的預防：** 事先**跟團員約定**，走散了就**在原地等**，領隊會回頭找（115年考題）。也要讓團員帶著**飯店名片**和領隊電話。

### 11-2　團員生病、住院

1. 協助送醫、翻譯、聯絡**家屬**和**旅行社**
2. 團員需要住院時，**安排當地人員**（例如當地旅行社人員）**協助照顧**，等家屬趕到
3. 安排妥當後，領隊可以**帶其他團員繼續行程**（107年考題）

::: trap
**陷阱：** 領隊可以繼續帶團，但**一定要先安排好照顧的人**；「請旅客**獨自**接受診治，領隊隨團離開」是錯的（113年考題）。
:::

**醫藥費誰付？** 旅客**自己生病**（例如**高血壓中風**、心臟病），**不是旅行社的錯**，醫藥費由**旅客自己負擔**；責任保險只賠**意外**，不賠**疾病**（112、109年考題）。

### 11-3　車禍

1. 先確認安全，**有骨折（尤其開放性骨折）的傷患不要任意移動**，等救護人員
2. 叫救護車、**報警並做筆錄**
3. 通知**旅行社**和**國外代理旅行社**協助（113年考題）
4. 收集證據、保留單據，申請保險理賠

**醫藥費誰付？**

- 搭**旅行社安排的遊覽車**出車禍：屬**意外**，由**旅行業責任保險**給付（109年考題）。
- 團員**自由活動時自己搭計程車**出車禍：不是旅行社安排的，旅客**先自己付**，再用自己的保險申請（109年考題）。
- 搭**火車**等**大眾運輸**出事：由**運輸業者（鐵路公司）**直接負責（106年考題）。

### 11-4　遊覽車緊急逃生

自動門、安全門都打不開時，用**車窗擊破器**敲擊**玻璃的四個角落**（角落最容易碎，115年考題）。

### 11-5　團員死亡

1. 向**當地警察**報案，取得**死亡證明**
2. 通知**駐外館處**、**旅行社**、**家屬**（不能只報警，108年考題）
3. 遺體處理（火化、運回）要尊重**家屬意願**，**等家屬同意**，不能為了行程自己決定火化（106年考題）
4. 旅行社向觀光署通報

::: trap
**陷阱：** 死亡要向我國的**駐外館處**報告，**不是**向「所在地觀光局」報備（109年考題）。
:::

### 11-6　天災、戰亂、恐攻

- 領隊要**主動**聯繫**駐外館處**和**旅行社**，帶團員撤到安全地點；**不能只等**駐外館處來聯絡（113年考題）。
- 對媒體發言不是領隊的工作，由公司統一說明。
- 行程因此要變更，增加的費用由**旅行社**負擔、不能向旅客收（定型化契約，111年考題）。

### 11-7　飯店安全與治安

- 遇到**治安問題**，領隊第一優先是**保護團員安全**（113年考題）。
- 提醒團員：**錢包不外露**、**不單獨行動**、避免和陌生人接觸（113年考題）。
- 住飯店要加扣**安全鎖**；**不要把衣物披在燈上晾乾**（會引起火災，107年考題）。
- **火災**：用溼毛巾掩住口鼻、**低姿勢**沿牆走、**走樓梯、不搭電梯**。

### 11-8　危險活動

參加有危險性的自費行程（例如高空彈跳、潛水）前，要**事先告知危險性**，由旅客**自己決定**參不參加。

## 12　駐外館處能做與不能做

| ✔ 可以協助 | ✘ 不能做 |
|---|---|
| 提供遭遇**不可抗力事件**時的資訊和**必要協助** | **代墊或代付醫療費、入院保證金** |
| 協助聯繫**家屬**、親友 | 介入**消費糾紛、商業糾紛**（只能提供當地消保機構資訊） |
| 提供當地**醫院、律師**名單、**推薦律師** | **代付罰款、保釋金** |
| 協助**翻譯**（溝通協助） | 代為申請當地**居留權、駕照、入學或工作許可** |
| 補發護照、入國證明書 | 擔任訴訟代理人 |
| 急需返國又沒錢：**借**候機期間基本生活費 | 送錢給你（是**借款**，要還） |

**急難借款：**

- 當事人短時間內拿不到錢、又急需返國時，駐外館處可**借**候機返國期間的基本生活費，最高 **800 美元**（不是 300 或 500 美元，115、113年考題）。
- 借款要在**立約日次日起 60 天內**主動還給外交部。

**旅外國人急難救助全球免付費專線：** 由**外交部**設置，號碼 **800-0885-0885**（「由觀光局設置」是錯的，109年考題）。

## 13　旅遊保險

### 13-1　保險總表

| 保險 | 誰買 | 保什麼 | 不保什麼 |
|---|---|---|---|
| **旅行業責任保險** | **旅行社**（**依法強制**） | 旅客在旅途中發生**意外事故**的死亡、受傷、證件遺失等 | 旅客**自己生病** |
| **履約保證保險** | **旅行社**（**依法強制**） | 旅行社**倒閉**、財務困難**出不了團**，旅客**繳的團費損失** | 旅途中的意外 |
| 旅行平安保險 | 旅客自己 | 個人**意外**傷害、醫療（可加購疾病醫療） | — |
| 旅遊不便險 | 旅客自己 | **班機延誤**、**行李延誤或遺失**、旅程取消等 | — |
| **海外急難救助** | 附加在保險上，由**保險公司**（委託國際救援公司）提供 | **醫療**轉送、**法律**協助、**旅遊**協助、緊急事件協助等多項服務 | — |

### 13-2　責任保險最低投保金額（每位旅客）

| 項目 | 金額 |
|---|---|
| 意外**死亡** | 新臺幣 **250 萬元** |
| 意外**體傷醫療**費用 | 新臺幣 **10 萬元** |
| **家屬前往海外處理善後**的必要費用 | 新臺幣 **10 萬元**（國內旅遊 5 萬元） |
| 旅客**證件遺失**的損害賠償 | 新臺幣 **2,000 元** |

- 意外事故發生日起 **180 天內死亡**，可以申請死亡給付（114年考題）。
- 旅行社**沒投保**：出事時要賠「最低投保金額 × **3 倍**」（110年考題）。
- **自由活動**期間發生意外，責任保險**也可以理賠**，但要有必要單據正本（106年考題）。

::: info
**舊考題注意：** 108 年以前考題選項的死亡金額是 **200 萬元**（當時規定），現行是 **250 萬元**。
:::

### 13-3　額外住宿與旅行費用（附加條款）

因為**不可抗力**（例如火山爆發、班機取消）滯留，額外的住宿和旅行費用，每位旅客**每天最高 2,000 元**。

::: example
**例子（115年考題）：** 冰島火山爆發，航班取消，延後 **8 天**回國，每天額外花 **3,000 元**。理賠多少？

1. 每天上限 2,000 元（花 3,000 也只賠 2,000）
2. 2,000 × 8 ＝ **16,000 元**
:::

### 13-4　申請理賠要準備的文件

**領隊報告書**、**理賠申請書**、**醫療費用收據正本**、**意外事故證明**（例如警察報案證明）。
**不需要**「旅行業履約保證保險合約」（113年考題）。

### 13-5　平安險的「意外」是什麼

保險的「意外傷害事故」指的是**外來、突發、非疾病**引起的事故，例如**車禍**；中風、心臟病發作是疾病，不算意外（108年考題）。

### 13-6　健保核退

在國外**臨時發生不可預期的傷病**或**緊急分娩**就醫，可以在**出院日（或門診、急診日）起 6 個月內**，帶醫療收據、診斷證明等，向**健保署**申請**核退**部分醫療費用（112年考題：「不能申請核退」是錯的）。

### 13-7　旅行社倒閉

出發前發現旅行社倒閉，可以找：**交通部觀光署**、**中華民國旅行業品質保障協會**（品保協會）、**各地旅行公會**、**旅行商業同業公會全國聯合會**協助處理（114年考題）；團費損失由旅行社投保的**履約保證保險**理賠。

## 14　誰付錢？總整理

| 情況 | 誰付 | 依據 |
|---|---|---|
| 旅客**自己生病**住院（中風、心臟病） | **旅客** | 不可歸責旅行社 |
| 搭旅行社安排的車**出車禍** | **責任保險** | 意外事故 |
| **自由活動**自己搭計程車出車禍 | 旅客先付，再找自己的保險 | 不是旅行社安排的 |
| 火車翻覆 | **鐵路公司** | 大眾運輸業者直接負責 |
| 不可抗力**改行程**、增加費用 | **旅行社**（不能向旅客收） | 定型化契約 |
| 機場員工罷工**多住一晚** | **旅客**（可用自己的不便險） | 航空運送約款 |
| 導遊弄丟全團護照、滯留 | **旅行社**，另要賠償 | 可歸責旅行社 |
| 旅行社**倒閉** | **履約保證保險** | — |
| 在餐廳**自己弄丟**東西 | **旅客** | 不可歸責旅行社 |

## 15　容易搞混總整理

| 容易搞混 | 正確說法 |
|---|---|
| 路倒病人第一步 | 評估**意識** |
| 壓胸位置 | **胸骨下半段**，不是劍突 |
| 壓胸：吹氣 | **30：2** |
| 深度、速度 | **5～6 公分**、**100～120 下／分** |
| AED 電擊後 | **不關機**，繼續 CPR |
| 能咳 vs 不能咳 | 能用力咳：鼓勵咳；完全阻塞：哈姆立克 |
| 中風能不能喝水 | **不能** |
| 天旋地轉 | 較像眩暈，不是典型中風 |
| 癲癇 | **不可撬開牙關、不可塞東西** |
| 中暑順序 | 蔭涼→脫衣→散熱→喝水→送醫 |
| 燒燙傷沖水 | **15～30 分鐘**，不是 10 分鐘 |
| 三度燒燙傷 | 黑白色、**不痛**；超過 10% 有生命危險 |
| 止血帶 | **最後手段**，四肢大動脈加壓止不住才用 |
| 骨折固定 | 包含**上下兩個關節** |
| 毒蛇咬傷 | 包紮**不可太緊**、不可切開、患肢放低 |
| 蜂群 | 快速離開，**不要臥倒** |
| 日本腦炎 vs 登革熱 | 家蚊 vs **埃及斑蚊** |
| 國際檢疫傳染病 | 霍亂、鼠疫、黃熱病；**瘧疾不是** |
| 瘧疾預防 | **吃藥**，沒有預防疫苗；穿**淺色**衣 |
| NTG | **舌下含**，不是吞 |
| CRISIS 的 R | **Report**，不是 Repeat |
| 通報時限 | **24 小時**，不是 48 小時 |
| 入國證明書 | 只能**回臺灣**；要去別國須補發護照 |
| 補發護照效期 | 一般 5 年；未滿 14 歲 **3 年** |
| 駐外急難借款 | 最高 **800 美元**、60 天內還 |
| 責任險 vs 履約險 | 意外 vs 旅行社倒閉 |
| 責任險死亡 | 現行 **250 萬**（舊題 200 萬） |
| 健保核退 | 出院日起 **6 個月** |

## 17　讀完自我檢查

1. 看到有人倒地，第一步做什麼？（2）
2. 成人 CPR 的壓胸位置、深度、速度、壓吹比？（3-3）
3. 團員吃湯圓噎到，還能用力咳嗽，要做哈姆立克法嗎？（4）
4. 中暑的處理順序？（5-5）
5. 癲癇發作時，哪兩件事絕對不能做？（5-4）
6. 日本腦炎、登革熱各由什麼蚊子傳染？（8-1）
7. CRISIS 的 R 和第一個 I 分別是什麼？（9-1）
8. 團員在倫敦遺失護照，要直接回臺灣，申請什麼文件？回國補辦護照可免附什麼？（10-1）
9. 團員因高血壓中風住院，醫藥費誰付？責任保險賠不賠？（11-2）
10. 火山爆發滯留 5 天，每天額外花 2,500 元，額外住宿附加條款賠多少？（13-3）

::: answer
**參考答案：**

1. 評估意識（拍肩呼叫）
2. 胸骨下半段；5～6 公分；每分鐘 100～120 下；30：2
3. 不用，鼓勵他用力咳
4. 蔭涼→脫衣→散熱→喝水（意識清楚時）→送醫
5. 撬開牙關、塞東西進嘴巴
6. 日本腦炎：三斑家蚊等家蚊；登革熱：埃及斑蚊、白線斑蚊
7. R＝Report 報告；I＝Interpretation 說明（控制掌握客人行動和心態）
8. 入國證明書；我國警察機關報案證明
9. 旅客自己付；不賠（責任保險只賠意外）
10. 每天上限 2,000 元 × 5 天 ＝ 10,000 元
:::
