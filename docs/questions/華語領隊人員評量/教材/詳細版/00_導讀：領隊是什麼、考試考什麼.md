## 1　旅遊業的基本角色

### 1-1　一個旅行團裡有哪些人

| 角色 | 是誰 | 做什麼 |
|---|---|---|
| **旅客** | 報名、付錢參加旅行團的人 | 享受行程，也要配合規定 |
| **旅行社**（法規叫「**旅行業**」） | 設計行程、賣行程、和旅客**簽約**的公司 | 對旅客**負全部責任**，包括它找的國外合作廠商出的錯 |
| **OP**（Operator） | 旅行社內部的作業人員 | 訂機位、飯店、餐廳、遊覽車 |
| **領隊** | 旅行社派出，**從臺灣跟團出國**、全程照顧團員的人 | 處理出入境、交通、食宿、突發狀況 |
| **當地接待旅行社**（Local Agent） | 國外的合作旅行社 | 安排當地的車、導遊、餐廳、門票 |
| **導遊** | **在當地**負責解說帶路的人 | 景點解說、帶路 |

### 1-2　領隊 vs 導遊（法律定義）

依「**發展觀光條例**」第 2 條：

| | 定義 | 白話 |
|---|---|---|
| **領隊人員** | 執行引導**出國**觀光旅客團體旅遊業務，而收取報酬的服務人員 | 帶**臺灣人出國** |
| **導遊人員** | 執行接待或引導**來本國**觀光旅客旅遊業務，而收取報酬的服務人員 | 帶**外國人、陸客遊臺灣** |

::: tip
**口訣：** **領隊帶出去，導遊帶進來。**
（日常生活中，臺灣團到國外由「當地導遊」解說，那是當地國家的導遊，不是我國法規說的導遊。）
:::

## 2　旅行社的三種類型

依「**旅行業管理規則**」，旅行社分三種：

| 種類 | 能做什麼 | 實收資本額至少 |
|---|---|---|
| **綜合旅行業** | 國內、國外都能做；可以**批發**行程、委託其他旅行社**代為招攬** | 新臺幣 **3,000 萬元** |
| **甲種旅行業** | 國內、國外都能做；**自己招攬、自己出團** | 新臺幣 **600 萬元** |
| **乙種旅行業** | **只能做國內旅遊** | 新臺幣 **120 萬元** |

::: plain
**名詞：**

- **實收資本額**：公司股東真正拿出來的錢。
- **批發**：綜合旅行社設計好行程，交給其他旅行社幫忙賣，也叫「躉售」。
- **招攬**：找客人、賣行程。

帶團出國的旅行社，一定是**綜合**或**甲種**。詳細規定在第三章。
:::

## 3　華語領隊與外語領隊

| | 華語領隊 | 外語領隊 |
|---|---|---|
| 可以帶團去哪裡 | **只能**去**大陸、香港、澳門** | **全世界**（包括大陸港澳） |
| 評量科目 | 3 科：領隊執業**實務**、領隊執業**法規**、**觀光資源**概要 | 同樣 3 科，**再加一科外國語** |
| 及格標準 | 三科**平均 60 分** | 平均 60 分，且外國語至少 50 分 |

::: info
**你考的是華語領隊。** 所以這個考試特別重視：兩岸條例（第二章）、中國大陸的歷史地理（第十、十一章）。但實務科、法規科的其他內容和外語領隊一樣，資源科也會考東南亞、日韓等地區。
**之後想升級：** 拿到華語領隊、受完訓的人，再考外語領隊及格後，職前訓練節數**減半**。
:::

## 4　從考試到帶團

### 4-1　流程

| 步驟 | 內容 |
|---|---|
| ① **評量測驗** | 交通部觀光署辦理的筆試（113 年起由「考試」改為「**評量**」） |
| ② **職前訓練** | 及格後參加觀光署（或委託團體）辦的訓練，共 **56 節課**、每節 50 分鐘；缺課不能超過 **1/10** |
| ③ 領**結業證書** | 訓練合格 |
| ④ 請領**執業證** | 執業證就是領隊的「上班證件」 |
| ⑤ 受旅行社**僱用或指派**帶團 | 帶團時把執業證**掛在胸前明顯處** |

### 4-2　重要年限

| 規定 | 年限 |
|---|---|
| 評量及格後，要完成職前訓練 | 成績公布日起算滿 **3 年**的 6 月 30 日前；逾期**及格資格不保留** |
| **執業證**有效期間 | **3 年**，期滿前 1 年內申請換發 |
| 拿到結業證書或執業證後，**連續 3 年沒帶團** | 要**重新受訓**（**28 節課**）才能再帶團 |
| 執業證被**廢止** | **5 年內**不能再當領隊 |

::: tip
三個「3 年」：及格後 3 年內受訓、執業證有效 3 年、連續 3 年沒帶團要重訓。第三章會詳細講領隊的權利義務和罰則。
:::

## 5　考試長什麼樣子

### 5-1　116 年的時程

116 年導遊及領隊人員評量的簡章已在 115 年 11 月 16 日公告：

| 項目 | 日期 |
|---|---|
| 報名 | **115 年 12 月 1 日～12 月 10 日**（網路報名） |
| 筆試 | **116 年 3 月 6 日～7 日** |
| 考區 | 北、中、南、東 4 區 |

::: trap
**別忘了報名！** 報名只有 10 天，錯過就要再等一年。
:::

### 5-2　考試形式

| 項目 | 內容 |
|---|---|
| 科目 | 領隊執業**實務**、領隊執業**法規**、**觀光資源**概要，共 **3 科** |
| 題型 | 全部是**單選題**（四選一） |
| 每科 | **50 題**，每題 **2 分**，滿分 100 分 |
| 考試時間 | 每科 **60 分鐘** |
| **及格標準** | 三科**平均滿 60 分**（三科總分 180 分以上） |
| 注意 | **缺考一科算 0 分**；**有任何一科 0 分就不及格** |

::: example
**例子：** 法規 80、實務 75、資源 30 → 平均 61.7 → **及格**。
所以資源科範圍很大、比較難，可以靠法規和實務拉分。
:::

### 5-3　出題方式

- **不是固定題庫**：每年都出新的題目。
- 但**考點高度重複**：同一個規定、同一個數字，換個說法年年考。這也是為什麼用考古題練習最有效。
- **答案以現行法規為準**：法規修正後，舊考古題的答案可能已經過時。教材和題庫都已經標出來，並用現行條文出新題。

### 5-4　各科出題比重（113～115 年平均）

| 科目 | 主題（每年約幾題） | 對應章節 |
|---|---|---|
| **領隊執業法規** | 旅遊契約 **11**、兩岸條例 **9**、旅行業管理規則 7、護照入出境 6、外匯 5、領隊管理規則 5、海關檢疫 3 | 01、02、03、04 |
| **領隊執業實務** | 領隊技巧與觀光心理 **12**、航空票務 **11**、緊急事件 9、急救保健 9、國際禮儀 6 | 06、07、08 |
| **觀光資源概要** | 中國大陸與港澳 **15**、東南亞南亞 **12**、世界遺產與資源維護 6、臺灣 5、日韓 5 | 10、11、12、13 |

### 5-5　目標分數

| 科目 | 目標 | 理由 |
|---|---|---|
| 法規 | **80 分** | 規定和數字固定，背熟就能拿分 |
| 實務 | **80 分** | 很多是常識和情境判斷，加上少數要背的規定 |
| 資源 | **55 分** | 範圍最廣，抓年年考的重點就好 |
| 平均 | **71.7 分** | 留了 11 分以上的安全空間 |

## 6　一個團的一生：把十三章串起來

用一個「**5 天上海團**」，從報名到回國，每一段會用到哪一章：

| 階段 | 會發生什麼事 | 要懂的知識 | 章節 |
|---|---|---|---|
| 旅行社開業 | 申請執照、繳保證金、買保險 | 旅行業管理規則、發展觀光條例 | 03 |
| 看廣告、報名簽約 | 審閱契約、付團費 | 定型化契約、團費包含什麼 | 01 |
| 出發前取消 | 旅客不去了、人數不夠 | 取消賠償比例 | 01 |
| 辦證件 | 護照、臺胞證、役男出境 | 護照條例、入出國法規 | 04 |
| 去大陸的特別規定 | 誰需要申請、不能做什麼、旅遊警示 | 兩岸條例 | 02 |
| 派領隊 | 執業證、領隊不能做的事 | 領隊人員管理規則 | 03 |
| 機場與搭機 | 報到、行李、轉機、時差 | 航空票務 | 06 |
| 抵達、住飯店、吃飯 | Check-in、訂餐、解說 | 領隊技巧、國際禮儀 | 08 |
| 參觀景點 | 外灘、故宮、世界遺產 | 中國歷史地理 | 10、11 |
| 旅途中出事 | 生病、車禍、護照遺失、行程變更 | 急救、緊急事件、契約 | 07、01 |
| 購物、自費行程 | 能不能臨時加購物 | 定型化契約、領隊技巧 | 01、08 |
| 回國入境 | 免稅額、肉品不能帶、外幣申報 | 海關、檢疫、外匯 | 04 |

如果帶的是東南亞、日韓團（外語領隊），資源科就是第十二、十三章的內容。

## 7　法律文件怎麼讀

法規科要讀很多法條，先認識這些名詞：

### 7-1　法律的種類

| 名稱 | 誰訂的 | 例子 |
|---|---|---|
| **法律**（名稱叫法、律、**條例**、通則） | **立法院**通過、總統公布 | 民法、**發展觀光條例**、**兩岸條例**、護照條例 |
| **命令**（名稱叫**規則**、辦法、細則、標準） | **行政機關**依法律授權訂定 | **旅行業管理規則**、**領隊人員管理規則** |
| **定型化契約範本** | 主管機關公告 | 國外旅遊定型化契約書範本 |

::: plain
**關係：** 法律訂大原則，命令訂細節。例如「發展觀光條例」說「旅行社要繳保證金」，「旅行業管理規則」才寫「綜合旅行社繳多少」。
:::

### 7-2　條文的層次

一條法律可以分成：**條 → 項 → 款 → 目**。

::: example
**例子：** 「發展觀光條例**第 2 條**」裡有很多「款」，第 12 款是導遊的定義、第 13 款是領隊的定義。
「**第 514 條之 1**」是後來加進去的條文，排在第 514 條後面。
:::

### 7-3　常見法律用語

| 用語 | 意思 |
|---|---|
| **應** | 一定要做 |
| **得** | 可以做（不是一定） |
| **不得** | 不可以做 |
| **以上、以下、以內** | **包含**本數（例如 5 人以上，包含 5 人） |
| **未滿、超過、逾** | **不包含**本數（例如未滿 2 歲，不包含 2 歲） |
| **主管機關** | 管這件事的政府機關。觀光的主管機關：中央是**交通部**，實際由**交通部觀光署**執行 |
| **罰鍰** | 行政機關罰的錢（例如觀光署罰旅行社） |
| **罰金** | 法院判刑罰的錢（刑罰） |

::: trap
**很常考的陷阱：** 「以上」包含、「超過」不包含。例如「183 天以上」包含 183 天，「超過 183 天」要 184 天。
:::

## 8　怎麼用這套教材和題庫

### 8-1　讀書流程

1. 讀一章**教材**（先看開頭的目錄與大綱，知道這章在講什麼）
2. 做 App 裡**同編號的單元**（50 題）
3. 錯的題目用**攻克模式**清掉，看解析回頭查教材
4. 每章最後的「**容易搞混總整理**」和「**數字速記卡**」，考前再看一次

### 8-2　每科的讀法

| 科目 | 讀法 |
|---|---|
| **法規** | 重點是**數字**（天數、百分比、倍數、金額）和**機關**（誰負責什麼）。每章都有對照表 |
| **實務** | 情境題用第八章的「解題原則」判斷；急救步驟、代碼要背 |
| **資源** | 範圍最廣，抓「年年考」的重點；用地圖和故事記，不要死背 |

- 每個單元 **50 題**，絕大多數是 **101～114 年的官方考古題**，每題附解析和出處（「XXX年XX第N題」）。
