## 1　基本名詞：先把字看懂

| 名詞 | 白話解釋 |
|---|---|
| **護照** | 證明「你是哪一國人」的國際身分證，出國一定要帶 |
| **效期** | 證件可以用到哪一天 |
| **換發** | 舊護照還沒到期，但因為某些原因要換一本新的 |
| **補發** | 護照**遺失**後重新申請一本 |
| **加簽** | 在護照上另外加註資料（例如僑居身分、外文別名） |
| **簽證** | 要去的國家發給你的「入境許可」，蓋在護照上或用電子方式 |
| **免簽證** | 對方國家同意你**不用申請簽證**就能入境停留一段時間 |
| **入國／入境** | 進入一個國家 |
| **出國／出境** | 離開一個國家 |
| **有戶籍國民** | 在臺灣有戶口（有身分證）的中華民國國民 |
| **役男** | 還沒當兵（服兵役）的男生，出國要先申請核准 |
| **海關** | 機場檢查行李、收進口稅的單位 |
| **紅線檯／綠線檯** | 入境時，有東西要申報走**紅線**；沒有走**綠線** |
| **沒入** | 東西被政府**沒收** |
| **檢疫** | 檢查動植物、食物有沒有帶病菌或害蟲，防止傳染病進來 |
| **疫區** | 正在流行某種動物疾病的國家或地區 |
| **外匯** | 外國的錢和以外幣計價的票據、證券 |
| **結匯** | 用新臺幣換外幣（結購），或把外幣換成新臺幣（結售） |
| **匯率** | 1 元外幣可以換多少新臺幣 |
| **牌告匯率** | 銀行公布出來的匯率表 |
| **旅行支票** | 銀行發行、出國用的票據，遺失可以掛失補發（現在少用了） |

## 3　護照

### 3-1　法律依據

- 護照的申請、核發、管理，依「**護照條例**」辦理（108年考題）；主管機關是**外交部**。
- 護照分**外交**護照、**公務**護照、**普通**護照；公務護照效期以 **5 年**為限。

### 3-2　效期

| 情況 | 普通護照效期 |
|---|---|
| 一般（**14 歲以上**） | **10 年** |
| **未滿 14 歲** | **5 年** |
| **遺失補發**（14 歲以上） | **5 年** |
| 未滿 14 歲遺失補發 | 3 年 |

- 效期自**核發之日**起算（不是申請日，114年考題）。
- 護照效期屆滿，**不能延期**，要重新申請（114年考題）。

::: example
**例子（115年考題）：** 張先生 25 歲第一次申請護照 → **10 年**；黃先生 25 歲因遺失申請補發 → **5 年**。
:::

### 3-3　什麼時候要「換發」

| 要換發 ✔ | 不用換發 ✘ |
|---|---|
| **中文姓名變更** | 戶籍**地址**變更 |
| **資料頁記載事項**變更 | 從軍中**退伍** |
| **相貌變更**，和照片不符 | 取得**僑居身分**（用加簽） |
| 護照**污損**不堪使用 | 效期**不足 1 年** |
| 護照**製作有瑕疵** | 不是**最新式樣** |
| 取得或變更身分證統一編號 | 持照人自己**覺得需要** |

::: trap
**陷阱：** 「效期不足」「不是新式樣」「自己想換」都**不是**應申請換發的事由（108、109、114年考題）。
:::

### 3-4　護照條例施行細則（114年考題）

- 空白內頁不足可以**加頁**，但以 **1 次**為限
- 中文姓名**不得加列別名**
- 要由**本人親自簽名**，不會簽名可以按**指印**
- 未滿 7 歲或受監護宣告的人，由**法定代理人**申請
- 以不實資料申請到的護照要**註銷**

### 3-5　速件處理費

送件後要求提前製發，按提前的工作日加收速件費；考題：提前 **3 個工作日** → **900 元**（110年考題）。

## 4　國外遺失護照

### 4-1　一般國家

1. 先向**當地警察機關**報案，拿**報案證明**（不是向海關、移民單位，111年考題）
2. 到我國**駐外館處**（大使館、辦事處）：
    - 申請**補發護照**；或
    - 急著回國，申請「**入國證明書**」返臺（115年考題）
3. **不是**向移民署申請「入出境許可證」（112年考題）

### 4-2　在大陸遺失

大陸沒有我國駐外館處。要搭直航班機返臺，建議在搭機前約 **2 天**，帶下列資料，洽請**出發地機場的航空公司**協助：

1. 足以證明身分的文件（例：身分證、駕照）
2. 護照遺失**報案證明**
3. **臺胞證**（臺灣居民來往大陸通行證）

（「來回機票存根」「入國證明書」不需要，113年考題。）

::: plain
**領隊實務：** 出團前把團員護照、臺胞證**影本**和**大頭照**準備好，遇到遺失可以加快補辦。
:::

## 5　役男出境

### 5-1　誰是役男

| 名稱 | 年齡 | 出國要不要申請 |
|---|---|---|
| **接近役齡**男子 | 18 歲當年 1 月 1 日起，到 18 歲當年 12 月 31 日 | **不用**（112年考題） |
| **役齡男子（役男）** | **19 歲當年 1 月 1 日**起，到 36 歲當年 12 月 31 日 | **要**事先申請核准 |

::: example
**例子（110年考題）：** 民國 90 年 10 月 10 日出生的男子，109 年滿 19 歲 → 從 **109 年 1 月 1 日**起出境要申請。（看「年」，不是看生日。）
:::

### 5-2　怎麼申請

| 情形 | 向哪裡申請 |
|---|---|
| 短期出國旅遊 | **內政部役政署**網站**線上申請**；考題：12/1 出國，11/15 申請（114年考題） |
| 出境**就學**（例：國外讀研究所） | **內政部移民署**（112年考題） |
| 國內大學生出國修**雙聯學位**、交換學生 | 由**學校造冊**，向**戶籍地**直轄市、縣（市）政府申請（110年考題） |
| **僑民**役男 | **內政部移民署**（111年考題） |

- 役男也可以申請**護照**，效期一樣 **10 年**，**不用**加蓋兵役管制章戳；服役期間也能申請護照（111年考題）。
- 未經核准擅自出境：會被**列管**、限制出境，並依法處罰（115年考題）。

### 5-3　出境就學

- 在國外就讀當地國立案的**高中以上**學校，可以申請出境就學（111年考題）。
- 核准出境就學後，回國每次停留**不得逾 3 個月**；24 歲以下返國後可以憑在學證明申請再出境。

### 5-4　延期返國

出境期限到了，因**重病、意外災難**不能如期回國：檢附當地醫院診斷書，向戶籍地區公所申請延期，**每次不得逾 2 個月**（113年考題）。

### 5-5　研發替代役

研發替代役役男出國旅遊：**每年 1 次**，每次**不得逾 8 天**（109年考題）。

## 6　簽證與免簽

### 6-1　電子簽證

- 透過網路申請、付款、領件，**不用親自**跑駐外館處，**任何時間地點**都能申請。
- 但**仍然要審核**，不是「免審核」（111年考題）。

### 6-2　常考的國家

| 地區 | 規定 |
|---|---|
| **申根區**（歐洲多國） | 免簽；**任何 180 天內**停留合計不超過 **90 天**；不能工作 |
| **英國** | 我國國民免簽 **180 天**；英國人來臺免簽 **90 天**（110年考題） |
| **美國** | 免簽（VWP）：要**有戶籍國民**、**晶片護照**、事先取得 **ESTA** 授權；可以觀光、探親、**短期商務**；**不能**求學、移民（護照效期不必超過 1 年，109年考題） |
| **韓國** | 觀光免簽 **90 天**（112年考題） |
| **大陸** | 臺灣民眾要持「**臺灣居民來往大陸通行證**」（臺胞證）入境（114年考題） |

::: trap
**申根新變化：** **克羅埃西亞**（2023）、**羅馬尼亞**和**保加利亞**（2025）都已經加入申根區。111 年考題說這三國是「例外」，已經不適用。
:::

::: info
**留學、工作要申請簽證：** 免簽只能觀光、探親、短期商務；去英國念大學、當交換學生，要事先申請**就學簽證**（110年考題）。
:::

### 6-3　旅遊警示

| 地區 | 發布機關 |
|---|---|
| 國外 | **外交部**（114年考題） |
| **大陸**（例：雲南） | **大陸委員會**（114年考題） |

## 7　入出國查驗

- **有戶籍國民入國**：只要有**有效護照**，經移民署查驗、蓋章（112年考題）；細節規定在「**入出國查驗及資料蒐集利用辦法**」（111年考題）。
- 有戶籍國民從大陸**偷渡**回臺：要向**移民署**申請補辦入國手續（109年考題）。
- **自動查驗通關**（e-Gate）：外國人有永久居留、陸配長期居留、外交官員證都可以申請；**只有航空公司貴賓卡不行**（112年考題）。
- **快速通關櫃檯**：**亞太經濟合作（APEC）商務旅行卡**、**中華民國學術與商務旅行卡**持卡人、經核准的**外籍**商務人士（112年考題）。
- 學術與商務旅行卡：效期內多次入出，每次停留 **90 天**。
- 外國人持居留簽證入國後 **15 天**內，向移民署申請**外僑居留證**；有居留證的移工臨時出國，要申請「**重入國許可**」才能再回來。
- 外國人在臺**逾期停留**：至少 **1 年**禁止入國。
- 外籍旅客**退稅**：自**購買之日**起一定期間內攜帶貨物出境（111年考題）。

## 8　搭機安檢（和第六章相關）

| 物品 | 規定 |
|---|---|
| 可伸縮**三腳架**（管徑 1 公分以上） | 收合後超過 **60 公分**要**託運**（112年考題） |
| 尖銳物（釘子、毛線針） | 長度 **5 公分**以下可以隨身 |
| 醫療、梳妝用噴劑 | 每人合計 **2 公升**以下 |
| **含酒精飲料**（託運） | 合計 **5 公升**以下；酒精濃度 **24% 以下**不受限制（110年考題） |
| **水銀溫度計、氣壓計** | **不得攜帶**（111年考題） |

## 9　海關：免稅與申報（回國時）

### 9-1　免稅額和菸酒

| 項目 | 規定 |
|---|---|
| 行李物品**免稅額** | 完稅價格 **35,000 元**（115年考題） |
| 可帶菸酒的年齡 | **酒 18 歲**、**菸 20 歲**（112 年 1 月 1 日起，115年考題） |
| **免稅**菸 | 捲菸 **200 支**，或雪茄 **25 支**，或菸絲 **1 磅** |
| **免稅**酒 | **1.5 公升**（115年考題） |
| 攜帶**上限** | 捲菸 **1,000 支**，或雪茄 **125 支**，或菸絲 **5 磅**；酒 **5 公升**（114年考題） |
| 自用**非處方藥** | 每種 **12 瓶**，合計不超過 **36 瓶**（113年考題） |

::: plain
**免稅量 vs 上限：**

- 在**免稅量以內** → 走綠線，不用繳稅
- 超過免稅量、但在**上限以內** → 走**紅線**申報，扣掉免稅量後**課稅**
- 超過**上限** → 不能帶

例：菸絲 5 磅已超過免稅量 1 磅，要申報課稅（113年考題）。
:::

### 9-2　錢與貴重物品的申報門檻

| 物品 | 超過多少要申報 | 沒申報會怎樣 |
|---|---|---|
| **外幣**現鈔 | 等值 **1 萬美元** | 超過的部分**沒入** |
| **新臺幣** | **10 萬元** | 超過限額或申報的部分**沒入**（114年考題） |
| **人民幣** | **2 萬元** | 超過的部分**封存**於海關，出境時帶走；沒申報或申報不實，超過 2 萬元或申報的部分**沒入** |
| 有價證券 | 等值 1 萬美元 | 依洗錢防制規定處罰 |
| **黃金** | 總值逾 **2 萬美元** | 要向**經濟部國際貿易署**申請輸入許可並報關（1 萬美元的黃金可以走綠線，115年考題） |
| 有洗錢之虞的物品（鑽石、寶石、白金） | 總值逾新臺幣 **50 萬元** | 要走紅線申報；**黃金不包括在內**，黃金另有規定（113年考題） |

::: example
**例子（113年考題）：** 帶人民幣 8 萬元，只申報 4 萬元：

- 申報的 4 萬元中，**2 萬**可以帶進來，另外 **2 萬**封存在海關、出境時帶走
- 沒申報的 **4 萬**被**沒入**
:::

::: trap
**陷阱：** 人民幣沒申報，是超過「**2 萬元**」的部分沒入，**不是**超過 5 萬元（113年考題）。
:::

## 10　動植物檢疫

### 10-1　肉製品

- **肉類**和肉製品**一律不能**帶進來，包括**泡麵裡的肉類調理包**、**寵物罐頭**（牛肉罐頭）。
- **蝦味、蔬菜**乾燥調理包的泡麵可以帶（115年考題）。
- 從**非洲豬瘟**疫區帶豬肉產品、沒主動申請檢疫：**第一次就罰 20 萬元**（112年考題）。
- 從**口蹄疫**等疫區擅自輸入禁止的檢疫物：**7 年以下有期徒刑**（111年考題）。
- 規避、拒絕植物檢疫人員檢查：罰 **1 萬～5 萬元**。

### 10-2　動物

- 犬、貓、兔等：申報檢疫合格可以入境；**寵物鼠**（囓齒類）即使檢疫合格也**不能**隨身攜入（111年考題）。
- 攜帶**出境**：犬、貓各限 **3 隻**以下；動物產品 **5 公斤**以下。

### 10-3　植物

- **生鮮果實**：即使符合檢疫程序，也**不能隨身攜帶入境**（108年考題）。
- **活植物**從禁止輸入的疫區帶進來、檢疫不合格 → **限期補正**證明文件、**退運**，或**放棄後銷燬**；**不能**「重新申請」（112年考題）。
- **種子、種球**的限量不一樣，**不是都限 3 公斤**（114年考題）。
- 出境植物產品 **10 公斤**以下，申請檢疫免收檢疫費。

### 10-4　領隊遇到疑似傳染病

旅客在途中或入境時出現疑似傳染病症狀 → 要**通報檢疫單位**，並**提供團員名單**（110年考題）。

## 11　外匯法規（管理外匯條例）

| 項目 | 規定 |
|---|---|
| **外匯的定義** | 外國**貨幣**、**票據**、**有價證券**（113、115年考題） |
| **不算**外匯 | **黃金、白銀、飾金、飾銀**、**國際信用卡**、**加密貨幣** |
| 行政**主管機關** | **財政部** |
| **掌理外匯業務** | **中央銀行**（例：審核民間匯出匯入款） |
| **申報** | 新臺幣 **50 萬元**以上等值外匯收支，要申報；辦法由**中央銀行**定（113、115年考題） |
| 非法買賣外匯**為常業** | **3 年以下**有期徒刑（115年考題） |
| 疑似洗錢 | 外幣收兌處向**法務部調查局**舉報（113年考題） |

**個人結匯（外匯收支或交易申報辦法）：**

- 年滿 20 歲、有身分證的個人，每年累積結匯 **500 萬美元**以內，可以直接向銀行辦理
- **每筆**達 **50 萬美元**，要附交易證明文件
- 委託他人辦結匯申報，由**委託人**負責
- 申報書塗改時，要在塗改處**簽名或蓋章**；申報後**不能要求更改**內容（只能經銀行向央行申請更正）

::: tip
**記法：** 外匯＝「**錢、票、證券**」，**黃金不算**。管外匯的是**財政部**（主管）和**中央銀行**（業務）。
:::

## 12　匯率怎麼看（每年一題）

### 12-1　站在「銀行」的角度看

銀行牌告的「買入、賣出」都是**銀行**在買、在賣：

| 牌告 | 意思 | 旅客什麼時候用 | 價格 |
|---|---|---|---|
| **銀行買入**（買匯） | 銀行跟你**買**外幣 | 旅客**賣**外幣（外幣換回新臺幣） | 比較**低** |
| **銀行賣出**（賣匯） | 銀行**賣**外幣給你 | 旅客**買**外幣（出國前換錢） | 比較**高** |

::: example
**例子（115年考題）：** 美金牌告：買入 29.81／賣出 30.48

- 旅客買 1 美元，要付 **30.48 元**（銀行賣出價）
- 銀行願意用 29.81 元向旅客買 1 美元
- 價差 ＝ 30.48 − 29.81 ＝ **0.67**
- 不同銀行的報價會不一樣
:::

### 12-2　現金 vs 即期

| 交易方式 | 看哪一個匯率 |
|---|---|
| 換**現鈔** | **現金**匯率 |
| **旅行支票**、匯款 | **即期**匯率 |

::: example
**例子：**

- 用新臺幣現鈔買美元現鈔 → **現金賣匯**（110年考題）
- 把美元現鈔賣給銀行 → **現金買匯**；把美元旅行支票賣給銀行 → **即期買匯**（114年考題）
:::

- 買賣**價差**會隨外匯市場波動改變，**不是固定的**（113年考題）。

### 12-3　信用卡

國外刷卡的匯率，以**商店向銀行請款日**計算（不是刷卡當下，114年考題）。

### 12-4　旅行支票

1. 買到時**立即在上款簽名**（不是背面背書，113年考題）
2. 使用時在**下款**當面**副署**（再簽一次）
3. 簽名要和購買合約書、護照一致
4. 支票和購買合約書**分開保管**；沒用完要存回銀行時，帶賣匯水單或購買合約書

### 12-5　偽鈔

銀行發現旅客拿來兌換的外幣是偽鈔：當面說明；如果持兌人**不同意**銀行留下偽鈔，**不論金額多少**，銀行都要記下持兌人的姓名、國籍、職業、住址並**報警**（111年考題）。
