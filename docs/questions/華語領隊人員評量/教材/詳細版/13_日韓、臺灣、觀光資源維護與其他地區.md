## 1　基本名詞：先把字看懂

| 名詞 | 白話解釋 |
|---|---|
| **天皇** | 日本的君主，大部分時代只是象徵 |
| **幕府** | 日本武士政權；最高領袖叫「**將軍**」，實際掌權 |
| **大名** | 日本各地的領主（像諸侯） |
| **鎖國** | 江戶幕府限制和外國往來 |
| **明治維新** | 1868 年起日本推翻幕府、學習西方、快速現代化 |
| **總督** | 殖民地的最高長官（日治臺灣的臺灣總督） |
| **原住民族** | 漢人來臺以前就住在臺灣的族群；目前官方認定 **16 族** |
| **平埔族** | 住在平地、較早漢化的原住民族（西拉雅、拍瀑拉等） |
| **南島語族** | 說南島語系語言的民族，分布在太平洋、印度洋的島嶼 |
| **國家公園** | 政府劃設、保護自然和文化資源的大型區域 |
| **承載量** | 一個地方在不被破壞、遊客也不覺得太擠的前提下，最多能容納多少遊客 |
| **衝擊** | 觀光對環境、社會、經濟造成的影響（好或壞） |
| **永續觀光** | 讓觀光資源下一代也能享受的經營方式 |

## 2　日本歷史

### 2-1　時代總表

| 時代 | 重點 | 景點 |
|---|---|---|
| **奈良**時代 | 遣唐使；唐朝高僧**鑑真**（8 世紀）東渡傳授佛教戒律（115年考題） | 奈良東大寺、**唐招提寺** |

## 5　臺灣歷史

### 5-1　時間軸

| 時期 | 重點 |
|---|---|
| 史前 | **十三行遺址**（新北八里）：**金屬器時代**，會煉鐵（109年考題） |
| 明末 | **陳第**《東番記》：記載臺南**西拉雅族**（109年考題） |
| **荷蘭**（1624–1662） | 南部大員（安平）**熱蘭遮城**；傳教士用**西拉雅語**羅馬拼音寫「**新港文書**」（113年考題） |
| **西班牙**（1626–1642） | 北部**雞籠**（基隆和平島）**聖薩爾瓦多城**、淡水聖多明哥城（112年考題） |
| **鄭氏**（1662–1683） | **沈光文**開館授徒，推動漢文化（112年考題） |
| **清治**（1683–1895） | 移民諺語「唐山過臺灣，心肝結歸丸」「紅柿上樹頭，羅漢腳目屎流」；**牡丹社事件**（1874，**排灣族**殺害琉球漂流民，日本出兵；清代最早、最著名的外國武力入侵，111、115年考題）；開港後**馬偕**等長老教會傳教士帶來**西醫**（114年考題） |
| **日治**（1895–1945） | 見 5-2 |
| **戰後** | 見 5-3 |

### 5-2　日治時期

| 項目 | 重點 |
|---|---|
| **六三法**（1896） | 總督可以發布有法律效力的命令，加上行政、司法、**軍事**權（110年考題）；1920 年**新民會**以撤廢六三法為目標 |
| 醫療衛生 | 日治時期才建立現代**醫療衛生**系統（108年考題）；**杜聰明**：臺大醫學院院長、創高雄醫學院、研究鴉片戒菸（110年考題） |
| **糖業** | 依**新渡戶稻造**〈糖業改良意見書〉；諺語「**第一憨，種甘蔗給會社磅**」是**日治**時期（113年考題） |
| 1900 年調查 | 漢人祖籍：**泉州**、**漳州**最多 |
| 文官總督 | **田健治郎**（1919）：「**內地延長主義**」；1920 年改**州廳制** |
| 1935 年選舉 | 臺灣第一次選舉，是**限制選舉**：年滿 25 歲、繳稅年額 5 圓以上的男性才能投票，**不是**所有 25 歲以上住民（110年考題） |
| 1930 年 | 林獻堂、蔡培火組「**臺灣地方自治聯盟**」 |
| **小林躋造**（1936） | 三大方針：**皇民化**、**工業化**、**南進基地化** |
| 皇民化團體 | 皇民奉公會等；「**揚文會**」是 1900 年的，**不是**皇民化組織 |
| 高砂義勇隊 | 原住民被動員到南洋；1974 年在印尼發現的**史尼育唔**（李光輝） |
| 電影院 | **1930 年代**最興盛 |
| 作曲家 | **鄧雨賢**〈雨夜花〉〈望春風〉、**王雲峯**〈桃花泣血記〉、**蘇桐**〈青春嶺〉；**李臨秋**是作詞家（〈望春風〉），「李臨秋－心酸酸」是錯誤配對（113年考題） |
| 民謠 | 〈**丟丟銅仔**〉描寫**宜蘭線**火車過隧道（112年考題） |

### 5-3　戰後

| 項目 | 重點 |
|---|---|
| 1945 | **陳儀**任行政長官兼警備總司令，被謔稱「**新總督**」（108年考題） |
| **幣制改革**（1949） | 舊臺幣 4 萬元換新臺幣 1 元，通膨緩和，但民眾財產大縮水（108年考題） |
| 1950 年代 | **肥料換穀**；**美援**（麵粉袋做的內褲，112、115年考題） |
| 1951 | 第一任臺北市民選市長**吳三連** |
| **1958** | **八二三砲戰**＝第二次臺海危機（113年考題） |
| 1970 年代 | 經濟奇蹟：**高儲蓄率**（刻苦勤儉） |
| 1980 年代 | **鹿港反杜邦**：最早的環保街頭抗爭（112年考題）；宜蘭縣長**陳定南**拒絕六輕 |
| 政治順序 | **開放兩岸探親**（1987）→ **廢除動員戡亂臨時條款**（1991）→ **首次總統直選**（1996）→ **兩岸直航**（2008）（113年考題） |

### 南島語族

- 範圍：**西到馬達加斯加、東到復活節島、北到臺灣、南到紐西蘭**；臺灣被認為是**南島文化的源頭**（114年考題）。
- **馬爾地夫不屬於**南島文化；智利的**復活節島**原住民語言和臺灣原住民最相近（111年考題）。

## 8　觀光資源維護

### 8-1　承載量

| 種類 | 意思 |
|---|---|
| **生態承載量** | 以自然環境**不退化**為前提（114年考題） |
| 實質（空間）承載量 | 空間能擠進多少人 |
| **社會心理承載量** | 遊客覺得**擁擠**、滿意度下降的程度（109年考題）；看遊客數量、車輛、擁擠程度，和遊客的**社經背景較無關**（110年考題） |
| 設施承載量 | 停車場、廁所等能服務多少人 |

### 8-2　遊憩衝擊與管理

| 項目 | 重點 |
|---|---|
| 經濟衝擊 | **季節性失業**、物價上漲 |
| 步道衝擊 | 踩踏、加寬、土壤流失（野生動物排遺**不是**遊憩造成的衝擊） |
| 管理策略 | 分析衝擊因子、監測、**環境教育**；一味**嚴格管制**不妥；避免衝突可依活動、時間、空間分區，**不要依年齡層** |
| **ROS**（遊憩機會序列） | 以**遊客體驗**為本，把遊憩資源**分級**（從原始到都市） |
| 危險評估 | 頻率低、嚴重度低的危險 → 可**接受並任其存在** |
| 颱風天闖封鎖線獲救 | 依《災害防救法》，搜救費用由**獲救者**或可歸責的業者負擔 |

### 8-3　LNT 無痕山林

**LNT＝Leave No Trace**（110年考題）：

- 垃圾、**吃剩的食物**全部**帶下山**，不要留在野外（111年考題）
- 走在既有步道上，**排成一列縱隊**，不要併行踩寬步道
- 不帶走、不破壞自然物

### 8-4　永續觀光與世界遺產

- **GSTC**（全球永續觀光委員會）目的地評選：永續管理、社會經濟（住民）、**文化與傳統**、**環境與氣候**；**不含**「交通與安全」（111年考題）。
- **世界遺產**：1972 年《世界遺產公約》；文化、自然、複合三類；另有**非物質文化遺產**（例：椰棗樹知識與傳統，多個阿拉伯國家共同申報）。
- **跨國**世界遺產：西班牙**聖地牙哥朝聖之路**、絲綢之路（113年考題）。
- 被破壞的遺產：阿富汗**巴米揚大佛**，2001 年因宗教理由被**塔利班**炸毀（111年考題）。
- 青海**可可西里**保護區：保護**藏羚羊**（115年考題）。

### 8-5　氣候變遷

- 長期影響：**冰川融化**短期吸引冰川觀光，長期**破壞生態**、減少冰雪活動吸引力（114年考題）。
- 青藏高原森林線上升、湖泊擴大 → **全球暖化**（112年考題）。
- 其他：海平面上升、珊瑚白化。
