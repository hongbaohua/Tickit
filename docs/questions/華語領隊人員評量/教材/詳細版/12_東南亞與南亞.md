## 1　基本名詞：先把字看懂

| 名詞 | 白話解釋 |
|---|---|
| **東南亞** | 中國南方、印度東方的國家：中南半島（越、寮、柬、泰、緬）＋馬來半島與島嶼（馬、新、印尼、菲、汶萊、東帝汶） |
| **中南半島** | 也叫「印度支那半島」，夾在中國和印度之間 |
| **南亞** | 印度、巴基斯坦、孟加拉、尼泊爾、不丹、斯里蘭卡、馬爾地夫 |
| **殖民** | 外國占領統治一個地方，拿它的資源 |
| **保護國** | 名義上還有國王，但外交、軍事由外國控制 |
| **上座部佛教**（南傳） | 從斯里蘭卡往東南傳；重視個人修行；泰、緬、柬、寮、斯里蘭卡 |
| **大乘佛教**（北傳） | 經中亞傳入中國，再到韓日越；重視普度眾生 |
| **印度教** | 印度本土宗教，多神（梵天、毗濕奴、濕婆） |
| **伊斯蘭教**（回教） | 信阿拉；清真寺**不放人像、動物像**，只用植物、幾何圖案、經文裝飾 |
| **東協**（ASEAN） | 東南亞國家協會，東南亞十國的區域組織 |
| **土生華人** | 在當地出生、融合當地文化的華人後代 |

## 3　宗教怎麼傳進來

| 順序 | 宗教 | 怎麼來 | 現在哪裡最多 |
|---|---|---|---|
| 1 | **印度教** | 古代印度商人、僧侶 | 印尼**峇里島**；吳哥窟、普蘭巴南原本是印度教 |
| 2 | **佛教** | 從印度、斯里蘭卡傳入 | 上座部：**泰、緬、柬、寮**；大乘：**越南** |
| 3 | **伊斯蘭教** | 13～15 世紀阿拉伯、印度穆斯林商人；15 世紀**麻六甲王朝**是傳播中心 | **印尼、馬來西亞、汶萊**、**菲律賓南部**（民答那峨） |
| 4 | **天主教** | 16 世紀以後西班牙殖民 | **菲律賓**（108年考題） |

- 印尼大多信伊斯蘭教，但**峇里島**以**印度教**為主（110年考題）；旁邊的**龍目島**是**伊斯蘭教**（113年考題）。
- **吳哥窟**：**先印度教、後佛教**（107、115年考題）。

## 4　殖民與獨立

### 4-1　誰殖民誰

| 殖民者 | 殖民地 |
|---|---|
| **英國** | 緬甸、馬來西亞、新加坡、汶萊（還有印度） |
| **法國** | **越南、柬埔寨、寮國**＝「**法屬印度支那**」（114年考題） |
| **荷蘭** | **印尼**（不是法國，110年考題） |
| **西班牙** → **美國** | **菲律賓** |
| 沒被殖民 | **泰國** |

### 4-2　泰國為什麼沒被殖民

19 世紀末英國（從緬甸、馬來亞）和法國（從印度支那）兩邊擴張，同意留泰國當**緩衝國**；泰國國王也積極**自主現代化**、靈活外交（106、110年考題）。

### 4-3　獨立運動人物

| 國家 | 人物或團體 |
|---|---|
| **越南** | **潘佩珠**：《越南淪亡史》，1904 年創「越南維新會」（110年考題）；1954 年**奠邊府戰役**法軍大敗，日內瓦會議後退出越南 |
| **緬甸** | 20 世紀初「**緬甸佛教青年會**」領導民族運動，反抗英國（106年考題） |
| **菲律賓** | **黎薩**（Jose Rizal）：寫《不許碰我》，1896 年被西班牙槍殺，菲律賓國父 |

## 5　泰國

### 5-1　王朝順序

**素可泰**（1238，第一個王朝）→ **大城**（阿瑜陀耶）→ **吞武里** → **卻克里**（曼谷王朝，至今）

- 13 世紀吳哥（吉蔑）帝國、緬甸蒲甘衰落，加上**蒙古**入侵東南亞，泰族趁勢崛起（106年考題）。
- **拉瑪四世**：開始現代化改革；電影《安娜與國王》的國王。
- **拉瑪五世**：繼續改革，避免被殖民。

### 5-2　二戰

日軍進駐泰國，泰國 1942 年向英美宣戰；駐美大使**社尼‧巴莫**拒絕宣戰，組織「**自由泰運動**」（109年考題）。

### 5-3　景點與地理

- **美斯樂**（泰北）：國共內戰後**雲南**孤軍後裔定居，種茶（115年考題）。
- **昭披耶河**（湄南河）：流經曼谷，2011 年大洪水。
- 普吉島、**蘇梅島**：海島度假。

## 6　越南

| 項目 | 重點 |
|---|---|
| 北屬時期 | 從漢朝到五代，越南北部被中國統治約 **1,000 年**（108年考題）→ 屬**漢字文化圈**（115年考題） |
| **中法戰爭** | 1884–1885 年中國和法國為越南開戰（109年考題）；之後越南成為法國保護國 |
| **順化** | 阮朝首都（1802 年起，106年考題）；**順化皇城**仿北京紫禁城 |
| **河內升龍皇城** | 11 世紀李朝建在**中國**唐代**安南都護府**的堡壘原址上（115年考題） |
| **會安古城** | 15～19 世紀貿易港，街景融合**中式、日式、法式**（115年考題）；能完整保存是因為 19 世紀**港口淤積、經濟停滯**，沒有被大規模開發（115年考題） |
| **下龍灣** | 石灰岩**喀斯特**海景，「水上桂林」 |
| **胡志明市** | 原名**西貢**（115年考題）；華人集中在**堤岸** |
| 1975 年統一後 | 推行社會主義、沒收私人企業，迫使許多**華人企業家出走**（114年考題） |

河內街景：皇宮、寺院、文廟有**中國風**；總督府、歌劇院是**法式**（109年考題）。

## 7　柬埔寨、寮國、緬甸

### 7-1　柬埔寨

| 時代 | 中國史籍的名稱 |
|---|---|
| 古代（1～7 世紀） | **扶南**（108年考題） |
| 吳哥王朝（9～15 世紀） | **真臘** |

- **吳哥窟**：**12 世紀**建，受**印度**文化影響；原本是**印度教**神廟（供奉毗濕奴），後來改成**佛教**；世界遺產；畫在**國旗**上，象徵**吳哥王朝**（114年考題）。

### 7-2　寮國

- **1893 年**成為法國保護國（110年考題）。
- **龍坡邦**：法式殖民建築和傳統佛寺並存，世界遺產。

### 7-3　緬甸

| 王朝 | 重點 |
|---|---|
| **蒲甘**王朝（849 年左右） | 緬族第一個王朝，上緬甸伊洛瓦底江岸；萬座佛塔 |
| **東吁**王朝 | **16 世紀**擴張，一連串攻打泰國（110年考題） |
| 首都 | **2005 年**從仰光遷到**奈比多** |

## 8　馬來西亞、新加坡、印尼、菲律賓

### 8-1　馬來西亞

- **麻六甲王朝**（15 世紀）：**伊斯蘭教**傳播中心。
- **麻六甲**、**檳城喬治市**：殖民建築，世界遺產。
- **雙子星塔**（Petronas Towers）：伊斯蘭**八角星**造型（115年考題）。
- 英國殖民時引進**橡膠**種植，大量**華人**移入（106年考題）。
- 1963 年馬來西亞聯邦：馬來亞、沙巴、沙撈越、**新加坡**（新加坡 1965 年退出獨立）。

### 8-2　峇峇娘惹（土生華人）

- **15～17 世紀**華商到馬來西亞、印尼定居，和當地女子通婚形成的族群；**男稱峇峇、女稱娘惹**（115年考題）。
- 「**三代成峇**」：第三代華人就成了峇峇，代表**華人文化融入當地**（114年考題）。

### 8-3　新加坡

- 華人為主的多元國家；**Singlish** 混合福建話、馬來語、印度語，反映**族群多元**（106年考題）。
- **牛車水**：新加坡的中國城（113年考題）。
- **大寶森節**：**印度教**徒頭頂奶壺、用**鐵鉤**穿過皮膚、扛拱門苦行繞境（114年考題）。
- 脫離英國後先加入馬來西亞，**1965 年**才獨立（不是立即獨立）。

### 8-4　印尼

| 項目 | 重點 |
|---|---|
| 人口 | 東南亞**最多**；世界上穆斯林人口最多的國家（115年考題） |
| **巴達維亞** | 1619 年荷蘭東印度公司據點，就是今天的**雅加達**（114年考題） |
| **婆羅浮屠**（中爪哇） | **佛教**建築，9 世紀**賽倫德拉**王朝（114年考題） |
| **普蘭巴南** | **印度教**建築 |
| **峇里島** | **印度教** |
| 荷蘭殖民政策 | 1830 年「**強迫種植制**」；1900 年「**倫理政策**」 |
| **萬隆會議**（1955） | 在印尼召開，亞非 29 國，「第三世界」意識的里程碑（107年考題） |
| 蘇哈托「新秩序」 | 限制**華文教育**、**華人姓名**、**華人節慶**；**沒有**限制華人從商（115年考題） |

### 8-5　菲律賓

- **1521 年麥哲倫**抵達菲律賓 → 西班牙 16 世紀起統治 300 多年（113、110年考題） → 1898 年後美國。
- 主要信**天主教**（108年考題）；南部民答那峨信伊斯蘭教。
- 第一位女總統：**柯拉蓉‧艾奎諾**（110年考題）。
- **巴拿威梯田**：伊富高族開墾，世界遺產。

## 9　東南亞地理

| 項目 | 重點 |
|---|---|
| **湄公河** | 流經 **6 國**（中國、緬甸、寮國、泰國、柬埔寨、越南），**水資源衝突最多**（113年考題）；上游在中國叫**瀾滄江** |
| 湄公河三角洲 | 東南亞最大三角洲，吉隆坡飛臺北看得到（107年考題） |
| 兩大海峽 | **麻六甲海峽**、**巽他海峽**：進出東南亞的主要航道（109年考題） |
| 千島之國 | **印尼、菲律賓**（114年考題） |
| 氣候 | 以**熱帶**為主（不是溫帶） |
| 時區 | 理論上 15 度一時區；新加坡、馬來西亞理論上屬 UTC+7，實際採 **UTC+8**（115年考題） |
| 地震 | 雲南、印尼一帶位在**印澳板塊**和**歐亞板塊**交界（109年考題） |

## 10　南亞

### 10-1　印度歷史

| 項目 | 重點 |
|---|---|
| **印度河文明** | 以**城市規劃、排水系統**聞名；遺址**摩亨佐－達羅**在**巴基斯坦**（114年考題） |
| **種姓制度** | **婆羅門**（祭司）、**剎帝利**（武士貴族）、**吠舍**（**農人、牧人**、商人）、**首陀羅**（勞動者）（107年考題） |
| 宗教發源 | **印度教**、**佛教**都源自印度 |
| **印巴分治**（1947） | 英屬印度的**印度教徒**和**穆斯林**互不信任 → **印度**、**巴基斯坦**分治（111、114年考題） |

### 10-2　印度建築

| 宗教 | 特徵 |
|---|---|
| 印度教、佛教 | 源自印度本土；佛塔、神像雕刻 |
| **伊斯蘭** | 外傳入；**外牆刻經文、幾何圖案**的高塔、圓頂（115年考題）；**泰姬瑪哈陵** |

### 10-3　旅遊季節與氣候

- 印度最佳旅遊季節：**10 月～3 月**乾季，例如**聖誕節**最乾爽舒適（115年考題）。
- **恆河**降水來自**孟加拉灣**的水氣；**阿薩姆**卡夕丘陵是世界最多雨地區之一（**地形雨**）。

### 10-4　紅茶

| 單品茶 | 產地 |
|---|---|
| **阿薩姆**、**大吉嶺** | **印度**（110年考題） |
| 錫蘭 | 斯里蘭卡 |
| 祁門 | 中國安徽 |

### 10-5　其他南亞國家

| 國家 | 重點 |
|---|---|
| **尼泊爾** | **藍毗尼**（佛陀誕生地）、加德滿都；**雪巴人**：住喜馬拉雅山谷，當登山嚮導（109年考題） |
| 斯里蘭卡 | 上座部佛教；錫蘭紅茶 |
| 不丹 | 國民幸福指數 |
| 馬爾地夫 | 伊斯蘭國家；**不屬於南島文化** |

## 12　容易搞混總整理

| 容易搞混 | 正確說法 |
|---|---|
| 婆羅浮屠 vs 普蘭巴南 | 佛教 vs 印度教（都在印尼爪哇） |
