## 1　基本名詞：先把字看懂

### 1-1　人

| 名詞 | 白話解釋 |
|---|---|
| **領隊**（Tour Leader／Tour Manager） | 從臺灣**跟團出國**、全程照顧團員的人，代表臺灣的旅行社 |
| **導遊**（Tour Guide） | 在**當地**負責解說、帶路的人，通常是當地旅行社派的 |
| **OP** | Operator，旅行社內負責**訂機位、訂飯店、安排行程作業**的人員 |
| **當地接待旅行社**（Local Agent／Land Operator） | 在國外幫臺灣旅行社安排車、飯店、餐廳、導遊的旅行社，也叫「國外代理商」 |
| **送機人員** | 旅行社派到機場協助團體報到的人員 |
| **履行輔助人** | 幫旅行社完成工作的人或公司（導遊、遊覽車、飯店）；他們出錯，臺灣的旅行社**要負同樣責任** |

### 1-2　行程

| 名詞 | 白話解釋 |
|---|---|
| **行程表**（Itinerary） | 每天去哪裡、住哪裡、吃什麼的表 |
| **Working Itinerary** | 國外代理商給領隊的**工作行程表**，寫清楚每天的車、餐、門票、哪些含哪些不含 |
| **自費行程**（Optional Tour） | 團費以外、**想參加的人另外付錢**的活動 |
| **自由活動** | 行程中沒有安排，團員自己逛的時間 |
| **放射狀行程** | 住**同一家飯店**當基地，每天出去玩、晚上回來 |
| **線條狀行程** | 從 A 地一路玩到 B 地，不回頭。遊覽車要空車開回去，容易產生**回頭空車**（Empty Run）成本 |
| **環狀行程** | 繞一圈回到出發地 |
| **FIT** | 個人自由行 |

### 1-3　飯店與餐

| 名詞 | 白話解釋 |
|---|---|
| **Check-in／Check-out** | 入住／退房 |
| **Wake-up call**（Morning call） | **晨喚**：請總機打電話叫醒房客 |
| **A La Carte** | **點菜**（單點） |
| **Table d'hôte**／Set Menu | 套餐 |

| **Porterage** | 行李搬運費 |

## 2　情境題的解題原則

這章大多是「下列何者**最適當**／**最不適當**」的情境題。照下面的順序想，幾乎都能選對：

| 順序 | 原則 | 例子 |
|---|---|---|
| 1 | **團員安全第一** | 火災、地震、治安問題，先保護人 |
| 2 | **先安撫、誠實說明** | 行程出狀況，先安撫情緒、誠實告知原因 |
| 3 | **回報公司、請求支援** | 領隊不自己亂做決定，重大事件先回報臺灣的旅行社 |
| 4 | **事前預防比事後補救好** | 事先確認、事先告知、事先約定 |
| 5 | **費用依契約判斷** | 不可抗力：增加的不能向旅客收、減少的要退；旅行社的錯：旅行社付；旅客自己的原因：旅客付 |
| 6 | **領隊不能**：丟下團員、找朋友代班、叫團員自己處理、強迫購物、代旅客簽名 | — |

::: tip
**猜題技巧：** 選項裡有「**自行處理**」「**請團員幫忙找**」「**要求團員分攤**」「**直接要求賠償**」「**搭電梯**」「**私人轎車**」的，通常是**錯的**。
:::

## 3　帶團流程：出發前

### 3-1　行程規劃

- 規劃行程**最重要**的考量：**顧客的需求和喜好**（114年考題）。
- 海外行程設計，最優先決定的供應商是**航空公司**（機位決定能不能成團，108年考題）。
- 團體機票要特別注意**停留天數的限制**，否則會增加成本（112年考題）。
- 團員出發前要繳的是團費（機票、住宿、餐食、門票等）；**額外的自費行程**不是出發前必須繳的費用（112年考題）。

### 3-2　行前說明會

說明行程、班機時間、天氣、服裝、**當地風俗和法律**、**安全注意事項**、貨幣與小費、液體與行動電源規定等（114年考題）。

- 嬰兒牛奶等**超過 100 毫升**的液體：要**主動申報**、經同意才能帶上機，不是「口頭說明就可以」（110年考題）。
- 綜合、甲種旅行社辦出國團，要用**書面**向旅客說明旅遊安全注意事項，或舉辦說明會。

### 3-3　領隊的態度

- **事先閱讀行程**，讓旅客充分體驗行程設計的內容（108年考題）。
- 領隊家裡臨時有事，**不能**自己找導遊朋友代班帶團，要回報公司處理（111年考題）。

## 4　帶團流程：機場與交通

### 4-1　機場與機上

- 報到後超過集合時間還有團員沒到：把那位團員的**機票、護照、登機證**交給**送機人員**轉交，領隊先帶其他人進關。
- 機位不足要**分兩班**飛：外語能力較好的團員搭第一班，**領隊搭第二班**照顧較需要協助的人（110年考題）。
- 登機後：請團員**找到自己的座位、迅速坐好**，不要擋住走道（109年考題）。
- 機上廁所顯示 **Occupied** ＝使用中，Vacant ＝沒人（111年考題）。
- 旅客自己開車去機場遇到大塞車趕不上：公司會協助後續交通讓他和團體會合，但**費用由旅客自己負擔**（109年考題）。

### 4-2　遊覽車

- 車開動後，領隊向團員**致歡迎詞**，介紹司機、導遊，說明**車上設備、行車安全規定和座位輪替方式**。
- 長途行車約每 **2 小時**休息一次（「每 4 小時一次」是錯的，109年考題）。
- 長途司機的餐食要照顧好，但要先弄清楚**司機的餐費由誰付**（107年考題）。
- 團員下車參觀時，提醒**貴重物品隨身**，不要放在車上；**護照**一定要隨身（111年考題）。
- 走路的時候：**導遊走最前面、領隊走最後面**（照顧落後的人，106年考題）。

### 4-3　遊覽車或導遊沒來

| 情況 | 正確作法 | 錯誤作法 |
|---|---|---|
| 接機的**遊覽車沒來** | 聯繫當地旅行社了解原因、先**安置團員**、等不到時由當地旅行社另外安排車 | 叫團員一起向接待旅行社**集體要求退費**；租臨時巴士叫團員**分攤費用**（108、107年考題） |
| **導遊**在路上出車禍不能來接 | **先安置團員**，再聯繫處理（110年考題） | — |
| 去機場途中**遊覽車拋錨** | 聯繫車行派車、評估時間、必要時叫合法計程車 | 一開始就請旅行社**改航班**（114年考題） |
| 要去機場時遊覽車**沒到** | 叫**合法的計程車**或營業車 | 用導遊朋友的**私人轎車** |

## 5　帶團流程：飯店

### 5-1　房價計價方式

| 代號 | 全名 | 包含 |
|---|---|---|
| **EP** | European Plan（歐式） | **只有住宿，不含餐**（115年考題） |
| **CP** | Continental Plan（歐陸式） | 住宿＋**歐陸式早餐**（麵包、咖啡） |
| BP | Bermuda Plan | 住宿＋**美式早餐**（有蛋、肉） |
| **MAP** | Modified American Plan（修正美式） | 住宿＋**早餐＋一餐**（午或晚） |
| **AP** | American Plan（美式） | 住宿＋**三餐** |

::: tip
**記法：** **E**P ＝ **E**mpty（空的，什麼都沒有）；**A**P ＝ **A**ll（三餐全包）；MAP 是 AP 打折，只有兩餐。
:::

### 5-2　房型

| 房型 | 意思 |
|---|---|
| Single | 單人房 |
| **Twin** | **兩張單人床** |
| **Double** | **一張雙人床** |
| Triple | 三人房 |
| **Connecting Room** | **連通房**：兩間房中間**有門相通**，適合家人親友（115、111年考題） |
| Adjoining Room | **相鄰房**：隔壁，但**中間沒有門** |
| Suite | 套房 |

### 5-3　Check-in 要宣布的事

- 隔天**晨喚**（Wake-up call）、**早餐**時間和地點、**集合**時間和地點
- **領隊的房號**和緊急聯絡方式
- 飯店設施、**付費項目**（迷你吧、電話、付費電視）
- 注意：英國、歐洲很多飯店的**大廳是 G 或 0 樓**，「1 樓」其實是我們的 2 樓；「提醒大廳按鈕是 1」是錯的（113年考題）

### 5-4　Check-out 的順序（115年考題）

1. 確認**房帳、個人消費**（迷你吧、電話）都已付清
2. **清點團體行李**件數
3. **交還房卡**
4. 最後提醒團員帶齊**個人物品和貴重物品**，上車前確認看到自己的大行李上車

### 5-5　飯店常見狀況

| 狀況 | 正確作法 |
|---|---|
| 房間**空調壞了、有菸味** | 請領隊跟飯店反映、處理或換房（114年考題） |
| 飯店**少訂兩間房** | 領隊出面跟飯店協調；**不能**叫會說當地語言的團員自己去溝通（114年考題） |
| 旺季**超賣**、沒有房間 | 要求當地旅行社安排**同等級以上**的飯店；**不能**讓團員睡飯店大廳（114年考題） |
| 原本市區飯店臨時改到**郊區同等級**飯店 | 領隊要協助安排團員**往返市區的交通**，即使是自由活動日（108年考題） |
| 旅客在飯店**遺失物品** | 協助向飯店查詢、報案；**不是直接要求飯店賠償**（114年考題） |
| 旅客借飯店物品沒還 | 由**旅客**負責，領隊不用自掏腰包賠（107年考題） |

### 5-6　住飯店的禮儀

- 在房間洗的衣服晾在**浴室**；**不要**披在燈罩上（會起火）。
- 用過的毛巾放在浴缸或地上，**不用摺回原狀**（摺回去會讓清潔人員以為沒用過）。
- 退房可以帶走的是**洗髮精、肥皂**等一次性備品；浴袍、毛巾、吹風機不能帶走。
- 游泳池：要穿**泳衣**，小朋友不能穿內衣褲下水。
- 加扣房門**安全鎖**；陌生人敲門不要隨便開。

## 6　帶團流程：餐食

### 6-1　訂餐要告知什麼

團名與團號、**用餐人數**、**特殊飲食需求的人數**（素食、糖尿病、過敏等）、餐標（每人預算）、菜色、**預計抵達時間**。考題問「最主要漏掉什麼」，答案是**特殊飲食需求人數**（115年考題）。

### 6-2　餐廳出狀況

| 狀況 | 正確作法 |
|---|---|
| 到了餐廳**沒有保留座位**（領隊沒再確認） | **誠懇道歉** → 先安置團員在休息區 → 協調餐廳加快 → 準備**備案餐廳**（115年考題） |
| 餐廳在**巷弄裡**很難找 | 領隊先**熟悉位置**，記住**附近明顯地標**，告訴團員（115年考題） |
| 團員吃飯時**突然講不出話**、兩眼看著你 | 先**檢查口腔**、問他**是不是噎到**（114年考題） |

### 6-3　其他

- 國外行程常安排中式餐，原因是團員吃得習慣、價格好控制、上菜快；「國外中式餐廳到處都有、很好找」是**錯的**（110年考題）。
- 猶太旅客：預訂 **KSML**（猶太餐，Kosher Meal，109年考題）；回教 **MOML**；素食 **VGML**；糖尿病 **DBML**。

## 7　購物與自費行程

### 7-1　購物規定

| 規定 | 內容 |
|---|---|
| 臨時加購物行程 | **不可以**，除非旅客**要求或同意** |
| 行程表上**已載明**購物站 | 旅行社安排前往**沒有不妥**（112、106年考題） |
| 旅客**不想進店** | **可以不進去**，不能強迫一起進店（114年考題） |
| 進購物店時 | 宣布**停留時間**，提醒**索取收據**（112年考題） |
| 領隊的角色 | 領隊要**參與把關**，不能全交給導遊、自己完全不管（106年考題） |
| 買到**瑕疵品** | **1 個月內**可以請旅行社協助處理；回國後才發現，領隊也要協助，不能說「已經離開了沒辦法」（110年考題） |

### 7-2　自費行程

- 只能銷售**事先載明**在行程說明中的自費行程（111年考題）。
- 有**危險性、特殊性**的自費行程：在旅客報名**前**，要**告知危險性**，由旅客**自己決定**（113、110年考題）。
- 旅客**不顧勸阻**，到警戒區外游泳溺斃：由**旅客本身**負責（112年考題）。
- 旅客參加水上活動時遺失私人財物：私人物品由**旅客本人**負保管責任（107年考題）；但如果是**領隊主動幫忙保管**、又交給別人顧而被偷，旅行社有責任（110年考題）。

### 7-3　退稅

歐洲各國的**退稅門檻不一樣**（不是全歐盟統一，114年考題）。退稅要在**離開歐盟的最後一個國家**的機場辦理。

## 8　團員管理

### 8-1　預防走失

| 正確 | 錯誤 |
|---|---|
| 事先**約定**：走散了**在原地等**，領隊回頭找 | 叫走失的人「在景點附近到處走動，提高被找到的機會」（112、111年考題） |
| 發給**飯店名片**、領隊電話 | 請其他團員（語言好的、看過他的）**去找**（114、110年考題） |
| 一定時間內找不到 → **向警察報案** | 叫全團一起找，找到才繼續行程（109年考題） |

**郵輪**上集合時間到了有人沒來：請船方廣播、通知船公司協助，**不是**集合全團一起去找（111年考題）。

### 8-2　脫隊

團員要**脫隊**（例如訪友）：請他簽**切結書**，說明中途脫隊**不退團費**，但旅行社因此**省下來的費用要退**（107年考題）。

### 8-3　證件保管

- 護照原則上**旅客自己保管**；領隊**沒有義務**代為保管（111、107年考題）。
- 旅客**主動**請旅行社代管，旅行社還是要盡**善良管理人的注意**，遺失**不能免責**（113年考題）。
- 自由活動時護照被扒：補辦費用由**旅客自己**負擔（111年考題）。

### 8-4　夜遊與財物安全

- 夜遊要**結伴**、搭**合法交通工具**、設定結束時間；**不要**單獨搭大眾運輸、**不要**因為氣氛好就一直延長（112、107年考題）。
- 財物不要藏在行李箱夾層；被偷了**立刻報警**（107年考題）。
- 遇到持槍搶劫：**配合交出財物**，保護人身安全，歹徒離開後立刻報警（107年考題）。
- 劫持綁架最危險的是**最初和最後**階段，要保持鎮定（107年考題）。
- 在餐廳皮包放在**身體和實心椅背之間**（107年考題）。

## 9　解說導覽技巧

### 9-1　解說的原則

- **有計畫地**安排解說內容（在有限時間內最重要，112年考題）。
- 吸引注意：**互動、提問、說故事**、和團員生活連結；只是**單一地講述事實**效果最差。
- 數字要**正確**，最好**轉換成實例**（例如「面積相當於 3 個大安森林公園」）。
- 用不同的話**重述重點**、引用名言佳句；**少用專有名詞**（109年考題）。
- 解說貴在**分享**而不是灌輸。

### 9-2　AIDAS 原則

| 字母 | 意思 |
|---|---|
| **A** | Attention：**引起注意** |
| **I** | Interest：**產生興趣** |
| **D** | Desire：**引發渴望** |
| **A** | Action：**付諸行動** |
| **S** | Satisfaction：**感到滿足** |

::: trap
**陷阱：** 第一個 A 是 **Attention**，**不是** Atmosphere（氛圍）（109年考題）。
:::

### 9-3　對不同對象

| 對象 | 解說技巧 |
|---|---|
| **兒童**（12 歲以下） | 注意力時間**短**，解說要**短、有趣**、多互動；一組約 **10 人**最適當；不是「只挑他們喜歡的稀釋解說」（113、108、107年考題） |
| **年長者** | 放慢速度、音量清楚、注意體力、多安排休息 |

### 9-4　行進間與定點解說

- 選好**位置**，讓團員都聽得到、看得到，也注意**動線安全**。
- **儀態整潔**，給團員專業和安全感。
- 預留**上廁所**時間。
- **提早**到集合地點；分組時注意大家是否跟上；**等團員到齊再解說**；結束前再**清點人數**（110年考題）。
- 解說最少用到的感官是**味覺**（107年考題）。

### 9-5　解說的方式

| 方式 | 說明 |
|---|---|
| 人員解說 | 導遊、解說員現場講解 |
| **生活劇場** | 用**人員表演**、模擬文化傳統生活或習俗來解說（111年考題） |
| 解說牌（非人員解說） | 遊客可**自己控制**看多少；耐用；任何時間都能用 |

**解說員的工作：** 設計解說活動、規範遊客安全、鼓勵遊客了解景點、主動引導參觀；**代訂車票、餐食、住宿不是**解說員的工作（110年考題）。

## 10　觀光心理與行銷

### 10-1　消費者購買決策五階段（每年必考）

**問題認知 → 資訊蒐集 → 替代方案評估 → 購買決策 → 購後行為**

| 階段 | 例子 |
|---|---|
| 問題認知 | 「好累，想出國放鬆」 |
| **資訊蒐集** | 問家人同事、看網路評價（113年考題） |
| 替代方案評估 | 比較日本團和泰國團 |
| 購買決策 | 決定報名 |
| 購後行為 | 玩完覺得滿不滿意、會不會推薦 |

### 10-2　心理學名詞

| 名詞 | 意思 |
|---|---|
| **動機** | 啟動、引導身體和心理朝某個目標前進的**內在**歷程（106年考題） |
| **有限理性** | 人沒辦法掌握所有資訊，只能選「**最適**」而不是「最佳」（106年考題） |
| 影響旅客行為的**外在**因素 | 文化、社會、家庭、參考群體；**個性**是**內在**因素（112年考題） |
| **內向型**人格的旅遊特徵 | 選**熟悉**的地方、為了**休息放鬆**、偏好**安排好的行程**（111年考題） |
| 觀光心理學**不研究**的 | 觀光發展對當地**環境資源**的衝擊（那是觀光環境學，109年考題） |

### 10-3　服務補救與服務品質

| 名詞 | 意思 |
|---|---|
| **互動正當性** | 服務補救時，**仔細聆聽**旅客不滿、態度誠懇（112年考題） |
| 程序正當性 | 處理流程公平、快速 |
| 結果正當性 | 給的補償合理 |
| 服務品質差距 | 例：主管要求「快速回應」卻沒說幾分鐘算快 → **管理認知與服務品質規格之間的差距**（106年考題） |

**客訴處理步驟：** 傾聽 → 同理 → 道歉 → 提出解決方案 → 追蹤。

### 10-4　行銷名詞

| 名詞 | 意思 | 例子 |
|---|---|---|
| **4P** | 產品、價格、**通路**（Place）、推廣 | 直接行銷、仲介商屬於「**通路**」（110年考題） |
| 市場區隔：**心理特性** | 依喜好、生活型態分 | 針對韓劇迷推「**追星團**」（110年考題） |
| **交叉銷售** | 客人買了 A，再推薦相關的 B | 訂機票再加訂飯店、租車（109年考題） |
| **道德訴求** | 廣告訴諸道德、公益 | 「綠色消費、節能減碳」（109年考題） |
| **「拉」的策略** | 直接對**消費者**打廣告，讓他們去找零售商買 | 躉售旅行社打廣告（108年考題） |
| 「推」的策略 | 對**通路商**促銷，讓他們推給消費者 | — |
| 關係行銷＋促銷 | 給**忠誠顧客**折價券 | —（107年考題） |
| 郵輪優惠 | 早鳥、第三四人優惠、長者優惠等；「**尖峰折扣**」**不存在**（旺季不會打折，111年考題） | — |

### 10-5　旅遊糾紛的原因

| 屬於**領隊專業不足**的 | **不是**領隊的問題 |
|---|---|
| 解說不清、態度不好、沒再確認餐廳、走失處理不當 | **航空公司超賣機位**、**行程表本來就安排住郊區**（112、111年考題） |

**不可控制因素：** 天候、罷工、天災等；「飯店客滿臨時改行程」是**可以控制**的（事先確認就能避免，108年考題）。

**遇到糾紛的申訴管道：** 觀光署、消保官、品保協會；「**投訴媒體主持公道**」不適當（110年考題）。

## 12　國際禮儀：食

### 12-1　西餐的座位與餐具

| 規則 | 內容 |
|---|---|
| 入座 | 從椅子的**左邊**入座 |
| 麵包盤、飲料杯 | **左麵包、右水杯**（麵包盤在左上、杯子在右上） |
| 杯子由左到右 | **水杯、紅酒杯、白酒杯**（白酒杯最靠右，最先用） |
| 刀叉 | **由外往內**取用（最外側的先用） |
| 暫時離席 | 餐巾放在**椅子上** |
| 用餐結束 | 餐巾放在**桌上**（左邊） |
| 皮包 | 放在**身體和實心椅背之間** |

### 12-2　吃的方法

- **麵包**：**撕成一口大小**，塗奶油、一口一口吃，**不要整個塗完直接咬**（106年考題）。
- **洗指碗**：吃生蠔、龍蝦、蝸牛等要用手的食物時，會附一碗水（可能有花瓣、檸檬），是**洗手指用的，不能喝**（110年考題）。
- **紅酒**配**紅肉**（單寧能解膩）、白酒配海鮮白肉。
- 飯後酒：白蘭地、波特酒、甜酒等；「**不甜的紅葡萄酒**」**不適合**當飯後酒（109年考題）。
- **魚子醬**：**冷藏後冷食**（108年考題）。
- 用餐時要和左右的人**聊天**，各吃各的、不說話是失禮的（106年考題）。

### 12-3　試酒

酒侍先倒一點點給**主人**試，主人點頭後，再依序幫客人倒（女士優先），最後才是主人。**不是**先倒給女主賓說「這是試酒」（111年考題）。

### 12-4　致詞

主人要致詞時，拿**湯匙或叉子輕敲酒杯**，大家就會安靜下來（111年考題）。

### 12-5　餐具掉了、打破了

**請服務生換新的**，自己不要撿起來繼續用；打破了也是**等服務生來處理**（115、112、107年考題）。

### 12-6　英式下午茶

三層架**由下往上吃**：

| 層 | 放什麼 |
|---|---|
| 下層 | **三明治**（鹹的） |
| 中層 | **司康**（Scone） |
| 上層 | **甜點、水果塔** |

### 12-7　各國禁忌

| 國家或地區 | 禁忌 |
|---|---|
| **印度、中東、回教國家** | **用右手**吃東西、遞東西；左手被視為不潔（114年考題） |
| **泰國** | 不能摸別人的頭；僧侶**不能接觸女性**，女性要把東西放在布上或交給男士轉交；「可以直接從女性手中接受物品」是錯的（109年考題） |
| 回教國家 | 不吃豬肉、不喝酒；齋戒月白天不進食 |
| 猶太人 | 吃**猶太潔食**（Kosher） |

**「入境問俗、入國問禁、入門問諱」**出自《**禮記**》（113年考題）。

## 14　國際禮儀：住行

### 14-2　乘車座次

### 14-3　電梯與樓梯

| 雙手提東西不方便按 | 可以**請人幫忙按**（112年考題） |

## 15　國際禮儀：社交

### 15-1　介紹的順序

**先把「較不尊」的人介紹給「較尊」的人認識：**

| 先介紹 | 給 |
|---|---|
| 男士 | 女士 |
| **年少者** | **年長者** |
| 位低者 | 位高者 |
| **未婚者** | **已婚者** |
| 晚到者 | 先到者 |

- 例外：**年輕女士**和**年長或位高的男士**見面，要**先介紹女士**（114年考題）。
- 被介紹的人有兩位以上：先介紹**職位高或年長**的。
- 被介紹時，除了**女士和長者**，都要**起立**。

### 15-2　名片

- **位低者先遞**給位高者（115年考題）。
- **雙手**拿著名片兩端，**正面朝對方**遞出（110年考題）。
- 收到名片要看一下，不要馬上塞進口袋。

### 15-3　握手

由**女士、長者、位高者**先伸手。

### 15-4　酒會、茶會、園遊會

- 主人在**接待線**迎接客人；客人**不要在接待線上和主人長談**（後面的人在等）。
- 活動開始後，主人在**賓客間穿梭寒暄**。
- 客人想**早退**，可以直接離開，**不用找主人告別**。
- 結束時主人在**出口送客**（113年考題）。

### 15-5　邀請函與拜訪

- 英文邀請函左下角寫 **RSVP**（法文「請回覆」，115年考題）。
- 西式信函摺**三摺**（106年考題）。
- **拜訪前先聯繫**、約好時間（112年考題）。
- 住寄宿家庭：主人家的電話響了，**不要主動接**（106年考題）。

### 15-6　手機與觀賞表演

- 音樂會、歌劇院：手機**關機**，不是改震動然後當場接聽（108年考題）。
- 看**歌劇**：演出中**不要鼓掌叫好**，等一段結束或謝幕再鼓掌（108年考題）。

### 15-7　其他

- 國家典禮演奏國歌時，**文職官員**行**扶手禮**（右手放在左胸），軍人行舉手禮（115年考題）。
- 打高爾夫：在**果嶺**上不要踩到其他球員的**推桿路線**（113年考題）。
- 歐洲上公共廁所**很多要付費**（「歐洲都不用付費」是錯的，110年考題）。
