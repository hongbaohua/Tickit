官方原卷整理，供查閱與出題比對用；App 不會載入本資料夾。

```
參考資料/
├── README.md
├── 考古題/                 ← 已轉成文字，可直接閱讀
│   ├── 1_領隊執業法規/      101年.md … 115年.md
│   ├── 2_領隊執業實務/
│   └── 3_觀光資源概要/
└── 原始PDF/                ← 官方原檔
    ├── 1_領隊執業法規/      {年}年_試題.pdf / _答案.pdf / _更正答案.pdf
    ├── 2_領隊執業實務/
    └── 3_觀光資源概要/
```

- 來源：101–112 年考選部考畢試題；113–115 年交通部觀光署評量考畢試題

- 104 年實務、資源與 105 年三科：PDF 選項為圖片，尚未轉成文字，請看原始 PDF
- 113 年前的法規題，部分數字已修法，以現行法規為準
